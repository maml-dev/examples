# 13936 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.handy-middle.info"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 138
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://prestigious-cope.biz"
      "https://app.monstrous-minister.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: true
    ttl: 1240
    store: "memory"
  }
}
```
