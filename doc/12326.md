# 12326 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "hunger-worker"
    namespace: "production"
    labels: {
      app: "hyphenation"
      tier: "backend"
    }
  }

  # Deployment spec
  spec: {
    replicas: 2
    container: {
      image: "edge:1.17.9"
      port: 8000
      resources: {
        cpu_limit: "1000m"
        memory_limit: "512Mi"
      }
    }

    health_check: {
      path: "/health"
      interval: 15
      timeout: 3
    }
  }
}
```
