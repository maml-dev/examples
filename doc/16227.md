# 16227 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "prestigious-labourer.info"
  inbound: {
    mx_records: [
      "mx1.prestigious-labourer.info"
      "mx2.prestigious-labourer.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.prestigious-labourer.info"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 285
      per_hour: 4898
    }
  }
}
```
