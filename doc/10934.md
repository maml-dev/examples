# 10934 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "excitable-longboat.org"
  inbound: {
    mx_records: [
      "mx1.excitable-longboat.org"
      "mx2.excitable-longboat.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.excitable-longboat.org"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 363
      per_hour: 4387
    }
  }
}
```
