# 13821 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "impeccable-lashes.biz"
  inbound: {
    mx_records: [
      "mx1.impeccable-lashes.biz"
      "mx2.impeccable-lashes.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.impeccable-lashes.biz"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 240
      per_hour: 1354
    }
  }
}
```
