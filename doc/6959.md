# 6959 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Cmd+Shift+L"
      action: "select_all_occurrences"
      when: "editor"
    }

    {
      key: "Ctrl+S"
      action: "toggle_sidebar"
      when: "editor"
    }

    {
      key: "Ctrl+/"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Ctrl+`"
      action: "search_project"
      when: "debug"
    }

    {
      key: "Cmd+K"
      action: "select_all_occurrences"
      when: "terminal"
    }

    {
      key: "Cmd+K"
      action: "command_palette"
      when: "global"
    }
  ]
}
```
