# 4555 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "GET"
      path: "/comments/:id"
      handler: "deletePosts"
      auth: true
    }

    {
      method: "POST"
      path: "/comments"
      handler: "deleteProducts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/comments/:id"
      handler: "listOrders"
      auth: true
    }
  ]
}
```
