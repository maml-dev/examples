# 16331 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.well-made-nightlife.biz"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 6861
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://ironclad-ocelot.biz"
      "https://app.aggravating-drug.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 756
    store: "memory"
  }
}
```
