# 10625 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.thrifty-switchboard.info"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 4626
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://muffled-fireplace.org"
      "https://app.quarrelsome-agreement.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 3085
    store: "redis"
  }
}
```
