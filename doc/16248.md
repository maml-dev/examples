# 16248 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "delete"
        "read"
      ]
      max_seats: 31
    }

    {
      name: "support"
      permissions: [
        "read"
        "delete"
        "write"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "export_data"
        "read"
        "manage_users"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "write"
        "export_data"
        "manage_users"
        "read"
        "manage_billing"
      ]
      max_seats: 48
    }
  ]
}
```
