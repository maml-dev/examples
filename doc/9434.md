# 9434 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "lifetime value"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "prod"
      region: "eu-west"
      team: "home"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 70
    memory_threshold: 93
    latency_p99_ms: 799
    error_rate: 0.02
    notification: {
      channel: "#incidents"
      severity: "critical"
    }
  }
}
```
