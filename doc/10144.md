# 10144 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "POST"
      path: "/users"
      handler: "updateOrders"
      auth: true
    }

    {
      method: "DELETE"
      path: "/products"
      handler: "updateOrders"
      auth: true
    }

    {
      method: "PUT"
      path: "/users/:id"
      handler: "getProducts"
      auth: false
    }

    {
      method: "PUT"
      path: "/products"
      handler: "listPosts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/comments/:id"
      handler: "getOrders"
      auth: true
    }
  ]
}
```
