# 13459 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "GET"
      path: "/posts"
      handler: "getPosts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/orders"
      handler: "getPosts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/comments/:id"
      handler: "updateUsers"
      auth: true
    }

    {
      method: "GET"
      path: "/products/:id"
      handler: "createUsers"
      auth: false
    }
  ]
}
```
