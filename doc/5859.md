# 5859 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "unhappy-platypus.net"
  records: [
    {
      type: "A"
      name: "@"
      value: "straight-crocodile.org"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "*"
      value: "tall-verve.biz"
      ttl: 300
    }

    {
      type: "TXT"
      name: "cdn"
      value: "inferior-thread.name"
      ttl: 3600
    }

    {
      type: "MX"
      name: "*"
      value: "1.28.82.11"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "@"
      value: "colorful-defendant.com"
      ttl: 3600
    }

    {
      type: "A"
      name: "api"
      value: "v=spf1 include:_spf.boring-mortise.name ~all"
      ttl: 86400
    }
  ]
}
```
