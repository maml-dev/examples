# 10587 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@unlucky-legislature.info"
  subject: "Aegrus sit reprehenderit terga damnatio textor."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Cruentus assentator modi somnus mollitia casso uredo cupiditate crebro accendo. Aveho demum tum demulceo attonbitus cursim aedificium ventito vapulus denique. Aequus porro aequitas crapula tabgo corporis culpo coniecto quasi.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Compono contra cruciamentum creber absconditus adstringo. Texo corpus curriculum vapulus necessitatibus. Coniuratio apto curis tristis synagoga cariosus consequuntur vulpes adsidue tepesco.

Visit: {{url}}
"""
}
```
