# 12203 - Logger Config

Structured logging configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  level: "error"
  format: "logfmt"
  timestamp: true
  caller: true # include file:line

  output: "stdout"
  rotation: true
  max_size_mb: 304
  max_age_days: 32
  compress: true
}
```
