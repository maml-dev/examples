# 8253 - Environment Vars

Environment variable definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  app: "pearl"
  variables: [
    {
      name: "JWT_SECRET"
      required: false
      secret: false
      default: "solium"
    }

    {
      name: "SMTP_PASSWORD"
      required: true
      secret: true
      default: "cura"
    }

    {
      name: "GITHUB_TOKEN"
      required: false
      secret: true
      default: null
    }

    {
      name: "DATABASE_URL"
      required: false
      secret: true
      default: null
    }
  ]
}
```
