# 15129 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "delectable-netsuke.org"
  inbound: {
    mx_records: [
      "mx1.delectable-netsuke.org"
      "mx2.delectable-netsuke.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.delectable-netsuke.org"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 401
      per_hour: 9669
    }
  }
}
```
