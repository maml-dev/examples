# 8395 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@nutritious-jump.net"
  subject: "Tristis corona explicabo voluptatem absorbeo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Taceo tenetur comptus triumphus torqueo volva. Eos tergeo defessus attero error temporibus cohaero strenuus soluta ademptio. Coerceo arto defessus omnis crebro quam tersus correptius vilicus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Aeger suffragium summopere speciosus inventore crinis artificiose theca. Quis undique incidunt demonstro quas tametsi adamo aro hic. Vigor dolorum curvo appello aliquam.

Visit: {{url}}
"""
}
```
