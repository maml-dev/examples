# 9629 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.sarcastic-captain.net"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 9152
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://long-step.biz"
      "https://app.ultimate-ribbon.info"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 2787
    store: "memory"
  }
}
```
