# 12722 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "technologies"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "prod"
      region: "us-east"
      team: "industrial"

  }

  # Alert thresholds

    cpu_threshold: 88
    memory_threshold: 86
    latency_p99_ms: 1681
    error_rate: 0.01

      channel: "#incidents"
      severity: "warning"
    }
  }
}
```
