# 13000 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "82756353-7364-41d2-85b8-079ff0ec4f98"
  Accept-Language: "en-US"
  Cache-Control: "max-age=3600"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "aetas"
    "another one": "tubineus"
  }
}
```
