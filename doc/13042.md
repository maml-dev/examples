# 13042 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "junior-pilot.info"
  records: [
    {
      type: "MX"
      name: "@"
      value: "232.188.201.32"
      ttl: 300
    }

    {
      type: "MX"
      name: "staging"
      value: "strict-sailor.info"
      ttl: 300
    }

    {
      type: "TXT"
      name: "*"
      value: "36.44.218.222"
      ttl: 86400
    }

    {
      type: "TXT"
      name: "www"
      value: "needy-rust.name"
      ttl: 3600
    }
  ]
}
```
