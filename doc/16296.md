# 16296 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@educated-alligator.org"
  subject: "Quis quisquam vereor deporto blandior cresco."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Tempus auxilium depopulo villa. Cursus depono benigne. Comptus sequi cibus vester aedificium audio dolorum.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Vester iusto teneo vorax viriliter demergo territo carus cognatus accendo. Aequitas curis vulnus tabula carcer. Tamquam ago vado pectus amet aetas victoria trado.

Visit: {{url}}
"""
}
```
