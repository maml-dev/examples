# 7747 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+S"
      action: "save"
      when: "terminal"
    }

    {
      key: "Cmd+Shift+L"
      action: "toggle_terminal"
      when: "terminal"
    }

    {
      key: "Cmd+Shift+L"
      action: "format"
      when: "editor"
    }

    {
      key: "Alt+F7"
      action: "toggle_comment"
      when: "editor"
    }
  ]
}
```
