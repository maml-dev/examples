# 12822 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "plump-newsprint.com"
  inbound: {
    mx_records: [
      "mx1.plump-newsprint.com"
      "mx2.plump-newsprint.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.plump-newsprint.com"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 220
      per_hour: 8513
    }
  }
}
```
