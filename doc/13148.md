# 13148 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "PATCH"
      path: "/comments"
      handler: "getUsers"
      auth: false
    }

    {
      method: "PATCH"
      path: "/posts/:id"
      handler: "updatePosts"
      auth: true
    }

    {
      method: "PUT"
      path: "/posts"
      handler: "listProducts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/posts"
      handler: "getPosts"
      auth: true
    }

    {
      method: "GET"
      path: "/comments"
      handler: "updateUsers"
      auth: true
    }

    {
      method: "GET"
      path: "/orders/:id"
      handler: "listOrders"
      auth: true
    }

    {
      method: "PUT"
      path: "/comments"
      handler: "createProducts"
      auth: true
    }
  ]
}
```
