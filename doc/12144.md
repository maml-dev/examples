# 12144 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "manage_users"
        "write"
        "read"
        "manage_billing"
        "view_analytics"
      ]
      max_seats: 17
    }

    {
      name: "moderator"
      permissions: [
        "read"
        "write"
        "manage_users"
        "export_data"
        "delete"
      ]
      max_seats: 35
    }

    {
      name: "editor"
      permissions: [
        "manage_users"
        "delete"
        "write"
      ]
      max_seats: 38
    }
  ]
}
```
