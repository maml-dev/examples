# 15724 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "jaunty-thongs.com"
  inbound: {
    mx_records: [
      "mx1.jaunty-thongs.com"
      "mx2.jaunty-thongs.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.jaunty-thongs.com"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 321
      per_hour: 1893
    }
  }
}
```
