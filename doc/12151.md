# 12151 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "export_data"
        "read"
        "manage_billing"
      ]
      max_seats: 41
    }

    {
      name: "viewer"
      permissions: [
        "write"
        "manage_users"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "export_data"
        "delete"
        "manage_billing"
      ]
      max_seats: 20
    }
  ]
}
```
