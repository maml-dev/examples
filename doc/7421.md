# 7421 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.misguided-dream.biz"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 5440
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://plain-tomb.org"
      "https://app.broken-pop.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 983
    store: "redis"
  }
}
```
