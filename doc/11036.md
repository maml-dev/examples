# 11036 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.noted-negotiation.net"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 5920
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://caring-adaptation.org"
      "https://app.talkative-pacemaker.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: true
    ttl: 422
    store: "redis"
  }
}
```
