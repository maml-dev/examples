# 6800 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@enlightened-dusk.biz"
  subject: "Adsidue tego venia denique curiositas."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Desino patria testimonium solium. Ventus desidero cras curis absum. Quae conventus volaticus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Volup cultura ciminatio maxime cogo. Crinis testimonium cum color laudantium. Apto tristis tergiversatio somnus vix.

Visit: {{url}}
"""
}
```
