# 5747 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Cmd+Shift+L"
      action: "toggle_terminal"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+P"
      action: "debug_run"
      when: "global"
    }

    {
      key: "Alt+Up"
      action: "format"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+F"
      action: "save"
      when: "debug"
    }
  ]
}
```
