# 10099 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/xml"
  X-Request-ID: "0b57642a-11f0-48ca-8e98-60d88e8d7639"
  Accept-Language: "ja-JP"
  Cache-Control: "max-age=3600"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "laborum"
    "another one": "adsidue"
  }
}
```
