# 5900 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@unconscious-maestro.net"
  subject: "Varietas adipisci capitulus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Turba tergo tabernus capio amor hic vito tunc. Deinde pax crinis. Tamdiu contego tamdiu.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Basium totidem vaco velociter considero varius verbera. Contego adnuo unde ullus comprehendo abscido depraedor pectus cariosus supplanto. Derideo condico sub utrimque pecus spectaculum tremo statua.

Visit: {{url}}
"""
}
```
