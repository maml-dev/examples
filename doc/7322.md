# 7322 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "lovable-peninsula.name"
  inbound: {
    mx_records: [
      "mx1.lovable-peninsula.name"
      "mx2.lovable-peninsula.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.lovable-peninsula.name"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 270
      per_hour: 2396
    }
  }
}
```
