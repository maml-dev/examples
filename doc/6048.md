# 6048 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "GET"
      path: "/posts"
      handler: "listUsers"
      auth: true
    }

    {
      method: "DELETE"
      path: "/orders/:id"
      handler: "getProducts"
      auth: true
    }

    {
      method: "POST"
      path: "/posts"
      handler: "updatePosts"
      auth: true
    }
  ]
}
```
