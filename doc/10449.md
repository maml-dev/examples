# 10449 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Ctrl+D"
      action: "toggle_terminal"
      when: "editor"
    }

    {
      key: "Cmd+Shift+L"
      action: "toggle_sidebar"
      when: "global"
    }

    {
      key: "Cmd+K"
      action: "find_references"
      when: "global"
    }

    {
      key: "Ctrl+S"
      action: "search_project"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+P"
      action: "find_references"
      when: "terminal"
    }

    {
      key: "Ctrl+B"
      action: "debug_run"
      when: "global"
    }
  ]
}
```
