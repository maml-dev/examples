# 12631 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "warmhearted-sonar.biz"
  inbound: {
    mx_records: [
      "mx1.warmhearted-sonar.biz"
      "mx2.warmhearted-sonar.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.warmhearted-sonar.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 365
      per_hour: 5775
    }
  }
}
```
