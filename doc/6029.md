# 6029 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.royal-version.info"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 6644
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://dirty-adviser.org"
      "https://app.frizzy-marimba.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 2362
    store: "memory"
  }
}
```
