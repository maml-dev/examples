# 14328 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.jumbo-labourer.name"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 5465
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://productive-bungalow.com"
      "https://app.partial-hyphenation.info"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 2305
    store: "memory"
  }
}
```
