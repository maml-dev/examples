# 8043 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "delete"
        "view_analytics"
      ]
      max_seats: 15
    }

    {
      name: "editor"
      permissions: [
        "delete"
        "export_data"
        "write"
        "manage_billing"
        "view_analytics"
      ]
      max_seats: 27
    }

    {
      name: "support"
      permissions: [
        "export_data"
        "manage_users"
        "write"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "read"
        "write"
        "export_data"
        "view_analytics"
        "manage_billing"
      ]
      max_seats: 34
    }
  ]
}
```
