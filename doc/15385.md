# 15385 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "3230101b-c925-41ba-814f-c3e7da106f8c"
  Accept-Language: "de-DE"
  Cache-Control: "no-cache"
  X-Powered-By: "Express"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "turbo"
    "another one": "fugiat"
  }
}
```
