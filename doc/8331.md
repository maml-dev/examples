# 8331 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.spiteful-omelet.org"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 6797
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://fixed-rust.net"
      "https://app.candid-slipper.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 1643
    store: "redis"
  }
}
```
