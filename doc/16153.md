# 16153 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "read"
        "manage_billing"
      ]
      max_seats: 39
    }

    {
      name: "billing"
      permissions: [
        "write"
        "export_data"
        "manage_billing"
        "view_analytics"
      ]
      max_seats: 7
    }

    {
      name: "billing"
      permissions: [
        "view_analytics"
        "delete"
        "write"
      ]
      max_seats: null
    }
  ]
}
```
