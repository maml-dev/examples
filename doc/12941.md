# 12941 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "distinct-technologist.name"
  records: [
    {
      type: "NS"
      name: "staging"
      value: "untried-unblinking.net"
      ttl: 86400
    }

    {
      type: "TXT"
      name: "staging"
      value: "v=spf1 include:_spf.indolent-vibration.name ~all"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "www"
      value: "244.30.15.67"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "mail"
      value: "141.27.88.193"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "mail"
      value: "different-numeric.info"
      ttl: 3600
    }
  ]
}
```
