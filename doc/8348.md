# 8348 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "read"
        "write"
      ]
      max_seats: 50
    }

    {
      name: "billing"
      permissions: [
        "read"
        "write"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "export_data"
        "delete"
      ]
      max_seats: null
    }
  ]
}
```
