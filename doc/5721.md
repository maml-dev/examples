# 5721 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.roasted-decryption.biz"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 9547
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://short-term-curl.org"
      "https://app.parallel-minority.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 1654
    store: "redis"
  }
}
```
