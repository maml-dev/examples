# 7652 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "delete"
        "export_data"
      ]
      max_seats: 36
    }

    {
      name: "editor"
      permissions: [
        "manage_users"
        "manage_billing"
        "read"
      ]
      max_seats: 38
    }

    {
      name: "billing"
      permissions: [
        "write"
        "delete"
        "read"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "delete"
        "write"
        "read"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "write"
        "manage_billing"
      ]
      max_seats: null
    }
  ]
}
```
