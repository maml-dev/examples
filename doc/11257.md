# 11257 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Cmd+K"
      action: "save"
      when: "editor"
    }

    {
      key: "Ctrl+S"
      action: "debug_run"
      when: "global"
    }

    {
      key: "Ctrl+D"
      action: "command_palette"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+P"
      action: "find_references"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+P"
      action: "toggle_sidebar"
      when: "editor"
    }

    {
      key: "Ctrl+D"
      action: "command_palette"
      when: "debug"
    }
  ]
}
```
