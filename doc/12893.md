# 12893 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@taut-settler.name"
  subject: "Cariosus subito accommodo complectus nulla labore."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Turba pecco careo curtus cupiditate tendo tredecim. Decimus adaugeo quo. Corporis nihil commodi.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Turbo iure audeo sumo carmen basium vix. Arguo adhuc summa civitas conitor volutabrum. Quasi agnosco canto cubo comis odio tristis nulla asper.

Visit: {{url}}
"""
}
```
