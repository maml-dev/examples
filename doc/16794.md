# 16794 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@alive-publicity.net"
  subject: "Perspiciatis quia beatus ab."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Celo alius virgo crustulum adiuvo. Suppono utique adipiscor desparatus incidunt thorax id substantia quibusdam. Amitto aut timor cauda abundans arca conventus aegrus umerus tergum.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Summopere tamquam censura somnus suscipio volup valeo tum carus. Inflammatio ascit auctor aureus tristis communis arbitro amita talus. Acervus usitas vulgaris alias conqueror culpa campana.

Visit: {{url}}
"""
}
```
