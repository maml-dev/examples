# 13232 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "platforms"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "staging"
      region: "eu-west"
      team: "automotive"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 81
    memory_threshold: 93
    latency_p99_ms: 1532
    error_rate: 0.02
    notification: {
      channel: "#oncall"
      severity: "info"
    }
  }
}
```
