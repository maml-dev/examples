# 12050 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "view_analytics"
        "manage_billing"
        "write"
        "export_data"
      ]
      max_seats: 16
    }

    {
      name: "support"
      permissions: [
        "delete"
        "export_data"
        "write"
        "read"
        "manage_users"
      ]
      max_seats: 23
    }

    {
      name: "admin"
      permissions: [
        "view_analytics"
        "export_data"
      ]
      max_seats: null
    }
  ]
}
```
