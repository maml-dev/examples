# 16639 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "blind-asset.name"
  inbound: {
    mx_records: [
      "mx1.blind-asset.name"
      "mx2.blind-asset.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.blind-asset.name"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 433
      per_hour: 9234
    }
  }
}
```
