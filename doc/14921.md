# 14921 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.foolish-cheese.org"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 4575
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://trusting-sailor.name"
      "https://app.impure-abacus.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 3452
    store: "redis"
  }
}
```
