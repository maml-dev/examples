# 16255 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "dirty-commodity.org"
  records: [
    {
      type: "NS"
      name: "cdn"
      value: "evil-confusion.info"
      ttl: 300
    }

    {
      type: "MX"
      name: "mail"
      value: "215.200.7.149"
      ttl: 3600
    }

    {
      type: "A"
      name: "staging"
      value: "162.154.24.229"
      ttl: 86400
    }

    {
      type: "A"
      name: "@"
      value: "v=spf1 include:_spf.tempting-heartbeat.info ~all"
      ttl: 3600
    }

    {
      type: "NS"
      name: "cdn"
      value: "v=spf1 include:_spf.bony-shark.info ~all"
      ttl: 86400
    }

    {
      type: "CNAME"
      name: "api"
      value: "spiteful-league.biz"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "staging"
      value: "v=spf1 include:_spf.scientific-swing.info ~all"
      ttl: 3600
    }
  ]
}
```
