# 16045 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "PATCH"
      path: "/users/:id"
      handler: "listPosts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/comments"
      handler: "listPosts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/orders/:id"
      handler: "getOrders"
      auth: false
    }

    {
      method: "PATCH"
      path: "/products"
      handler: "listProducts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/orders/:id"
      handler: "createOrders"
      auth: true
    }

    {
      method: "PUT"
      path: "/users/:id"
      handler: "getPosts"
      auth: false
    }
  ]
}
```
