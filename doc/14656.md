# 14656 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "PUT"
      path: "/products/:id"
      handler: "createProducts"
      auth: true
    }

    {
      method: "PUT"
      path: "/users/:id"
      handler: "deleteUsers"
      auth: true
    }

    {
      method: "PUT"
      path: "/products/:id"
      handler: "deleteUsers"
      auth: false
    }

    {
      method: "PATCH"
      path: "/posts"
      handler: "getOrders"
      auth: true
    }
  ]
}
```
