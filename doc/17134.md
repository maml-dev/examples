# 17134 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "brown-settler.org"
  inbound: {
    mx_records: [
      "mx1.brown-settler.org"
      "mx2.brown-settler.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.brown-settler.org"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 151
      per_hour: 9264
    }
  }
}
```
