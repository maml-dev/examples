# 5221 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "channels"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 60 # seconds
    labels: {
      env: "prod"
      region: "ap-south"
      team: "shoes"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 88
    memory_threshold: 94
    latency_p99_ms: 1451
    error_rate: 0.02
    notification: {
      channel: "#incidents"
      severity: "warning"
    }
  }
}
```
