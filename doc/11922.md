# 11922 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.smug-toothpick.biz"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 148
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://agitated-vibration.net"
      "https://app.adolescent-conservation.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 711
    store: "redis"
  }
}
```
