# 14397 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@bony-developing.org"
  subject: "Vereor substantia somniculosus vulariter appono."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Tremo uterque cattus adduco degusto aliquam omnis alioqui vestigium beatus. Spiculum bos absconditus demoror tantillus admitto amplus. Taceo suasoria sint volutabrum sustineo speculum ventus minima doloribus depraedor.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Ara quos terror. Tactus trado clibanus dolore arbitro aeger caput. Creber ancilla tamdiu expedita aeger ocer verbum.

Visit: {{url}}
"""
}
```
