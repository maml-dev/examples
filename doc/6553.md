# 6553 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "unkempt-finger.biz"
  records: [
    {
      type: "A"
      name: "*"
      value: "117.24.33.159"
      ttl: 3600
    }

    {
      type: "A"
      name: "*"
      value: "v=spf1 include:_spf.ornery-tuba.com ~all"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "@"
      value: "v=spf1 include:_spf.stylish-king.name ~all"
      ttl: 86400
    }

    {
      type: "NS"
      name: "@"
      value: "237.110.11.188"
      ttl: 300
    }

    {
      type: "TXT"
      name: "staging"
      value: "v=spf1 include:_spf.tiny-pile.name ~all"
      ttl: 86400
    }
  ]
}
```
