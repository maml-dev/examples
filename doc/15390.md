# 15390 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@eminent-hepatitis.biz"
  subject: "Voluptatibus tres pariatur ciminatio."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Cupiditas cito desino aeger virga coruscus adhaero degenero conforto. Vestigium deserunt cupiditate sumo. Arbitro vorago somniculosus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Varius unde textus cultura utrimque officiis impedit crudelis delectatio celo. Tum alii suggero cetera tibi depopulo curto cariosus volup. Arx natus veniam arguo cupressus cerno quibusdam vesper collum undique.

Visit: {{url}}
"""
}
```
