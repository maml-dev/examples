# 9742 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "unkempt-sushi.org"
  records: [
    {
      type: "MX"
      name: "*"
      value: "56.62.26.181"
      ttl: 3600
    }

    {
      type: "MX"
      name: "api"
      value: "218.80.225.4"
      ttl: 86400
    }

    {
      type: "MX"
      name: "*"
      value: "v=spf1 include:_spf.coordinated-produce.org ~all"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "www"
      value: "v=spf1 include:_spf.tender-palate.info ~all"
      ttl: 86400
    }
  ]
}
```
