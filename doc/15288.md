# 15288 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@zesty-agreement.info"
  subject: "Video debitis succedo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Appono terror articulus tripudio. Desidero vix contabesco. Spoliatio collum corrupti textus terminatio dedico coaegresco.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Brevis commemoro aveho. Custodia universe desidero summopere utrum civitas arca quam cibus. Aranea suffragium deludo damno laborum.

Visit: {{url}}
"""
}
```
