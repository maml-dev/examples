# 10104 - Logger Config

Structured logging configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  level: "info"
  format: "logfmt"
  timestamp: true
  caller: false # include file:line

  output: "stdout"
  rotation: false
  max_size_mb: 226
  max_age_days: 56
  compress: true
}
```
