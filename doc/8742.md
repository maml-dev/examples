# 8742 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Alt+F7"
      action: "select_all_occurrences"
      when: "editor"
    }

    {
      key: "Cmd+K"
      action: "toggle_comment"
      when: "terminal"
    }

    {
      key: "Ctrl+S"
      action: "command_palette"
      when: "debug"
    }

    {
      key: "Ctrl+B"
      action: "command_palette"
      when: "terminal"
    }

    {
      key: "Alt+F7"
      action: "toggle_terminal"
      when: "terminal"
    }

    {
      key: "F5"
      action: "toggle_terminal"
      when: "global"
    }

    {
      key: "Cmd+Shift+L"
      action: "find_references"
      when: "debug"
    }
  ]
}
```
