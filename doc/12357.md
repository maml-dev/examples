# 12357 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "delete"
        "read"
        "export_data"
        "view_analytics"
      ]
      max_seats: 43
    }

    {
      name: "editor"
      permissions: [
        "write"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "write"
        "manage_billing"
        "delete"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "manage_users"
        "manage_billing"
      ]
      max_seats: 49
    }
  ]
}
```
