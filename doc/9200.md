# 9200 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@lasting-aftermath.net"
  subject: "Abundans suffragium decens."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Clementia absconditus communis decretum iste ancilla amet hic cunabula. Baiulus admoneo cruciamentum tabella dedico venio adduco. Corona vacuus volup cuius subito.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Defluo acer attero impedit. Defaeco torrens perspiciatis utilis mollitia tamen depono vero cras degusto. Delectatio dolorum magnam conservo.

Visit: {{url}}
"""
}
```
