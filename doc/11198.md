# 11198 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@lined-pants.name"
  subject: "Iste subiungo chirographum adinventitias."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Contego accusator ustilo strenuus chirographum viduo. Baiulus arma adeo velum speculum turba cupressus. Turbo subnecto commodo cernuus derelinquo perspiciatis abscido aliquid.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Nobis depopulo derideo vel undique accedo contigo texo. Magni angulus spoliatio cura vitae. Modi est compello creptio atrocitas sapiente.

Visit: {{url}}
"""
}
```
