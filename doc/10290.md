# 10290 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@snarling-character.com"
  subject: "Explicabo artificiose tribuo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Thermae corporis vehemens. Repellendus animus comparo tyrannus defleo audacia. Deprecator abscido umquam subvenio vis vergo.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Conventus cometes aegrus collum pecto cetera aufero aperte adduco. Delectus vorax tantum. Tolero cunctatio temperantia.

Visit: {{url}}
"""
}
```
