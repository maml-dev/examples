# 16442 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Ctrl+D"
      action: "toggle_sidebar"
      when: "global"
    }

    {
      key: "Cmd+Shift+L"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+P"
      action: "save"
      when: "editor"
    }

    {
      key: "Alt+F7"
      action: "find_references"
      when: "editor"
    }

    {
      key: "Ctrl+`"
      action: "toggle_sidebar"
      when: "debug"
    }

    {
      key: "Alt+Up"
      action: "search_project"
      when: "debug"
    }
  ]
}
```
