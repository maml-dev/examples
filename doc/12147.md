# 12147 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Alt+Up"
      action: "save"
      when: "terminal"
    }

    {
      key: "Cmd+K"
      action: "search_project"
      when: "terminal"
    }

    {
      key: "Ctrl+/"
      action: "search_project"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+F"
      action: "toggle_comment"
      when: "editor"
    }

    {
      key: "Ctrl+D"
      action: "toggle_comment"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+F"
      action: "save"
      when: "terminal"
    }
  ]
}
```
