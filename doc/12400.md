# 12400 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@zany-shore.com"
  subject: "Possimus crudelis bis accusamus cupressus terra."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Tergo celebrer expedita pecco. Ea alter harum eius doloremque claro audeo. Tempore cura barba vere utrum.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Vitiosus labore callide. Crapula depulso cunabula anser. Pax collum deporto.

Visit: {{url}}
"""
}
```
