# 13947 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Ctrl+B"
      action: "toggle_terminal"
      when: "editor"
    }

    {
      key: "Ctrl+D"
      action: "search_project"
      when: "debug"
    }

    {
      key: "Ctrl+/"
      action: "toggle_terminal"
      when: "global"
    }

    {
      key: "Alt+F7"
      action: "select_all_occurrences"
      when: "terminal"
    }

    {
      key: "Alt+F7"
      action: "command_palette"
      when: "terminal"
    }

    {
      key: "F5"
      action: "command_palette"
      when: "debug"
    }
  ]
}
```
