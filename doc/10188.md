# 10188 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@reflecting-mentor.info"
  subject: "Subseco tardus territo solio."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Demonstro corporis basium. Virga clementia addo comitatus valetudo correptius. Crux vinum caterva solutio adeptio acidus tibi terreo amoveo.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Solutio adflicto vulpes conspergo voluptate solutio patior. Ad sunt eligendi illum pariatur abundans quae. Tendo argumentum ambulo.

Visit: {{url}}
"""
}
```
