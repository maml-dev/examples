# 9743 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "pink-pile.info"
  records: [
    {
      type: "CNAME"
      name: "*"
      value: "v=spf1 include:_spf.needy-underpants.org ~all"
      ttl: 300
    }

    {
      type: "CNAME"
      name: "staging"
      value: "sneaky-polarisation.biz"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "mail"
      value: "v=spf1 include:_spf.tight-nucleotidase.net ~all"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "*"
      value: "angelic-unblinking.info"
      ttl: 3600
    }
  ]
}
```
