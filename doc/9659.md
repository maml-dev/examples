# 9659 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "F5"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Cmd+K"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Ctrl+B"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "F5"
      action: "format"
      when: "debug"
    }

    {
      key: "Ctrl+`"
      action: "command_palette"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+P"
      action: "toggle_terminal"
      when: "editor"
    }

    {
      key: "Cmd+K"
      action: "find_references"
      when: "debug"
    }
  ]
}
```
