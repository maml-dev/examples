# 11455 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Ctrl+Shift+P"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Alt+Up"
      action: "find_references"
      when: "terminal"
    }

    {
      key: "Ctrl+D"
      action: "format"
      when: "editor"
    }

    {
      key: "Cmd+K"
      action: "search_project"
      when: "editor"
    }

    {
      key: "Alt+F7"
      action: "find_references"
      when: "global"
    }

    {
      key: "Cmd+Shift+L"
      action: "debug_run"
      when: "global"
    }

    {
      key: "Ctrl+/"
      action: "toggle_terminal"
      when: "editor"
    }
  ]
}
```
