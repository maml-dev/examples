# 12756 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Alt+Up"
      action: "find_references"
      when: "debug"
    }

    {
      key: "Ctrl+S"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Ctrl+D"
      action: "toggle_sidebar"
      when: "global"
    }

    {
      key: "Cmd+K"
      action: "find_references"
      when: "global"
    }

    {
      key: "Ctrl+S"
      action: "save"
      when: "editor"
    }
  ]
}
```
