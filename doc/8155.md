# 8155 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "manage_users"
        "view_analytics"
        "export_data"
      ]
      max_seats: 34
    }

    {
      name: "editor"
      permissions: [
        "export_data"
        "manage_billing"
        "write"
        "read"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "write"
        "export_data"
        "manage_billing"
      ]
      max_seats: 21
    }

    {
      name: "support"
      permissions: [
        "read"
        "write"
        "manage_users"
      ]
      max_seats: null
    }
  ]
}
```
