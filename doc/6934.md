# 6934 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.untidy-sauerkraut.com"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 4011
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://definite-priesthood.org"
      "https://app.agitated-premium.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 2105
    store: "redis"
  }
}
```
