# 9249 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "PATCH"
      path: "/users/:id"
      handler: "getPosts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/products"
      handler: "getUsers"
      auth: true
    }

    {
      method: "POST"
      path: "/posts"
      handler: "createOrders"
      auth: false
    }

    {
      method: "PATCH"
      path: "/orders"
      handler: "getPosts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/users/:id"
      handler: "updateOrders"
      auth: false
    }
  ]
}
```
