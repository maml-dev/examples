# 11805 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "royal-babushka.com"
  ttl: 3600 # seconds
  nameservers: [
    "ns1.cool-rubric.info"
    "ns2.brown-technician.name"
  ]

  soa_email: "admin@accomplished-pulse.net"
  refresh: 7200
  retry: 900
  expire: 604800
}
```
