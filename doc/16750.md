# 16750 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Cmd+K"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Ctrl+/"
      action: "toggle_comment"
      when: "editor"
    }

    {
      key: "F5"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+P"
      action: "find_references"
      when: "terminal"
    }

    {
      key: "Cmd+K"
      action: "debug_run"
      when: "editor"
    }

    {
      key: "Ctrl+S"
      action: "command_palette"
      when: "terminal"
    }
  ]
}
```
