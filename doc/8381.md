# 8381 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/xml"
  X-Request-ID: "0a475de6-cc7d-4624-8482-a82b31c20f72"
  Accept-Language: "fr-FR"
  Cache-Control: "no-cache"
  X-Powered-By: "Express"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "vilis"
    "another one": "totidem"
  }
}
```
