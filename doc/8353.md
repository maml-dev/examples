# 8353 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "POST"
      path: "/posts"
      handler: "getOrders"
      auth: false
    }

    {
      method: "PUT"
      path: "/products/:id"
      handler: "getProducts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/comments/:id"
      handler: "createUsers"
      auth: true
    }

    {
      method: "PUT"
      path: "/products/:id"
      handler: "getUsers"
      auth: false
    }

    {
      method: "POST"
      path: "/comments/:id"
      handler: "getUsers"
      auth: false
    }
  ]
}
```
