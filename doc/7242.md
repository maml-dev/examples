# 7242 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "F5"
      action: "find_references"
      when: "terminal"
    }

    {
      key: "Alt+Up"
      action: "debug_run"
      when: "global"
    }

    {
      key: "Ctrl+S"
      action: "select_all_occurrences"
      when: "editor"
    }

    {
      key: "Alt+F7"
      action: "select_all_occurrences"
      when: "global"
    }

    {
      key: "Ctrl+B"
      action: "find_references"
      when: "global"
    }

    {
      key: "Ctrl+Shift+F"
      action: "select_all_occurrences"
      when: "debug"
    }
  ]
}
```
