# 5931 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.unconscious-sideboard.name"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 5858
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://grouchy-kiss.org"
      "https://app.ashamed-premier.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 2730
    store: "redis"
  }
}
```
