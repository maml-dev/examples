# 7933 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "troubled-ferret.net"
  inbound: {
    mx_records: [
      "mx1.troubled-ferret.net"
      "mx2.troubled-ferret.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.troubled-ferret.net"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 179
      per_hour: 1454
    }
  }
}
```
