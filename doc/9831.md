# 9831 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.dramatic-charlatan.org"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 9516
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://aware-poppy.net"
      "https://app.burly-hierarchy.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 3587
    store: "redis"
  }
}
```
