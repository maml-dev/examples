# 7894 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "a1e35f40-abe1-484f-a506-6256f28d1fd8"
  Accept-Language: "de-DE"
  Cache-Control: "no-cache"
  X-Powered-By: "Koa"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "inventore"
    "another one": "arguo"
  }
}
```
