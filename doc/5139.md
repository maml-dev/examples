# 5139 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.unhealthy-pine.net"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 5018
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://unwieldy-roundabout.biz"
      "https://app.slow-ferret.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 1306
    store: "redis"
  }
}
```
