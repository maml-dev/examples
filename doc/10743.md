# 10743 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Cmd+Shift+L"
      action: "select_all_occurrences"
      when: "debug"
    }

    {
      key: "Cmd+Shift+L"
      action: "save"
      when: "global"
    }

    {
      key: "Cmd+Shift+L"
      action: "save"
      when: "editor"
    }
  ]
}
```
