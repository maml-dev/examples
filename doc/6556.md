# 6556 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "view_analytics"
        "delete"
      ]
      max_seats: 14
    }

    {
      name: "editor"
      permissions: [
        "export_data"
        "write"
        "manage_users"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "write"
        "manage_users"
      ]
      max_seats: null
    }
  ]
}
```
