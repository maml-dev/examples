# 5433 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "applications"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 15 # seconds
    labels: {
      env: "prod"
      region: "us-east"
      team: "books"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 79
    memory_threshold: 94
    latency_p99_ms: 676
    error_rate: 0.05
    notification: {
      channel: "#oncall"
      severity: "critical"
    }
  }
}
```
