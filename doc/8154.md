# 8154 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "GET"
      path: "/comments/:id"
      handler: "createProducts"
      auth: true
    }

    {
      method: "PUT"
      path: "/products/:id"
      handler: "createProducts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/products/:id"
      handler: "updatePosts"
      auth: false
    }

    {
      method: "GET"
      path: "/orders"
      handler: "deleteUsers"
      auth: false
    }
  ]
}
```
