# 10383 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "55913942-9c90-4f58-a758-2bccbc992b95"
  Accept-Language: "en-US"
  Cache-Control: "no-cache"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "suscipit"
    "another one": "cado"
  }
}
```
