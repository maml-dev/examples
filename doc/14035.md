# 14035 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.realistic-order.net"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 2730
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://instructive-hose.name"
      "https://app.deadly-bar.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: true
    ttl: 2585
    store: "redis"
  }
}
```
