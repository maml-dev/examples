# 12698 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@unsightly-platter.com"
  subject: "Cibus acervus acquiro vapulus cunabula."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Caveo conitor stipes verecundia tamdiu arbustum abbas antea terminatio. Ter truculenter tredecim voluptatum acerbitas corroboro sopor cometes. Ambitus aegrus temporibus vito depraedor argumentum balbus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Antepono utor itaque clarus condico sumo trado deputo laboriosam. Dicta impedit blanditiis pecus. Cogito cognomen suspendo aestivus placeat annus stips contra.

Visit: {{url}}
"""
}
```
