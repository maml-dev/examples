# 5682 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@close-role.biz"
  subject: "Cilicium tabesco angulus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Ager vulgaris vallum recusandae pecco cruciamentum alienus. Admiratio acerbitas vos cunctatio aurum color sumptus. Acer aro denuncio vester complectus cauda amplus viridis vergo aedificium.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Arx substantia cupressus verumtamen pariatur tener dolorem inventore. Ulterius crepusculum tametsi. Peior benevolentia ventito clarus sit.

Visit: {{url}}
"""
}
```
