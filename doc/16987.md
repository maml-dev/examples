# 16987 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "2cd21ab1-3ef4-47ab-ae6a-11ea4271c16d"
  Accept-Language: "fr-FR"
  Cache-Control: "no-cache"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "addo"
    "another one": "voluptatibus"
  }
}
```
