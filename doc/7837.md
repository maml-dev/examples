# 7837 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "salty-tectonics.org"
  inbound: {
    mx_records: [
      "mx1.salty-tectonics.org"
      "mx2.salty-tectonics.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.salty-tectonics.org"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 354
      per_hour: 6797
    }
  }
}
```
