# 12248 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "POST"
      path: "/orders/:id"
      handler: "getProducts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/orders"
      handler: "createProducts"
      auth: true
    }

    {
      method: "GET"
      path: "/orders"
      handler: "getOrders"
      auth: true
    }
  ]
}
```
