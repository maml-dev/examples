# 16356 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+`"
      action: "search_project"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+P"
      action: "format"
      when: "global"
    }

    {
      key: "Cmd+K"
      action: "toggle_comment"
      when: "editor"
    }

    {
      key: "Ctrl+`"
      action: "search_project"
      when: "terminal"
    }

    {
      key: "Ctrl+B"
      action: "toggle_comment"
      when: "editor"
    }

      action: "toggle_comment"
      when: "global"
    }

    {
      key: "Cmd+K"
      action: "format"
      when: "debug"
    }
  ]
}
```
