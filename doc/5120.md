# 5120 - App Settings

Application environment configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  app_name: "Zieme, Morissette and Gibson"
  environment: "staging"
  debug: true
  port: 6234

  # Logging
  log_level: "warn"
  log_format: "pretty"
  api_version: "v1"
  max_request_size: "7mb"
}
```
