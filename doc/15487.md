# 15487 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@stale-patroller.name"
  subject: "Commemoro audax odit absorbeo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Capto cometes vae virga comminor tandem vulnero. Apparatus utrimque libero canis capto animadverto ante dapifer vox voveo. Utrum sumo cupio quidem strenuus patria.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Cerno tumultus sed tenetur tamquam absorbeo officiis acidus. Aliquid curto tollo. Umquam bis stabilis adiuvo antepono comes despecto patior comes administratio.

Visit: {{url}}
"""
}
```
