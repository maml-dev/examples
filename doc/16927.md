# 16927 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.bulky-waterspout.biz"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 9443
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://outstanding-hydrolyze.net"
      "https://app.coarse-following.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 3315
    store: "redis"
  }
}
```
