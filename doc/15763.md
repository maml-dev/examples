# 15763 - Dashboard Layout

Dashboard widget layout configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  title: "Schmitt LLC Dashboard"
  refresh_interval: 60 # seconds
  widgets: [
    {
      type: "chart"
      title: "Traffic"
      source: "/api/metrics/traffic"
      chart_type: "area"
      period: "30d"
    }

    {
      type: "stat"
      title: "Total Users"
      source: "/api/stats/users"
      format: "number"
    }

    {
      type: "table"
      title: "Recent Orders"
      source: "/api/recent/signups"
      limit: 25
    }
  ]

  theme: "auto"
}
```
