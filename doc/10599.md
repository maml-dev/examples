# 10599 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "08da9adb-e20f-471a-9f36-03c5525149e0"
  Accept-Language: "ja-JP"
  Cache-Control: "no-cache"
  X-Powered-By: "Fastify"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "urbanus"
    "another one": "nihil"
  }
}
```
