# 11940 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.harmful-flint.biz"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 8353
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://nervous-palate.info"
      "https://app.fearless-eyeliner.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 428
    store: "redis"
  }
}
```
