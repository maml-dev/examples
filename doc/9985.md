# 9985 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@back-brook.name"
  subject: "Conventus undique stabilis volva atque contego."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Bellicus doloremque anser amplus provident appositus trucido. Benevolentia comprehendo subiungo conatus astrum conculco. Censura similique cibus error tonsor.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Venia denique maiores capio armarium similique temptatio subito. Quae vulgaris corroboro beatae. Dedecor vomer terga verbum.

Visit: {{url}}
"""
}
```
