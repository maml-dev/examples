# 13421 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "granular-noon.biz"
  inbound: {
    mx_records: [
      "mx1.granular-noon.biz"
      "mx2.granular-noon.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.granular-noon.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 394
      per_hour: 8044
    }
  }
}
```
