# 10958 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "view_analytics"
        "read"
      ]
      max_seats: 2
    }

    {
      name: "viewer"
      permissions: [
        "manage_billing"
        "export_data"
        "view_analytics"
        "manage_users"
      ]
      max_seats: 18
    }

    {
      name: "moderator"
      permissions: [
        "manage_billing"
        "delete"
      ]
      max_seats: null
    }
  ]
}
```
