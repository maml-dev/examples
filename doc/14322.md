# 14322 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "tributary-worker"
    namespace: "staging"
    labels: {
      app: "pine"
      tier: "data"
    }
  }

  # Deployment spec
  spec: {
    replicas: 3
    container: {
      image: "seagull:0.18.3"
      port: 3000
      resources: {
        cpu_limit: "1000m"
        memory_limit: "512Mi"
      }
    }

    health_check: {
      path: "/health"
      interval: 15
      timeout: 10
    }
  }
}
```
