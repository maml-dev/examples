# 13140 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "bourgeoisie-api"
    namespace: "default"
    labels: {
      app: "digit"
      tier: "frontend"
    }
  }

  # Deployment spec
  spec: {
    replicas: 2
    container: {
      image: "tooth:6.10.10"
      port: 8080
      resources: {
        cpu_limit: "500m"
        memory_limit: "256Mi"
      }
    }

    health_check: {
      path: "/health"
      interval: 10
      timeout: 10
    }
  }
}
```
