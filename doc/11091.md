# 11091 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/xml"
  X-Request-ID: "4615d8dd-b6a6-4eb9-b715-1633f597e580"
  Accept-Language: "en-US"
  Cache-Control: "public, max-age=86400"
  X-Powered-By: "Fastify"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "tum"
    "another one": "ars"
  }
}
```
