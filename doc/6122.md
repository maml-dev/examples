# 6122 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "variable-switch.net"
  inbound: {
    mx_records: [
      "mx1.variable-switch.net"
      "mx2.variable-switch.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.variable-switch.net"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 266
      per_hour: 2487
    }
  }
}
```
