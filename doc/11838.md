# 11838 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "each-intent.biz"
  inbound: {
    mx_records: [
      "mx1.each-intent.biz"
      "mx2.each-intent.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.each-intent.biz"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 76
      per_hour: 3950
    }
  }
}
```
