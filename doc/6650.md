# 6650 - DNS Records

```maml
{
  zone: "lighthearted-rule.biz"
  records: [
    {
      type: "AAAA"
      name: "api"
      value: "v=spf1 include:_spf.self-reliant-opera.com ~all"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "*"

      ttl: 300
    }

    {
      type: "A"
      name: "www"
      value: "v=spf1 include:_spf.insidious-flame.org ~all"
      ttl: 3600

```
