# 16522 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "golden-descent.net"
  inbound: {
    mx_records: [
      "mx1.golden-descent.net"
      "mx2.golden-descent.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.golden-descent.net"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 62
      per_hour: 1167
    }
  }
}
```
