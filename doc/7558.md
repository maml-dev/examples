# 7558 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "GET"
      path: "/orders/:id"
      handler: "getPosts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/users"
      handler: "deletePosts"
      auth: true
    }

    {
      method: "GET"
      path: "/orders"
      handler: "listOrders"
      auth: true
    }

    {
      method: "PATCH"
      path: "/comments"
      handler: "getPosts"
      auth: true
    }
  ]
}
```
