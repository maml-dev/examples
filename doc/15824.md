# 15824 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "communities"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 15 # seconds
    labels: {
      env: "prod"
      region: "eu-west"
      team: "baby"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 74
    memory_threshold: 79
    latency_p99_ms: 1762
    error_rate: 0.01
    notification: {
      channel: "#oncall"
      severity: "warning"
    }
  }
}
```
