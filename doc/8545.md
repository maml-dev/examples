# 8545 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "read"
        "view_analytics"
      ]
      max_seats: 46
    }

    {
      name: "editor"
      permissions: [
        "export_data"
        "read"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "delete"
        "manage_users"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "manage_users"
        "view_analytics"
        "export_data"
      ]
      max_seats: null
    }
  ]
}
```
