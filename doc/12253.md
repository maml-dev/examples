# 12253 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "view_analytics"
        "manage_billing"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "write"
        "view_analytics"
        "manage_billing"
        "delete"
        "read"
      ]
      max_seats: 6
    }

    {
      name: "support"
      permissions: [
        "manage_billing"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "export_data"
        "manage_users"
        "manage_billing"
        "write"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "delete"
        "manage_users"
      ]
      max_seats: 1
    }
  ]
}
```
