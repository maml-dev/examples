# 14722 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "technologies"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 10 # seconds
    labels: {
      env: "staging"
      region: "us-east"
      team: "electronics"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 92
    memory_threshold: 85
    latency_p99_ms: 542
    error_rate: 0.02
    notification: {
      channel: "#ops-alerts"
      severity: "warning"
    }
  }
}
```
