# 15928 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.grown-blight.name"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 1388
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://interesting-hydrocarbon.info"
      "https://app.grubby-almighty.info"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 1829
    store: "memory"
  }
}
```
