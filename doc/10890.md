# 10890 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@lighthearted-pillbox.com"
  subject: "Debeo triduana maiores tametsi totidem."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Tracto conduco capto id deleniti sequi consuasor. Cotidie unus confero ubi demitto sodalitas rerum attonbitus. Volo quis stella viscus amplus strues voco cado trado.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Quo dicta canto via crastinus cito thalassinus coniuratio itaque. Vir cruciamentum utrum vitium aetas aptus cogo vae. Verbum pel accusamus capio arx speciosus vespillo celer ascisco demulceo.

Visit: {{url}}
"""
}
```
