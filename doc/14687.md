# 14687 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "f72ee2c5-94b9-4a17-b441-a2db665a1882"
  Accept-Language: "de-DE"
  Cache-Control: "public, max-age=86400"
  X-Powered-By: "Koa"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "tenax"
    "another one": "trans"
  }
}
```
