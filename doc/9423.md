# 9423 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "anguished-decryption.info"
  inbound: {
    mx_records: [
      "mx1.anguished-decryption.info"
      "mx2.anguished-decryption.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.anguished-decryption.info"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 186
      per_hour: 1775
    }
  }
}
```
