# 6451 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "delete"
        "write"
        "export_data"
      ]
      max_seats: 37
    }

    {
      name: "billing"
      permissions: [
        "delete"
        "manage_billing"
        "manage_users"
        "view_analytics"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "read"
        "write"
        "view_analytics"
        "delete"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "delete"
        "manage_billing"
        "write"
        "read"
        "export_data"
      ]
      max_seats: 30
    }
  ]
}
```
