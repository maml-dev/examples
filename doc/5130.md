# 5130 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.brave-epic.biz"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 2557
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://exalted-simple.com"
      "https://app.jumbo-legend.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: true
    ttl: 3484
    store: "memory"
  }
}
```
