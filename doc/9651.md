# 9651 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "export_data"
        "read"
        "manage_billing"
        "manage_users"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "manage_users"
        "delete"
        "export_data"
        "manage_billing"
        "write"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "manage_users"
        "write"
        "manage_billing"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "read"
        "write"
        "manage_users"
      ]
      max_seats: 38
    }
  ]
}
```
