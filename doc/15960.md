# 15960 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "PATCH"
      path: "/users/:id"
      handler: "listUsers"
      auth: false
    }

    {
      method: "POST"
      path: "/orders"
      handler: "createPosts"
      auth: true
    }

    {
      method: "PUT"
      path: "/posts/:id"
      handler: "createUsers"
      auth: false
    }

    {
      method: "PATCH"
      path: "/products"
      handler: "createProducts"
      auth: false
    }
  ]
}
```
