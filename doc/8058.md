# 8058 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "celebrated-antelope.net"
  records: [
    {
      type: "AAAA"
      name: "cdn"
      value: "vibrant-draft.net"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "api"
      value: "immediate-term.name"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "www"
      value: "212.251.179.24"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "api"
      value: "caring-willow.name"
      ttl: 300
    }
  ]
}
```
