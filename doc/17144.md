# 17144 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Ctrl+/"
      action: "format"
      when: "global"
    }

    {
      key: "Cmd+Shift+L"
      action: "search_project"
      when: "terminal"
    }

    {
      key: "Ctrl+/"
      action: "save"
      when: "debug"
    }
  ]
}
```
