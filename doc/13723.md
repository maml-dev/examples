# 13723 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.bitter-tabletop.info"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 4850
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://raw-range.net"
      "https://app.wide-eyed-chapel.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 1091
    store: "memory"
  }
}
```
