# 10335 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "interfaces"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "staging"
      region: "eu-west"
      team: "automotive"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 85
    memory_threshold: 77
    latency_p99_ms: 1794
    error_rate: 0.01
    notification: {
      channel: "#incidents"
      severity: "critical"
    }
  }
}
```
