# 15752 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "manage_billing"
        "delete"
        "read"
        "export_data"
      ]
      max_seats: 5
    }

    {
      name: "editor"
      permissions: [
        "write"
        "delete"
        "manage_users"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "read"
        "delete"
      ]
      max_seats: 12
    }

    {
      name: "admin"
      permissions: [
        "manage_users"
        "view_analytics"
        "delete"
      ]
      max_seats: null
    }
  ]
}
```
