# 8536 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "warm-nerve.biz"
  inbound: {
    mx_records: [
      "mx1.warm-nerve.biz"
      "mx2.warm-nerve.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.warm-nerve.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 308
      per_hour: 8888
    }
  }
}
```
