# 14939 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.hoarse-halt.org"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 1978
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://impossible-hydrolyze.com"
      "https://app.vivid-harp.org"

    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 2805
    store: "memory"
  }
}
```
