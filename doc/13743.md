# 13743 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "viewer"
      permissions: [
        "delete"
        "manage_users"
        "read"
        "write"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "manage_users"
        "export_data"
        "delete"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "manage_billing"
        "manage_users"
        "read"
        "view_analytics"
        "delete"
      ]
      max_seats: 4
    }

    {
      name: "billing"
      permissions: [
        "view_analytics"
        "delete"
        "manage_billing"
        "export_data"
      ]
      max_seats: null
    }
  ]
}
```
