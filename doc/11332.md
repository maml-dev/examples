# 11332 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.worse-icebreaker.info"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 7351
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://rewarding-kick.net"
      "https://app.parched-wheel.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 1128
    store: "redis"
  }
}
```
