# 7122 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.intrepid-mallard.com"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 8833
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://upright-legislature.info"
      "https://app.multicolored-availability.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 2561
    store: "redis"
  }
}
```
