# 8588 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@orange-teammate.info"
  subject: "Comis velit umquam."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Comprehendo arbor caries casus balbus debilito theatrum incidunt. Suscipio aegrus sordeo corrigo quae synagoga civitas voluptas. Surgo thesaurus umbra arma aegre tricesimus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Triumphus adicio beatus cubitum amaritudo cito torrens sperno tamdiu accedo. Altus undique utrum cuppedia condico caelum curiositas vociferor canto. Vestigium ventito adimpleo adsidue basium ait deleniti.

Visit: {{url}}
"""
}
```
