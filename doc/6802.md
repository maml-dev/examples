# 6802 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "rewarding-runway.biz"
  ttl: 86400 # seconds
  nameservers: [
    "ns1.lovable-lyre.info"
    "ns2.serene-fundraising.biz"
  ]

  soa_email: "admin@unrealistic-verve.name"
  refresh: 7200
  retry: 900
  expire: 604800
}
```
