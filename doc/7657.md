# 7657 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Alt+F7"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+F"
      action: "command_palette"
      when: "terminal"
    }

    {
      key: "Ctrl+/"
      action: "search_project"
      when: "debug"
    }

    {
      key: "Alt+Up"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Ctrl+D"
      action: "select_all_occurrences"
      when: "terminal"
    }

    {
      key: "Cmd+Shift+L"
      action: "debug_run"
      when: "global"
    }

    {
      key: "Alt+Up"
      action: "toggle_terminal"
      when: "editor"
    }
  ]
}
```
