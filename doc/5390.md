# 5390 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@old-fashioned-king.com"
  subject: "Theatrum taceo ascisco caelestis vester."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Arguo bardus caute accommodo velit. Victus totidem auctus amiculum. Vulticulus terreo ater convoco absque.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Laudantium cruciamentum tempus desidero. Agnitio sunt agnosco corrumpo capitulus aggero. Vis delectatio ustilo creta stultus acer.

Visit: {{url}}
"""
}
```
