# 10133 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "distinct-masterpiece.org"
  inbound: {
    mx_records: [
      "mx1.distinct-masterpiece.org"
      "mx2.distinct-masterpiece.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.distinct-masterpiece.org"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 245
      per_hour: 5816
    }
  }
}
```
