# 6487 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@optimistic-pliers.info"
  subject: "Articulus consuasor pax caterva."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Cubicularis vitae chirographum curvo corporis porro assumenda angelus qui cruentus. Validus cito centum. Tamen abeo vigor calculus patruus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Supra una tui. Aperiam somniculosus confido comis creator adiuvo crux cunabula claudeo comedo. Voluptatibus certus aureus ad cupiditas tergum voveo.

Visit: {{url}}
"""
}
```
