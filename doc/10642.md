# 10642 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Ctrl+B"
      action: "search_project"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+P"
      action: "search_project"
      when: "terminal"
    }

    {
      key: "Alt+F7"
      action: "toggle_comment"
      when: "global"
    }

    {
      key: "Alt+Up"
      action: "format"
      when: "debug"
    }

    {
      key: "Ctrl+/"
      action: "toggle_terminal"
      when: "global"
    }
  ]
}
```
