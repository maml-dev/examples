# 13958 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Cmd+K"
      action: "command_palette"
      when: "editor"
    }

    {
      key: "Alt+Up"
      action: "toggle_terminal"
      when: "editor"
    }

    {
      key: "Alt+F7"
      action: "toggle_comment"
      when: "global"
    }

    {
      key: "Ctrl+Shift+F"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Ctrl+D"
      action: "toggle_sidebar"
      when: "debug"
    }
  ]
}
```
