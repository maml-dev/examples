# 9549 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Alt+Up"
      action: "search_project"
      when: "debug"
    }

    {
      key: "Ctrl+/"
      action: "toggle_comment"
      when: "global"
    }

    {
      key: "Ctrl+B"
      action: "toggle_sidebar"
      when: "editor"
    }

    {
      key: "Ctrl+D"
      action: "select_all_occurrences"
      when: "terminal"
    }

    {
      key: "Ctrl+D"
      action: "select_all_occurrences"
      when: "debug"
    }

    {
      key: "Cmd+Shift+L"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+P"
      action: "select_all_occurrences"
      when: "terminal"
    }
  ]
}
```
