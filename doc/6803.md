# 6803 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "black-grass.com"
  ttl: 300 # seconds
  nameservers: [
    "ns1.jittery-sonar.net"
    "ns2.speedy-championship.org"
  ]

  soa_email: "admin@thin-executor.net"
  refresh: 14400
  retry: 600
  expire: 604800
}
```
