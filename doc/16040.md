# 16040 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.excitable-bump.name"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 7917
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://bulky-embarrassment.org"
      "https://app.writhing-armoire.info"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 1322
    store: "memory"
  }
}
```
