# 12559 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "view_analytics"
        "manage_users"
        "read"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "manage_billing"
        "write"
        "export_data"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "delete"
        "export_data"
        "manage_billing"
        "manage_users"
        "view_analytics"
      ]
      max_seats: 26
    }
  ]
}
```
