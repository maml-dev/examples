# 7330 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.triangular-promise.name"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 8883
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://cloudy-maestro.com"
      "https://app.low-platter.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: true
    ttl: 3286
    store: "redis"
  }
}
```
