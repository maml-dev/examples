# 15828 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "favorite-attraction.biz"
  inbound: {
    mx_records: [
      "mx1.favorite-attraction.biz"
      "mx2.favorite-attraction.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.favorite-attraction.biz"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 458
      per_hour: 5342
    }
  }
}
```
