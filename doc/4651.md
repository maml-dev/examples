# 4651 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "write"
        "view_analytics"
        "delete"
        "manage_billing"
      ]
      max_seats: 7
    }

    {
      name: "viewer"
      permissions: [
        "write"
        "export_data"
        "manage_billing"
        "read"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "export_data"
        "read"
        "manage_billing"
        "delete"
        "manage_users"
      ]
      max_seats: 47
    }
  ]
}
```
