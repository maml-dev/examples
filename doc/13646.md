# 13646 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Cmd+K"
      action: "save"
      when: "terminal"
    }

    {
      key: "Cmd+Shift+L"
      action: "format"
      when: "editor"
    }

    {
      key: "Ctrl+`"
      action: "toggle_comment"
      when: "terminal"
    }
  ]
}
```
