# 4733 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "oddball-bathhouse.info"
  inbound: {
    mx_records: [
      "mx1.oddball-bathhouse.info"
      "mx2.oddball-bathhouse.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.oddball-bathhouse.info"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 246
      per_hour: 6601
    }
  }
}
```
