# 10282 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@low-casement.name"
  subject: "Auditor valens crur reprehenderit."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Unde denuo ipsam ea vilitas adipiscor. Decipio advoco decerno sint votum tepidus supra torqueo velut. Demonstro capitulus astrum theologus verbum arcesso illo votum.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Speculum vacuus certus rerum quidem eos via sponte somniculosus deorsum. Capto denego theatrum approbo cetera cupio bestia. Explicabo deserunt cruciamentum voluptates subseco ea alioqui solium beneficium.

Visit: {{url}}
"""
}
```
