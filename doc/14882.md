# 14882 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@thorny-overheard.info"
  subject: "Triduana suasoria auctor thermae advenio trepide."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Iste apto amor. Acsi alii valeo iste uberrime vorago apostolus stabilis velum. Ultio atque corona eaque odio vitiosus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Arma debilito solitudo. Aliqua uxor antea ipsum vallum curia dolore debilito. Cupio repellat vorax speciosus comedo spes animi distinctio vesica.

Visit: {{url}}
"""
}
```
