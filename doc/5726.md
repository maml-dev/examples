# 5726 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "scared-stay.name"
  inbound: {
    mx_records: [
      "mx1.scared-stay.name"
      "mx2.scared-stay.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.scared-stay.name"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 485
      per_hour: 6643
    }
  }
}
```
