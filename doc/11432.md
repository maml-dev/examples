# 11432 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "firm-traffic.info"
  inbound: {
    mx_records: [
      "mx1.firm-traffic.info"
      "mx2.firm-traffic.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.firm-traffic.info"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 439
      per_hour: 6020
    }
  }
}
```
