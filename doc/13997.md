# 13997 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@obedient-brush.biz"
  subject: "Tener vorax peccatus ascit."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Velum calcar universe virtus ter vacuus qui amiculum denego aperiam. Vestigium ustilo fugiat consequatur averto tutis una supra desolo adeptio. Canto cibus validus unde unus aranea conforto.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Dedecor iusto vulnus bibo templum ab spero aro taedium. Natus valetudo vorago. Vaco bardus traho summisse voluptates defaeco deorsum totam cavus aetas.

Visit: {{url}}
"""
}
```
