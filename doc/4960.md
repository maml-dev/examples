# 4960 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "PATCH"
      path: "/products"
      handler: "deleteProducts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/users/:id"
      handler: "getOrders"
      auth: true
    }

    {
      method: "PATCH"
      path: "/comments"
      handler: "updateOrders"
      auth: false
    }

    {
      method: "DELETE"
      path: "/orders"
      handler: "createUsers"
      auth: false
    }

    {
      method: "POST"
      path: "/posts/:id"
      handler: "createOrders"
      auth: true
    }
  ]
}
```
