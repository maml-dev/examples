# 4435 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.second-hand-exhaust.net"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 3799
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://crushing-mainstream.com"
      "https://app.some-thongs.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 1295
    store: "redis"
  }
}
```
