# 6433 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "burdensome-cinder.net"
  inbound: {
    mx_records: [
      "mx1.burdensome-cinder.net"
      "mx2.burdensome-cinder.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.burdensome-cinder.net"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 432
      per_hour: 6870
    }
  }
}
```
