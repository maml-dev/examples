# 7923 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.stylish-netsuke.org"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 1534
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://heartfelt-edge.name"
      "https://app.sore-arcade.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: true
    ttl: 1493
    store: "memory"
  }
}
```
