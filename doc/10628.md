# 10628 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "tangible-ribbon.com"
  inbound: {
    mx_records: [
      "mx1.tangible-ribbon.com"
      "mx2.tangible-ribbon.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.tangible-ribbon.com"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 338
      per_hour: 4418
    }
  }
}
```
