# 5631 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.unkempt-numeric.net"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 3043
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://realistic-flight.com"
      "https://app.authorized-bump.info"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 3477
    store: "memory"
  }
}
```
