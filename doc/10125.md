# 10125 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "quick-maintainer.org"
  inbound: {
    mx_records: [
      "mx1.quick-maintainer.org"
      "mx2.quick-maintainer.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.quick-maintainer.org"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 77
      per_hour: 8301
    }
  }
}
```
