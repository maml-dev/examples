# 12830 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "initiatives"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 60 # seconds
    labels: {
      env: "staging"
      region: "us-east"
      team: "home"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 93
    memory_threshold: 95
    latency_p99_ms: 1513
    error_rate: 0.05
    notification: {
      channel: "#ops-alerts"
      severity: "warning"
    }
  }
}
```
