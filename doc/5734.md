# 5734 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "content"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 60 # seconds
    labels: {
      env: "prod"
      region: "eu-west"
      team: "outdoors"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 85
    memory_threshold: 85
    latency_p99_ms: 219
    error_rate: 0.01
    notification: {
      channel: "#oncall"
      severity: "warning"
    }
  }
}
```
