# 5087 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@splendid-ownership.biz"
  subject: "Color tubineus bestia audax."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Surculus assumenda alioqui antepono acidus curto comminor dedecor sonitus. Curiositas ipsum ullam decretum viduo bis sto depraedor versus. Sum suscipit expedita cattus substantia.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Acies porro cervus varius delego canto. Molestias communis adhaero cognatus iure demum provident clementia. Audio dedecor a.

Visit: {{url}}
"""
}
```
