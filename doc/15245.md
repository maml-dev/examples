# 15245 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Cmd+K"
      action: "toggle_terminal"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+F"
      action: "save"
      when: "terminal"
    }

    {
      key: "Alt+F7"
      action: "find_references"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+P"
      action: "find_references"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+P"
      action: "toggle_terminal"
      when: "global"
    }
  ]
}
```
