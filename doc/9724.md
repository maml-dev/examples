# 9724 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "rewarding-coil.com"
  inbound: {
    mx_records: [
      "mx1.rewarding-coil.com"
      "mx2.rewarding-coil.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.rewarding-coil.com"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 272
      per_hour: 1996
    }
  }
}
```
