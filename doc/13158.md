# 13158 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "PATCH"
      path: "/products"
      handler: "listUsers"
      auth: false
    }

    {
      method: "POST"
      path: "/comments"
      handler: "deletePosts"
      auth: true
    }

    {
      method: "PUT"
      path: "/comments/:id"
      handler: "listUsers"
      auth: false
    }
  ]
}
```
