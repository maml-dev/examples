# 8044 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "delete"
        "write"
        "export_data"
        "read"
        "manage_billing"
      ]
      max_seats: 1
    }

    {
      name: "admin"
      permissions: [
        "delete"
        "manage_users"
        "manage_billing"
        "write"
      ]
      max_seats: 7
    }

    {
      name: "viewer"
      permissions: [
        "delete"
        "manage_users"
        "write"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "write"
        "export_data"
      ]
      max_seats: 41
    }
  ]
}
```
