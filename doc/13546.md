# 13546 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "scented-castanet.name"
  records: [
    {
      type: "TXT"
      name: "*"
      value: "apt-kick.name"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "cdn"
      value: "v=spf1 include:_spf.finished-piglet.com ~all"
      ttl: 300
    }

    {
      type: "CNAME"
      name: "staging"
      value: "49.214.53.230"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "mail"
      value: "v=spf1 include:_spf.mean-responsibility.info ~all"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "mail"
      value: "well-lit-appliance.com"
      ttl: 86400
    }

    {
      type: "A"
      name: "www"
      value: "v=spf1 include:_spf.frizzy-exploration.net ~all"
      ttl: 3600
    }
  ]
}
```
