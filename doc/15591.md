# 15591 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@upset-bookend.name"
  subject: "Cicuta odit tempora nam cuppedia absconditus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Odio super demens alter. Tracto placeat arbitro tandem dedico demitto pauci vestrum vacuus. Comis vel undique deserunt voluptatem eos apud varius.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Conqueror commodo tenax vester coepi. Cotidie ciminatio tam audeo avarus vulnero ater totidem. Cerno balbus causa temperantia baiulus vereor venustas vilis censura.

Visit: {{url}}
"""
}
```
