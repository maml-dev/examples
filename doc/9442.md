# 9442 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "manage_users"
        "write"
        "export_data"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "export_data"
        "view_analytics"
        "write"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "write"
        "manage_billing"
        "delete"
        "view_analytics"
        "read"
      ]
      max_seats: null
    }
  ]
}
```
