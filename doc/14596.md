# 14596 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@complicated-bonnet.biz"
  subject: "Textor clamo ventus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Crebro dolorem apto cruciamentum. Argentum adhaero placeat creber absorbeo utroque thalassinus. Pecto surculus expedita adimpleo ulterius.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Campana spiculum adeo titulus thermae. Curvo paulatim tondeo carcer suspendo colligo turpis. Subnecto corrigo somnus textilis copia toties cavus.

Visit: {{url}}
"""
}
```
