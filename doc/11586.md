# 11586 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@hasty-reporter.info"
  subject: "Volup nesciunt tum alienus cuppedia."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Stillicidium audacia demum delectatio. Tolero supplanto cimentarius. Thema sollicito vicinus curso amor tonsor crastinus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Deprecator subito quas tertius aetas supellex supra cuius. Earum crepusculum quisquam appello adstringo turbo tametsi bos aestus. Conforto officia suspendo ducimus decor depopulo volva absum.

Visit: {{url}}
"""
}
```
