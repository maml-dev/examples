# 5343 - Font Stack

Typography font family definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  fonts: [
    {
      family: "Noto Sans"
      category: "display"
      weights: [
        300
        400
        600
      ]
      variable: true
    }

      category: "sans-serif"

        200
        600
      ]
      variable: false
    }

    {
      family: "Inter"
      category: "monospace"
      weights: [
        100
        800
      ]

    }
  ]
}
```
