# 17143 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "write"
        "export_data"
        "view_analytics"
      ]
      max_seats: 50
    }

    {
      name: "viewer"
      permissions: [
        "delete"
        "export_data"
        "manage_billing"
        "read"
      ]
      max_seats: 18
    }

    {
      name: "admin"
      permissions: [
        "manage_billing"
        "delete"
        "view_analytics"
      ]
      max_seats: 27
    }
  ]
}
```
