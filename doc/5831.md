# 5831 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.spanish-pneumonia.net"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 516
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://enchanting-deed.org"
      "https://app.that-topsail.info"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 307
    store: "memory"
  }
}
```
