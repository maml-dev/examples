# 6892 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@impassioned-sunbeam.info"
  subject: "Bellicus spero curo substantia accommodo tantum."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Apto texo stillicidium ver labore. Bonus versus deprecator sum cinis. Cetera distinctio solium claudeo.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Soluta defaeco vae absque creta cupiditate compono vulgivagus sperno cogo. Vita libero tunc clibanus. Ustilo corrupti textilis officia adfectus.

Visit: {{url}}
"""
}
```
