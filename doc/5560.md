# 5560 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "GET"
      path: "/products/:id"
      handler: "deleteProducts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/orders"
      handler: "listProducts"
      auth: false
    }

    {
      method: "POST"
      path: "/users"
      handler: "getUsers"
      auth: false
    }

    {
      method: "POST"
      path: "/posts/:id"
      handler: "listProducts"
      auth: false
    }

    {
      method: "PUT"
      path: "/comments"
      handler: "listPosts"
      auth: false
    }
  ]
}
```
