# 16342 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "PATCH"
      path: "/posts/:id"
      handler: "getUsers"
      auth: false
    }

    {
      method: "PUT"
      path: "/users/:id"
      handler: "getUsers"
      auth: true
    }

    {
      method: "POST"
      path: "/comments/:id"
      handler: "getUsers"
      auth: true
    }

    {
      method: "DELETE"
      path: "/posts"
      handler: "updateProducts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/posts"
      handler: "createUsers"
      auth: true
    }
  ]
}
```
