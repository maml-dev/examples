# 4734 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.scared-bell.org"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 8134
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://woeful-nephew.name"
      "https://app.wise-nerve.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 2853
    store: "redis"
  }
}
```
