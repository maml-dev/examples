# 9043 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "DELETE"
      path: "/comments/:id"
      handler: "listOrders"
      auth: true
    }

    {
      method: "PATCH"
      path: "/users/:id"
      handler: "getUsers"
      auth: false
    }

    {
      method: "PUT"
      path: "/orders/:id"
      handler: "deletePosts"
      auth: false
    }
  ]
}
```
