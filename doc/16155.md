# 16155 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Ctrl+/"
      action: "save"
      when: "terminal"
    }

    {
      key: "Cmd+Shift+L"
      action: "search_project"
      when: "editor"
    }

    {
      key: "Alt+F7"
      action: "debug_run"
      when: "global"
    }

    {
      key: "Ctrl+B"
      action: "toggle_comment"
      when: "debug"
    }
  ]
}
```
