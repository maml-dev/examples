# 14452 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Ctrl+B"
      action: "toggle_terminal"
      when: "global"
    }

    {
      key: "Ctrl+`"
      action: "command_palette"
      when: "global"
    }

    {
      key: "Alt+Up"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "Ctrl+D"
      action: "toggle_comment"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+F"
      action: "find_references"
      when: "debug"
    }
  ]
}
```
