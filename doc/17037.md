# 17037 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "solutions"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 60 # seconds
    labels: {
      env: "prod"
      region: "us-east"
      team: "clothing"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 81
    memory_threshold: 85
    latency_p99_ms: 1795
    error_rate: 0.02
    notification: {
      channel: "#oncall"
      severity: "critical"
    }
  }
}
```
