# 12245 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Ctrl+`"
      action: "search_project"
      when: "terminal"
    }

    {
      key: "Ctrl+S"
      action: "toggle_terminal"
      when: "debug"
    }

    {
      key: "Ctrl+S"
      action: "format"
      when: "terminal"
    }

    {
      key: "Cmd+Shift+L"
      action: "find_references"
      when: "editor"
    }

    {
      key: "Ctrl+S"
      action: "find_references"
      when: "editor"
    }
  ]
}
```
