# 14060 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Ctrl+`"
      action: "debug_run"
      when: "global"
    }

    {
      key: "Ctrl+D"
      action: "debug_run"
      when: "editor"
    }

    {
      key: "Ctrl+S"
      action: "select_all_occurrences"
      when: "debug"
    }
  ]
}
```
