# 7543 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Ctrl+B"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Ctrl+D"
      action: "toggle_comment"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+F"
      action: "command_palette"
      when: "editor"
    }

    {
      key: "Ctrl+/"
      action: "save"
      when: "terminal"
    }
  ]
}
```
