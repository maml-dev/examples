# 13549 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "export_data"
        "write"
      ]
      max_seats: 46
    }

    {
      name: "viewer"
      permissions: [
        "delete"
        "export_data"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "view_analytics"
        "manage_billing"
        "write"
        "manage_users"
      ]
      max_seats: 3
    }

    {
      name: "moderator"
      permissions: [
        "export_data"
        "manage_users"
        "write"
        "view_analytics"
        "delete"
      ]
      max_seats: 4
    }

    {
      name: "editor"
      permissions: [
        "read"
        "manage_users"
        "view_analytics"
        "delete"
      ]
      max_seats: 26
    }
  ]
}
```
