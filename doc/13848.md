# 13848 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "delete"
        "export_data"
      ]
      max_seats: 36
    }

    {
      name: "billing"
      permissions: [
        "view_analytics"
        "manage_billing"
      ]
      max_seats: 32
    }

    {
      name: "moderator"
      permissions: [
        "view_analytics"
        "read"
      ]
      max_seats: 6
    }

    {
      name: "editor"
      permissions: [
        "write"
        "export_data"
        "manage_users"
      ]
      max_seats: 14
    }
  ]
}
```
