# 14693 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "3b01e473-dfbf-4ca5-a47b-07b5a710b4cd"
  Accept-Language: "en-US"
  Cache-Control: "no-cache"
  X-Powered-By: "Fastify"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "crastinus"
    "another one": "tricesimus"
  }
}
```
