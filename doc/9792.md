# 9792 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@impartial-ectoderm.com"
  subject: "Tonsor ipsum aufero appono crepusculum."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Pauci denuo crustulum tabula cohors rerum alias admiratio curatio. Appello tunc argentum quia corporis conturbo ducimus cattus cedo ventosus. Adulatio sint vulariter.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Perferendis sonitus vulariter ipsam angelus omnis terra cometes compello cultellus. Audacia sto praesentium carpo sum annus. Chirographum deludo vorax comedo enim umquam id.

Visit: {{url}}
"""
}
```
