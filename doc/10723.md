# 10723 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "informal-responsibility.biz"
  inbound: {
    mx_records: [
      "mx1.informal-responsibility.biz"
      "mx2.informal-responsibility.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.informal-responsibility.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 249
      per_hour: 5103
    }
  }
}
```
