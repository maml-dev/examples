# 8247 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "sentimental-fold.name"
  records: [
    {
      type: "TXT"
      name: "cdn"
      value: "229.17.92.189"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "cdn"
      value: "166.94.122.206"
      ttl: 3600
    }

    {
      type: "NS"
      name: "*"
      value: "192.86.229.205"
      ttl: 300
    }

    {
      type: "MX"
      name: "@"
      value: "242.52.143.230"
      ttl: 300
    }

    {
      type: "MX"
      name: "api"
      value: "v=spf1 include:_spf.spirited-guide.name ~all"
      ttl: 300
    }

    {
      type: "NS"
      name: "cdn"
      value: "72.76.91.101"
      ttl: 300
    }
  ]
}
```
