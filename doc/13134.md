# 13134 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "edible-flint.net"
  inbound: {
    mx_records: [
      "mx1.edible-flint.net"
      "mx2.edible-flint.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.edible-flint.net"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 148
      per_hour: 9583
    }
  }
}
```
