# 6446 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "POST"
      path: "/users/:id"
      handler: "createOrders"
      auth: false
    }

    {
      method: "POST"
      path: "/posts"
      handler: "getProducts"
      auth: false
    }

    {
      method: "GET"
      path: "/orders/:id"
      handler: "listPosts"
      auth: true
    }

    {
      method: "PUT"
      path: "/posts"
      handler: "createOrders"
      auth: true
    }
  ]
}
```
