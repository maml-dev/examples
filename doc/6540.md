# 6540 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.clumsy-ghost.com"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 2100
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://perfumed-bungalow.name"
      "https://app.granular-hovel.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 1385
    store: "redis"
  }
}
```
