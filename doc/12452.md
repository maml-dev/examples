# 12452 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "glaring-fax.com"
  records: [
    {
      type: "A"
      name: "cdn"
      value: "edible-piglet.name"
      ttl: 86400
    }

    {
      type: "A"
      name: "cdn"
      value: "v=spf1 include:_spf.chubby-case.com ~all"
      ttl: 86400
    }

    {
      type: "MX"
      name: "*"
      value: "v=spf1 include:_spf.spirited-dream.info ~all"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "*"
      value: "161.46.209.145"
      ttl: 300
    }

    {
      type: "TXT"
      name: "cdn"
      value: "140.124.209.183"
      ttl: 300
    }

    {
      type: "TXT"
      name: "@"
      value: "v=spf1 include:_spf.agitated-mousse.org ~all"
      ttl: 300
    }
  ]
}
```
