# 5111 - Locale Config

```maml
{
  language: "zh"
  country: "ER"
  timezone: "America/Mexico_City"
  currency: "MNT"

  date_format: "DD/MM/YYYY"
  time_format: "24h"
  first_day_of_week: "monday"
  decimal_separator: "."
}
```
