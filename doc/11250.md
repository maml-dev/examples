# 11250 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Alt+Up"
      action: "find_references"
      when: "debug"
    }

    {
      key: "Ctrl+S"
      action: "toggle_terminal"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+P"
      action: "toggle_terminal"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+F"
      action: "save"
      when: "global"
    }
  ]
}
```
