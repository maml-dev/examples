# 10136 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.beloved-cantaloupe.net"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 1616
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://firm-characterization.com"
      "https://app.mysterious-warming.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: true
    ttl: 1184
    store: "memory"
  }
}
```
