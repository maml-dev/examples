# 4955 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "view_analytics"
        "delete"
        "read"
        "manage_users"
        "write"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "delete"
        "export_data"
      ]
      max_seats: 9
    }

    {
      name: "billing"
      permissions: [
        "manage_users"
        "view_analytics"
        "manage_billing"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "manage_users"
        "view_analytics"
        "export_data"
        "read"
        "write"
      ]
      max_seats: null
    }
  ]
}
```
