# 15638 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "fuzzy-coil.info"
  inbound: {
    mx_records: [
      "mx1.fuzzy-coil.info"
      "mx2.fuzzy-coil.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.fuzzy-coil.info"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 331
      per_hour: 6869
    }
  }
}
```
