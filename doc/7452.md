# 7452 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+S"
      action: "toggle_comment"
      when: "terminal"
    }

    {
      key: "Cmd+Shift+L"
      action: "toggle_terminal"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+F"
      action: "command_palette"
      when: "editor"
    }

    {
      key: "Alt+F7"
      action: "select_all_occurrences"
      when: "global"
    }

    {
      key: "Ctrl+Shift+F"
      action: "select_all_occurrences"
      when: "debug"
    }

    {
      key: "Alt+Up"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "F5"
      action: "search_project"
      when: "editor"
    }
  ]
}
```
