# 7639 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.whirlwind-teammate.biz"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 3426
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://hurtful-cd.net"
      "https://app.tender-other.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 2288
    store: "redis"
  }
}
```
