# 6250 - Font Stack

Typography font family definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  fonts: [
    {
      family: "Noto Sans"
      category: "display"
      weights: [
        100
        900
      ]
      variable: true
    }

    {
      family: "Source Sans Pro"
      category: "display"
      weights: [
        800
        900
      ]
      variable: true
    }

    {
      family: "Source Sans Pro"
      category: "monospace"
      weights: [
        100
        200
        500
      ]
      variable: false
    }

    {
      family: "Noto Sans"
      category: "display"
      weights: [
        400
        900
      ]
      variable: false
    }
  ]
}
```
