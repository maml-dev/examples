# 7838 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "sinful-hello.biz"
  inbound: {
    mx_records: [
      "mx1.sinful-hello.biz"
      "mx2.sinful-hello.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.sinful-hello.biz"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 355
      per_hour: 4481
    }
  }
}
```
