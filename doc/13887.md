# 13887 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@oval-forage.name"
  subject: "Accendo cuius verumtamen acervus beneficium hic."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Cervus turpis aut bos magni vestrum quod. Comitatus audio tremo tendo ea currus. Cuppedia sint cum venia concedo depopulo.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Cenaculum explicabo crur caste incidunt subvenio varietas placeat. Aestivus deinde titulus bellicus. Aufero speculum adopto temporibus sonitus conculco.

Visit: {{url}}
"""
}
```
