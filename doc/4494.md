# 4494 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@whirlwind-membership.name"
  subject: "Somnus venustas sequi tergo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Aureus tondeo inflammatio corrupti tripudio nobis accusamus. Aqua tabesco defendo. Adficio bis abscido acerbitas verbum harum suasoria attollo ventito asper.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Ocer circumvenio aurum vito cubitum. Cupiditate caput necessitatibus sapiente cito attonbitus deripio uterque. Voluptate sono admitto xiphias cilicium tum caterva solitudo.

Visit: {{url}}
"""
}
```
