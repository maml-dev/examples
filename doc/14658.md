# 14658 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "view_analytics"
        "write"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "delete"
        "export_data"
      ]
      max_seats: 5
    }

    {
      name: "editor"
      permissions: [
        "manage_users"
        "read"
        "manage_billing"
        "delete"
      ]
      max_seats: 25
    }

    {
      name: "support"
      permissions: [
        "write"
        "read"
      ]
      max_seats: 9
    }

    {
      name: "billing"
      permissions: [
        "delete"
        "manage_users"
        "read"
        "manage_billing"
      ]
      max_seats: 11
    }
  ]
}
```
