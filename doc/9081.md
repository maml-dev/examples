# 9081 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@afraid-encouragement.name"
  subject: "Cunctatio trepide occaecati summopere curvo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Tener tabula degenero denique animus patrocinor capillus convoco tamquam vomito. Suasoria deludo tonsor abeo. Sequi caute sui.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Vinitor id arca. Arca ascit tergo desipio thymum ocer usitas adfero. Demo voluptatibus talio verecundia ex pecco communis pel.

Visit: {{url}}
"""
}
```
