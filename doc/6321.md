# 6321 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "systems"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 60 # seconds
    labels: {
      env: "prod"
      region: "eu-west"
      team: "shoes"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 73
    memory_threshold: 76
    latency_p99_ms: 1876
    error_rate: 0.05
    notification: {
      channel: "#oncall"
      severity: "critical"
    }
  }
}
```
