# 12360 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "manage_users"
        "write"
        "read"
        "delete"
        "view_analytics"
      ]
      max_seats: 47
    }

    {
      name: "support"
      permissions: [
        "manage_billing"
        "read"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "manage_users"
        "view_analytics"
        "write"
        "delete"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "view_analytics"
        "delete"
      ]
      max_seats: null
    }
  ]
}
```
