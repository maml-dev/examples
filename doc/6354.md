# 6354 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "manage_billing"
        "delete"
        "read"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "manage_billing"
        "write"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "manage_users"
        "manage_billing"
        "view_analytics"
        "export_data"
        "read"
      ]
      max_seats: 30
    }

    {
      name: "support"
      permissions: [
        "manage_billing"
        "view_analytics"
        "write"
        "delete"
        "manage_users"
      ]
      max_seats: 34
    }
  ]
}
```
