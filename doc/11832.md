# 11832 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "comparison-worker"
    namespace: "default"
    labels: {
      app: "swim"
      tier: "backend"
    }
  }

  # Deployment spec
  spec: {
    replicas: 5
    container: {
      image: "formation:3.19.4"
      port: 8000
      resources: {
        cpu_limit: "1000m"
        memory_limit: "256Mi"
      }
    }

    health_check: {
      path: "/health"
      interval: 30
      timeout: 10
    }
  }
}
```
