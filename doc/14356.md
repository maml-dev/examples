# 14356 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "GET"
      path: "/products"
      handler: "createOrders"
      auth: true
    }

    {
      method: "PATCH"
      path: "/posts"
      handler: "updatePosts"
      auth: false
    }

    {
      method: "GET"
      path: "/orders"
      handler: "listOrders"
      auth: false
    }

    {
      method: "POST"
      path: "/products"
      handler: "updateUsers"
      auth: false
    }
  ]
}
```
