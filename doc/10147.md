# 10147 - Environment Vars

Environment variable definitions. This is an example of a [MAML](https://maml.dev) document.

  variables: [
    {
      name: "DATABASE_URL"

      default: null

      name: "SECRET_KEY"
      required: true
      secret: false
      default: null
    }

    {
      name: "GITHUB_TOKEN"
      required: false

      default: null
    }

    {
      name: "AWS_ACCESS_KEY"
      required: true

      default: "astrum"
    }
  ]
}
