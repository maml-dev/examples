# 11324 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "catalyst-worker"
    namespace: "default"
    labels: {
      app: "molasses"
      tier: "data"
    }
  }

  # Deployment spec
  spec: {
    replicas: 3
    container: {
      image: "makeover:4.14.2"
      port: 9090
      resources: {
        cpu_limit: "250m"
        memory_limit: "512Mi"
      }
    }

    health_check: {
      path: "/healthz"
      interval: 10
      timeout: 5
    }
  }
}
```
