# 16648 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "manage_billing"
        "delete"
        "write"
      ]
      max_seats: 38
    }

    {
      name: "admin"
      permissions: [
        "write"
        "export_data"
      ]
      max_seats: 8
    }

    {
      name: "moderator"
      permissions: [
        "export_data"
        "view_analytics"
        "delete"
        "manage_users"
      ]
      max_seats: 50
    }
  ]
}
```
