# 10055 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+S"
      action: "command_palette"
      when: "debug"
    }

    {
      key: "Cmd+K"
      action: "save"
      when: "debug"
    }

    {
      key: "F5"
      action: "toggle_sidebar"
      when: "debug"
    }

    {
      key: "F5"
      action: "command_palette"
      when: "debug"
    }

    {
      key: "Alt+Up"
      action: "save"
      when: "global"
    }

    {
      key: "Ctrl+Shift+F"
      action: "toggle_terminal"
      when: "debug"
    }

    {
      key: "Ctrl+S"
      action: "format"
      when: "terminal"
    }
  ]
}
```
