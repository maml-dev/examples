# 15022 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.expensive-gym.name"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 3045
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://clumsy-papa.info"
      "https://app.crafty-legging.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 629
    store: "redis"
  }
}
```
