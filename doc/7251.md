# 7251 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "delete"
        "export_data"
        "read"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "delete"
        "write"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "read"
        "manage_billing"
        "manage_users"
        "write"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "manage_users"
        "delete"
        "write"
      ]
      max_seats: 49
    }
  ]
}
```
