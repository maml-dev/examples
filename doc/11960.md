# 11960 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{

  records: [
    {
      type: "NS"
      name: "www"
      value: "118.214.167.133"
      ttl: 300

      type: "NS"
      name: "cdn"
      value: "v=spf1 include:_spf.trusting-scaffold.org ~all"
      ttl: 3600
    }

    {

      name: "mail"

      ttl: 86400

      type: "MX"
      name: "@"

      ttl: 86400

    {
      type: "A"
      name: "mail"
```
