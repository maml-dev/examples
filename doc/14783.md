# 14783 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "fa484478-bbdc-4d74-a212-197f563b4e0f"
  Accept-Language: "de-DE"
  Cache-Control: "no-cache"
  X-Powered-By: "Koa"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "defero"
    "another one": "spoliatio"
  }
}
```
