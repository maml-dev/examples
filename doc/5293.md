# 5293 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@grimy-mantua.name"
  subject: "Abscido officiis testimonium basium odit totus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Temeritas usque cognatus id curriculum cuppedia canonicus attollo. Omnis depereo verbum arma tero. Adsidue apparatus vae tabula supra quia necessitatibus amiculum utpote turpis.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Cornu claro corrigo comminor terga vilis aegrus cohors vespillo. Tergum vilis supplanto colo. Comes curia tabernus adeptio illo tergum teneo.

Visit: {{url}}
"""
}
```
