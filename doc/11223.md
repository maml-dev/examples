# 11223 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.black-and-white-chairperson.name"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 2432
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://burly-hydrant.name"
      "https://app.vague-deduction.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 3366
    store: "redis"
  }
}
```
