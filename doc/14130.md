# 14130 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.each-middle.info"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 3440
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://tattered-bathhouse.name"
      "https://app.idealistic-harp.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 1126
    store: "memory"
  }
}
```
