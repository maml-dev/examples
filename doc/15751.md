# 15751 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "impish-government.info"
  records: [
    {
      type: "AAAA"
      name: "staging"
      value: "male-papa.name"
      ttl: 300
    }

    {
      type: "NS"
      name: "www"
      value: "impish-fencing.biz"
      ttl: 3600
    }

    {
      type: "A"
      name: "staging"
      value: "126.230.1.196"
      ttl: 3600
    }

    {
      type: "MX"
      name: "*"
      value: "outlandish-giant.net"
      ttl: 300
    }

    {
      type: "NS"
      name: "@"
      value: "v=spf1 include:_spf.spherical-stay.info ~all"
      ttl: 3600
    }
  ]
}
```
