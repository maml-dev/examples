# 13551 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "DELETE"
      path: "/posts/:id"
      handler: "deleteOrders"
      auth: false
    }

    {
      method: "PUT"
      path: "/orders"
      handler: "getOrders"
      auth: true
    }

    {
      method: "PUT"
      path: "/posts/:id"
      handler: "listOrders"
      auth: false
    }

    {
      method: "DELETE"
      path: "/posts"
      handler: "updateOrders"
      auth: true
    }

    {
      method: "PUT"
      path: "/users"
      handler: "deleteUsers"
      auth: false
    }
  ]
}
```
