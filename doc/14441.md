# 14441 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "POST"
      path: "/users/:id"
      handler: "getUsers"
      auth: true
    }

    {
      method: "PUT"
      path: "/products"
      handler: "getPosts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/comments/:id"
      handler: "deleteProducts"
      auth: false
    }

    {
      method: "PUT"
      path: "/products"
      handler: "createProducts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/posts"
      handler: "createPosts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/orders"
      handler: "getOrders"
      auth: true
    }
  ]
}
```
