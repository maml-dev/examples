# 13589 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@apprehensive-finger.net"
  subject: "Dignissimos templum dedico."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Vix itaque curvo blanditiis. Comparo substantia comis acer aut vindico recusandae somniculosus. Corona venustas angulus degusto comedo.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Tibi cotidie aptus celo facere acerbitas tres. Beneficium velut thesis. Attonbitus dicta arto verecundia universe stultus adipisci.

Visit: {{url}}
"""
}
```
