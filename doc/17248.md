# 17248 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "DELETE"
      path: "/users"
      handler: "listUsers"
      auth: false
    }

    {
      method: "POST"
      path: "/orders/:id"
      handler: "updateUsers"
      auth: true
    }

    {
      method: "DELETE"
      path: "/orders"
      handler: "deleteOrders"
      auth: false
    }

    {
      method: "GET"
      path: "/users"
      handler: "listOrders"
      auth: false
    }

    {
      method: "PUT"
      path: "/users"
      handler: "createPosts"
      auth: true
    }

    {
      method: "PUT"
      path: "/orders/:id"
      handler: "getProducts"
      auth: false
    }
  ]
}
```
