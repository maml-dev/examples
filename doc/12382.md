# 12382 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@oval-seal.com"
  subject: "Vereor cena commodo derideo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Umbra succedo caritas toties aer vorago virga cogito. Angulus abduco adfero argentum territo absque cedo suspendo. Avaritia sit celo comptus tergeo vacuus defero ustulo cenaculum suscipit.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Caelestis confido constans cupiditas spectaculum ambitus. Debeo aer libero cupiditate absconditus canonicus reprehenderit claro commodi abutor. Convoco uter repellendus umbra adipiscor statim statim similique alter.

Visit: {{url}}
"""
}
```
