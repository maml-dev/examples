# 9584 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "fdfc0671-15c2-4f17-963e-49c6e84389c9"
  Accept-Language: "fr-FR"
  Cache-Control: "public, max-age=86400"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "careo"
    "another one": "clamo"
  }
}
```
