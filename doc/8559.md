# 8559 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "wicked-leading.info"
  records: [
    {
      type: "A"
      name: "@"
      value: "powerful-hexagon.name"
      ttl: 86400
    }

    {
      type: "A"
      name: "api"
      value: "unwieldy-gastropod.org"
      ttl: 86400
    }

    {
      type: "CNAME"
      name: "@"
      value: "v=spf1 include:_spf.medium-knickers.name ~all"
      ttl: 3600
    }

    {
      type: "NS"
      name: "www"
      value: "unfinished-dulcimer.org"
      ttl: 86400
    }

    {
      type: "CNAME"
      name: "staging"
      value: "peppery-hippodrome.info"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "*"
      value: "icy-bin.org"
      ttl: 3600
    }
  ]
}
```
