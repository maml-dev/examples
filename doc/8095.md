# 8095 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@agile-mechanic.org"
  subject: "Aperiam vester circumvenio nobis dolore."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Infit perferendis degusto conitor arguo voluptatum. Cenaculum accusator textor acidus soluta auditor. Subito solium sui talio spero carmen fugiat.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Ambulo hic totidem tendo ventito consequuntur uberrime auditor accedo. Complectus numquam uter clarus cibo suspendo urbanus dapifer vespillo strues. Aspernatur tutamen vestigium arto quasi curtus annus conduco.

Visit: {{url}}
"""
}
```
