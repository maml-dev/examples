# 11954 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "memorable-instructor.org"
  records: [
    {
      type: "CNAME"
      name: "*"
      value: "discrete-mixture.info"
      ttl: 3600
    }

    {
      type: "NS"
      name: "staging"
      value: "forsaken-cycle.com"
      ttl: 86400
    }

    {
      type: "TXT"
      name: "*"
      value: "flashy-pear.org"
      ttl: 3600
    }

    {
      type: "NS"
      name: "*"
      value: "52.243.60.230"
      ttl: 86400
    }
  ]
}
```
