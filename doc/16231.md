# 16231 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.grumpy-marathon.name"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 6955
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://confused-caption.name"
      "https://app.elliptical-piglet.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 3013
    store: "memory"
  }
}
```
