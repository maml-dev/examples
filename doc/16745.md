# 16745 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "POST"
      path: "/products/:id"
      handler: "deleteUsers"
      auth: true
    }

    {
      method: "POST"
      path: "/products"
      handler: "updateProducts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/posts"
      handler: "listUsers"
      auth: true
    }

    {
      method: "GET"
      path: "/users/:id"
      handler: "updateOrders"
      auth: true
    }

    {
      method: "PUT"
      path: "/products/:id"
      handler: "deleteOrders"
      auth: false
    }
  ]
}
```
