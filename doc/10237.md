# 10237 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.stable-longboat.com"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 3106
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://golden-muscat.com"
      "https://app.light-account.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 2460
    store: "memory"
  }
}
```
