# 16652 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "export_data"
        "manage_billing"
        "write"
      ]
      max_seats: 43
    }

    {
      name: "admin"
      permissions: [
        "manage_billing"
        "read"
        "view_analytics"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "view_analytics"
        "manage_billing"
        "write"
      ]
      max_seats: 48
    }
  ]
}
```
