# 13422 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "applications"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "prod"
      region: "eu-west"
      team: "beauty"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 86
    memory_threshold: 89
    latency_p99_ms: 1439
    error_rate: 0.05
    notification: {
      channel: "#oncall"
      severity: "warning"
    }
  }
}
```
