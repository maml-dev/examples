# 16349 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "delete"
        "view_analytics"
        "manage_billing"
        "manage_users"
        "read"
      ]
      max_seats: 38
    }

    {
      name: "billing"
      permissions: [
        "view_analytics"
        "delete"
        "export_data"
        "read"
        "manage_billing"
      ]
      max_seats: 27
    }

    {
      name: "admin"
      permissions: [
        "delete"
        "manage_billing"
        "read"
        "view_analytics"
      ]
      max_seats: null
    }
  ]
}
```
