# 6755 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "incomplete-rubric.name"
  records: [
    {
      type: "AAAA"
      name: "*"
      value: "189.148.183.38"
      ttl: 3600
    }

    {
      type: "MX"
      name: "www"
      value: "voluminous-haircut.name"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "www"
      value: "dazzling-teriyaki.net"
      ttl: 86400
    }

    {
      type: "A"
      name: "@"
      value: "remorseful-obedience.biz"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "staging"
      value: "nutritious-deduction.info"
      ttl: 86400
    }

    {
      type: "CNAME"
      name: "mail"
      value: "v=spf1 include:_spf.thorny-department.name ~all"
      ttl: 86400
    }
  ]
}
```
