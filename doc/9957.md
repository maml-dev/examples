# 9957 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "giving-newsstand.com"
  records: [
    {
      type: "AAAA"
      name: "cdn"
      value: "43.147.189.108"
      ttl: 300
    }

    {
      type: "A"
      name: "*"
      value: "v=spf1 include:_spf.ugly-tune-up.net ~all"
      ttl: 86400
    }

    {
      type: "NS"
      name: "www"
      value: "v=spf1 include:_spf.alienated-fishery.net ~all"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "www"
      value: "v=spf1 include:_spf.long-term-puppet.biz ~all"
      ttl: 86400
    }
  ]
}
```
