# 11601 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "worldly-tentacle.org"
  ttl: 300 # seconds
  nameservers: [
    "ns1.shy-crocodile.org"
    "ns2.electric-loaf.com"
  ]

  soa_email: "admin@productive-velocity.biz"
  refresh: 3600
  retry: 600
  expire: 604800
}
```
