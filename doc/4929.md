# 4929 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "partnerships"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "prod"
      region: "us-east"
      team: "music"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 79
    memory_threshold: 88
    latency_p99_ms: 698
    error_rate: 0.05
    notification: {
      channel: "#incidents"
      severity: "critical"
    }
  }
}
```
