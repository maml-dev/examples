# 11202 - Linter Config

Code linter rule configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  parser: "espree"
  env: "es2024"
  indent: 4
  semicolons: true
  quotes: "double"

  # Formatting
  max_line_length: 120
  trailing_comma: "all"
  no_unused_vars: true # error
  no_console: true # warn
}
```
