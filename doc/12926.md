# 12926 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.noxious-sightseeing.com"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 2185
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://teeming-pressure.com"
      "https://app.sizzling-captain.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 1762
    store: "memory"
  }
}
```
