# 6937 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.grumpy-king.biz"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 8943
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://oval-scale.com"
      "https://app.surprised-sushi.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 3486
    store: "memory"
  }
}
```
