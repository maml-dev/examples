# 8801 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "plain-responsibility.org"
  ttl: 86400 # seconds
  nameservers: [
    "ns1.ideal-kiss.net"
    "ns2.pleasing-academics.org"
  ]

  soa_email: "admin@watery-e-mail.org"
  refresh: 3600
  retry: 600
  expire: 1209600
}
```
