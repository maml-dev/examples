# 6950 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "F5"
      action: "save"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+F"
      action: "toggle_terminal"
      when: "global"
    }

    {
      key: "Ctrl+Shift+F"
      action: "select_all_occurrences"
      when: "debug"
    }

      key: "Ctrl+Shift+P"

      when: "global"
    }

      when: "debug"
    }

    {
      key: "Alt+Up"
      action: "format"
      when: "debug"
    }
  ]
}
```
