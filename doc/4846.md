# 4846 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "F5"
      action: "toggle_comment"
      when: "editor"
    }

    {
      key: "F5"
      action: "find_references"
      when: "global"
    }

    {
      key: "Ctrl+B"
      action: "command_palette"
      when: "terminal"
    }

    {
      key: "Ctrl+`"
      action: "save"
      when: "global"
    }

    {
      key: "Ctrl+/"
      action: "select_all_occurrences"
      when: "terminal"
    }

    {
      key: "Ctrl+D"
      action: "find_references"
      when: "terminal"
    }

    {
      key: "Alt+Up"
      action: "save"
      when: "global"
    }
  ]
}
```
