# 14150 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Alt+Up"
      action: "save"
      when: "editor"
    }

    {
      key: "Cmd+K"
      action: "toggle_comment"
      when: "terminal"
    }

    {
      key: "Ctrl+B"
      action: "command_palette"
      when: "global"
    }

    {
      key: "Ctrl+/"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Alt+Up"
      action: "format"
      when: "debug"
    }
  ]
}
```
