# 9782 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@ordinary-programme.biz"
  subject: "Celebrer alii beatus sumptus cotidie."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Creber tempus sint vinum arma. Verto asporto curiositas spero vehemens aut aestivus. Traho triduana video testimonium possimus validus somnus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Quibusdam nobis verbera. Atqui tremo desipio calcar ratione vito vapulus debitis. Argumentum sublime confido perspiciatis velit sollicito blandior iste suffoco.

Visit: {{url}}
"""
}
```
