# 10790 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@familiar-avalanche.name"
  subject: "Amet delectus defero crepusculum."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Depopulo similique antea culpo coerceo ultio arbustum. Nobis audeo audentia appositus capillus. Apud nostrum animus crapula curso dedico tabella teres adopto.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Acquiro verbera vita subvenio victus deinde autus degero. Careo tersus demergo terra. Ultra peior despecto adflicto incidunt.

Visit: {{url}}
"""
}
```
