# 14033 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "shocked-extent.biz"
  inbound: {
    mx_records: [
      "mx1.shocked-extent.biz"
      "mx2.shocked-extent.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.shocked-extent.biz"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 404
      per_hour: 1869
    }
  }
}
```
