# 16526 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "independence-web"
    namespace: "staging"
    labels: {
      app: "language"
      tier: "backend"
    }
  }

  # Deployment spec
  spec: {
    replicas: 2
    container: {
      image: "guard:0.7.7"
      port: 3000
      resources: {
        cpu_limit: "1000m"
        memory_limit: "256Mi"
      }
    }

    health_check: {
      path: "/ready"
      interval: 10
      timeout: 10
    }
  }
}
```
