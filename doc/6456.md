# 6456 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PATCH"
      path: "/comments"
      handler: "getProducts"
      auth: false
    }

    {
      method: "PUT"
      path: "/orders/:id"
      handler: "getOrders"
      auth: true
    }

    {
      method: "PUT"
      path: "/orders/:id"
      handler: "createUsers"
      auth: true
    }

    {
      method: "GET"
      path: "/products/:id"
      handler: "listProducts"
      auth: false
    }

    {
      method: "POST"
      path: "/posts"
      handler: "deleteUsers"
      auth: true
    }
  ]
}
```
