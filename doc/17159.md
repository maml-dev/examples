# 17159 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "DELETE"
      path: "/products/:id"
      handler: "deleteProducts"
      auth: false
    }

    {
      method: "PUT"
      path: "/posts"
      handler: "deletePosts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/posts"
      handler: "createUsers"
      auth: false
    }

    {
      method: "PATCH"
      path: "/comments/:id"
      handler: "updateProducts"
      auth: false
    }
  ]
}
```
