# 15518 - Logger Config

Structured logging configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  level: "warn"
  format: "pretty"
  timestamp: true
  caller: false # include file:line

  output: "stderr"
  rotation: false
  max_size_mb: 31
  max_age_days: 81
  compress: true
}
```
