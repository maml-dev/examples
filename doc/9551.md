# 9551 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "PUT"
      path: "/orders"
      handler: "updatePosts"
      auth: false
    }

    {
      method: "GET"
      path: "/products/:id"
      handler: "getOrders"
      auth: false
    }

    {
      method: "POST"
      path: "/products"
      handler: "deleteProducts"
      auth: false
    }

    {
      method: "GET"
      path: "/products"
      handler: "getOrders"
      auth: true
    }
  ]
}
```
