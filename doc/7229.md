# 7229 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.outlying-expense.com"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 7529
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://impeccable-intervention.biz"
      "https://app.frail-lyre.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 3592
    store: "memory"
  }
}
```
