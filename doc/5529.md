# 5529 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.present-sticker.biz"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 1400
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://dental-birdcage.org"
      "https://app.excited-pantyhose.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 1005
    store: "memory"
  }
}
```
