# 5133 - Theme Config

Design system theme configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  name: "tasty Theme"
  # Color palette
  colors: {
    primary: "#cecf82"
    secondary: "#3fae22"
    accent: "#6a3acb"
    background: "#f8f9fa"
    text: "#333333"

    error: "#dc3545"
    warning: "#ffc107"
    success: "#28a745"
  }

  # Typography
  typography: {
    font_family: "system-ui, sans-serif"
    base_size: 16
    line_height: 1.75
    headings: {
      font_family: "\"Space Grotesk\", sans-serif"
      weight: 600
    }
  }

  spacing: {
    unit: 8
    scale: [
      0
      4
      8
      16
      24
      32
      48
    ]
  }
  border_radius: 6
}
```
