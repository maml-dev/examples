# 10801 - Locale Config

```maml
{
  language: "zh"
  country: "FR"
  timezone: "America/Puerto_Rico"
  currency: "IDR"

  date_format: "YYYY-MM-DD"
  time_format: "12h"
  first_day_of_week: "monday"
  decimal_separator: ","
}
```
