# 9086 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "76de8c2d-9a88-4b69-930f-ee93f57fb422"
  Accept-Language: "en-US"
  Cache-Control: "max-age=3600"
  X-Powered-By: "Koa"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "venustas"
    "another one": "advoco"
  }
}
```
