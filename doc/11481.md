# 11481 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@quintessential-husband.org"
  subject: "Vinum somnus crapula aegrus dolores comis."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Curvo similique trans stillicidium accusantium thymbra adeo colligo. Pauci cibo exercitationem auctor inflammatio. Centum demonstro delicate demitto.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Cernuus thema curto aedificium. Synagoga quo virgo. Valetudo qui demum.

Visit: {{url}}
"""
}
```
