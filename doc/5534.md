# 5534 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "blockchains"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "staging"
      region: "eu-west"
      team: "grocery"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 74
    memory_threshold: 92
    latency_p99_ms: 1102
    error_rate: 0.05
    notification: {
      channel: "#ops-alerts"
      severity: "critical"
    }
  }
}
```
