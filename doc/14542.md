# 14542 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "hefty-slime.org"
  records: [
    {
      type: "A"
      name: "@"
      value: "96.151.141.70"
      ttl: 86400
    }

    {
      type: "CNAME"
      name: "*"
      value: "v=spf1 include:_spf.separate-bathrobe.com ~all"
      ttl: 300
    }

    {
      type: "A"
      name: "staging"
      value: "224.79.70.239"
      ttl: 300
    }

    {
      type: "MX"
      name: "@"
      value: "animated-epic.net"
      ttl: 86400
    }

    {
      type: "CNAME"
      name: "www"
      value: "v=spf1 include:_spf.smooth-baseboard.net ~all"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "*"
      value: "haunting-knitting.net"
      ttl: 300
    }
  ]
}
```
