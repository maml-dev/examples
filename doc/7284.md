# 7284 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@short-term-almighty.com"
  subject: "Comburo labore spoliatio spes."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Quam sponte addo textus absorbeo astrum. Antea clibanus curia. Terga tergiversatio verus tui angelus stips aer stultus carcer.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Alo temperantia animadverto tripudio blandior cribro thesaurus dignissimos urbanus. Testimonium nobis virga recusandae cruentus tenetur soluta. Eligendi adicio nulla vorago subito tabesco confero tres.

Visit: {{url}}
"""
}
```
