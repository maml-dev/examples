# 4943 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "probable-beret.org"
  records: [
    {
      type: "AAAA"
      name: "*"
      value: "57.108.77.119"
      ttl: 86400
    }

    {
      type: "NS"
      name: "@"
      value: "clear-basket.com"
      ttl: 300
    }

    {
      type: "CNAME"
      name: "*"
      value: "v=spf1 include:_spf.optimistic-almighty.net ~all"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "mail"
      value: "weighty-permafrost.name"
      ttl: 300
    }

    {
      type: "MX"
      name: "staging"
      value: "210.24.175.254"
      ttl: 86400
    }
  ]
}
```
