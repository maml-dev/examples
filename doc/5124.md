# 5124 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "fearless-formation.com"
  inbound: {
    mx_records: [
      "mx1.fearless-formation.com"
      "mx2.fearless-formation.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.fearless-formation.com"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 148
      per_hour: 5305
    }
  }
}
```
