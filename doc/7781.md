# 7781 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@noxious-tuber.info"
  subject: "Virga cerno virgo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Cornu curiositas dolores suscipio id cicuta color viduo annus viduo. Appello adinventitias tendo vesco. Eveniet volo umquam tutamen velociter harum ad derideo.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Cupio absconditus paulatim celo crur vigilo caveo accusantium conduco. Adinventitias clam sed ipsum absconditus conitor ver sophismata amitto. Attero valeo cilicium.

Visit: {{url}}
"""
}
```
