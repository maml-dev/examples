# 5004 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "monthly-secret.org"
  ttl: 3600 # seconds
  nameservers: [
    "ns1.lustrous-mom.org"
    "ns2.edible-habit.info"
  ]

  soa_email: "admin@shocked-tomb.com"
  refresh: 7200
  retry: 600
  expire: 604800
}
```
