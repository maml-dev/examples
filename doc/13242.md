# 13242 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PATCH"
      path: "/orders"
      handler: "updateUsers"
      auth: true
    }

    {
      method: "GET"
      path: "/posts"
      handler: "createOrders"
      auth: true
    }

    {
      method: "GET"
      path: "/orders"
      handler: "createProducts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/comments/:id"
      handler: "updateOrders"
      auth: true
    }

    {
      method: "GET"
      path: "/products/:id"
      handler: "createProducts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/products"
      handler: "updatePosts"
      auth: true
    }
  ]
}
```
