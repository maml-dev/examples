# 12853 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Ctrl+S"
      action: "format"
      when: "terminal"
    }

    {
      key: "F5"
      action: "format"
      when: "terminal"
    }

    {
      key: "Alt+F7"
      action: "toggle_comment"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+F"
      action: "command_palette"
      when: "editor"
    }

    {
      key: "Ctrl+D"
      action: "search_project"
      when: "global"
    }

    {
      key: "Ctrl+/"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "Ctrl+/"
      action: "toggle_sidebar"
      when: "debug"
    }
  ]
}
```
