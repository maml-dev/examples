# 5981 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@fat-babushka.org"
  subject: "Tolero cogo curatio adicio."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Valetudo sulum sperno. Depromo constans coniuratio alioqui terreo ancilla solium adstringo benigne reiciendis. Spargo veniam sint consectetur vaco vitae.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Temporibus verumtamen succurro vos vomer vestrum conor candidus. Carbo crur omnis. Torqueo comedo tepesco vomica deduco speculum.

Visit: {{url}}
"""
}
```
