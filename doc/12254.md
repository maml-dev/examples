# 12254 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "insidious-going.biz"
  records: [
    {
      type: "NS"
      name: "api"
      value: "mammoth-gallery.org"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "mail"
      value: "guilty-ice-cream.org"
      ttl: 86400
    }

    {
      type: "A"
      name: "www"
      value: "135.6.128.129"
      ttl: 300
    }

    {
      type: "TXT"
      name: "staging"
      value: "18.59.35.243"
      ttl: 3600
    }

    {
      type: "TXT"
      name: "api"
      value: "vivacious-blight.com"
      ttl: 3600
    }

    {
      type: "TXT"
      name: "www"
      value: "v=spf1 include:_spf.shallow-muscat.net ~all"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "mail"
      value: "v=spf1 include:_spf.frank-parsnip.org ~all"
      ttl: 300
    }
  ]
}
```
