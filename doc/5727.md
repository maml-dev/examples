# 5727 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "roi"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 10 # seconds
    labels: {
      env: "prod"
      region: "eu-west"
      team: "games"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 87
    memory_threshold: 90
    latency_p99_ms: 499
    error_rate: 0.02
    notification: {
      channel: "#incidents"
      severity: "critical"
    }
  }
}
```
