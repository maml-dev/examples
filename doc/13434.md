# 13434 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "strange-excess.org"
  inbound: {
    mx_records: [
      "mx1.strange-excess.org"
      "mx2.strange-excess.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.strange-excess.org"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 146
      per_hour: 3951
    }
  }
}
```
