# 13059 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "DELETE"
      path: "/products"
      handler: "deleteUsers"
      auth: false
    }

    {
      method: "GET"
      path: "/products"
      handler: "createUsers"
      auth: false
    }

    {
      method: "DELETE"
      path: "/users"
      handler: "createUsers"
      auth: false
    }

    {
      method: "PUT"
      path: "/posts/:id"
      handler: "deletePosts"
      auth: true
    }

    {
      method: "GET"
      path: "/orders/:id"
      handler: "updateOrders"
      auth: false
    }

    {
      method: "PUT"
      path: "/posts/:id"
      handler: "getProducts"
      auth: false
    }
  ]
}
```
