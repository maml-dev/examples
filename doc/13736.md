API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.noxious-joy.biz"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 3901

  # CORS policy
  cors: {

      "DELETE"

  }

  cache: {
    enabled: false
    ttl: 203
    store: "memory"
  }
}
```
