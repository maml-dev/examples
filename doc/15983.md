# 15983 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@judicious-baseboard.org"
  subject: "Ultra taedium contabesco."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Tertius fugiat aequus nobis aliquid. Modi consequuntur supplanto baiulus casus apparatus officia commodi mollitia. Vox thesis circumvenio videlicet terreo advenio cicuta curo truculenter.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Deinde concido vergo vestigium acquiro adhaero. Altus vinculum angulus curto turpis beneficium adsidue summa umerus patior. Architecto iure tot degusto.

Visit: {{url}}
"""
}
```
