# 12346 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "export_data"
        "view_analytics"
      ]
      max_seats: 9
    }

    {
      name: "moderator"
      permissions: [
        "manage_billing"
        "read"
        "delete"
        "view_analytics"
        "write"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "read"
        "delete"
        "view_analytics"
        "write"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "write"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "manage_billing"
        "read"
        "export_data"
      ]
      max_seats: null
    }
  ]
}
```
