# 13647 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Ctrl+D"
      action: "save"
      when: "terminal"
    }

    {
      key: "Alt+Up"
      action: "format"
      when: "debug"
    }

    {
      key: "Ctrl+B"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "Ctrl+B"
      action: "command_palette"
      when: "debug"
    }
  ]
}
```
