# 14134 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.old-horst.info"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 8529
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://brilliant-ecliptic.org"
      "https://app.striking-angle.info"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 3478
    store: "memory"
  }
}
```
