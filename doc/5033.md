# 5033 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.avaricious-grandson.name"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 1568
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://standard-giant.net"
      "https://app.lone-masterpiece.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 690
    store: "memory"
  }
}
```
