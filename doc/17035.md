# 17035 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "nocturnal-handle.com"
  inbound: {
    mx_records: [
      "mx1.nocturnal-handle.com"
      "mx2.nocturnal-handle.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.nocturnal-handle.com"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 372
      per_hour: 4281
    }
  }
}
```
