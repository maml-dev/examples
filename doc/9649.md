# 9649 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Alt+F7"
      action: "save"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+P"
      action: "toggle_terminal"
      when: "global"
    }

    {
      key: "Ctrl+Shift+F"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+P"
      action: "command_palette"

    }

      key: "F5"
      action: "toggle_comment"
      when: "editor"
    }

      key: "Ctrl+Shift+F"
      action: "find_references"
      when: "editor"
    }

    {
      key: "F5"
      action: "toggle_sidebar"
      when: "editor"
    }
  ]
}
```
