# 6926 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.elementary-configuration.biz"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 1027
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://deep-promise.net"
      "https://app.forsaken-subexpression.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 945
    store: "memory"
  }
}
```
