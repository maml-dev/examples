# 9997 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "6e173fc1-87fa-4e99-b4c5-86c5a69220d3"
  Accept-Language: "en-US"
  Cache-Control: "max-age=3600"
  X-Powered-By: "Koa"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "claudeo"
    "another one": "umbra"
  }
}
```
