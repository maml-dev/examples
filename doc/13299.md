# 13299 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "cacc651c-943b-4eae-a900-0fc3a6879431"
  Accept-Language: "ja-JP"
  Cache-Control: "max-age=3600"
  X-Powered-By: "Express"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "capto"
    "another one": "ager"
  }
}
```
