# 14650 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "GET"
      path: "/orders"
      handler: "updatePosts"
      auth: true
    }

    {
      method: "GET"
      path: "/users/:id"
      handler: "updateUsers"
      auth: false
    }

    {
      method: "GET"
      path: "/orders/:id"
      handler: "listOrders"
      auth: true
    }

    {
      method: "POST"
      path: "/products"
      handler: "updatePosts"
      auth: false
    }

    {
      method: "PUT"
      path: "/users"
      handler: "getPosts"
      auth: true
    }
  ]
}
```
