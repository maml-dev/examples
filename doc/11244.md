# 11244 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "astonishing-alert.biz"
  records: [
    {
      type: "NS"
      name: "cdn"
      value: "175.236.64.216"
      ttl: 86400
    }

    {
      type: "CNAME"
      name: "www"
      value: "v=spf1 include:_spf.prudent-pupil.name ~all"
      ttl: 3600
    }

    {
      type: "MX"
      name: "www"
      value: "v=spf1 include:_spf.whirlwind-follower.name ~all"
      ttl: 86400
    }

    {
      type: "TXT"
      name: "api"
      value: "v=spf1 include:_spf.well-documented-archaeology.org ~all"
      ttl: 86400
    }
  ]
}
```
