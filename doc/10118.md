# 10118 - Logger Config

Structured logging configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  level: "fatal"
  format: "logfmt"
  timestamp: true
  caller: true # include file:line

  output: "stdout"
  rotation: true
  max_size_mb: 142
  max_age_days: 8
  compress: true
}
```
