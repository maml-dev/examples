# 13741 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "edible-tectonics.net"
  records: [
    {
      type: "AAAA"
      name: "mail"
      value: "sparkling-going.info"
      ttl: 300
    }

    {
      type: "CNAME"
      name: "mail"
      value: "156.197.192.232"
      ttl: 86400
    }

    {
      type: "TXT"
      name: "@"
      value: "v=spf1 include:_spf.long-term-premium.biz ~all"
      ttl: 3600
    }

    {
      type: "NS"
      name: "cdn"
      value: "120.6.41.144"
      ttl: 300
    }

    {
      type: "NS"
      name: "cdn"
      value: "240.51.209.192"
      ttl: 3600
    }

    {
      type: "TXT"
      name: "cdn"
      value: "bustling-lady.org"
      ttl: 86400
    }
  ]
}
```
