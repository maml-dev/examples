# 7952 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Ctrl+Shift+P"
      action: "toggle_terminal"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+F"
      action: "format"
      when: "global"
    }

    {
      key: "Ctrl+/"
      action: "save"
      when: "editor"
    }

    {
      key: "Cmd+K"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Alt+Up"
      action: "format"
      when: "debug"
    }
  ]
}
```
