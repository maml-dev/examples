# 16288 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@bright-petticoat.name"
  subject: "Tollo acquiro certe creator."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Denuo coniuratio vespillo tyrannus agnosco. Spectaculum speculum trepide textus qui celo suadeo confido voluptates. Amet sordeo trans summisse aurum depromo arcesso.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Universe accommodo atavus temeritas confugo vilis catena sollers confero. Suscipio agnosco adipisci caput vesper rem verbum calculus stips. Comptus bardus certe arbustum provident vir voveo censura coruscus id.

Visit: {{url}}
"""
}
```
