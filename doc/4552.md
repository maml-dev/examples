# 4552 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "viewer"
      permissions: [
        "export_data"
        "manage_billing"
      ]
      max_seats: 30
    }

    {
      name: "viewer"
      permissions: [
        "write"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "export_data"
        "manage_billing"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "manage_users"
        "write"
        "delete"
        "read"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "view_analytics"
        "read"
        "manage_users"
      ]
      max_seats: 11
    }
  ]
}
```
