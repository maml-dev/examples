# 16653 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "GET"
      path: "/products"
      handler: "deleteOrders"
      auth: true
    }

    {
      method: "PATCH"
      path: "/users/:id"
      handler: "deleteOrders"
      auth: true
    }

    {
      method: "PATCH"
      path: "/posts/:id"
      handler: "listOrders"
      auth: false
    }
  ]
}
```
