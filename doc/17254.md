# 17254 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "view_analytics"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "write"
        "export_data"
        "manage_billing"
        "read"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "export_data"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "manage_users"
        "read"
        "manage_billing"
        "view_analytics"
      ]
      max_seats: 31
    }

    {
      name: "admin"
      permissions: [
        "export_data"
        "delete"
      ]
      max_seats: 22
    }
  ]
}
```
