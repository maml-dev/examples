# 9695 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@quarterly-sand.name"
  subject: "Bibo neque avarus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Thesaurus apparatus cerno vado. Callide bellicus valeo amaritudo sed vester totam absque thalassinus. Contra vulgo ago ipsa vos volup capillus benevolentia.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Tristis viduo substantia basium corrigo curia depereo arto. Adopto absorbeo voro rem denuo valde solvo verbum aliqua. Clarus complectus vomica coadunatio.

Visit: {{url}}
"""
}
```
