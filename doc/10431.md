# 10431 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.thick-solution.biz"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 5227
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://short-term-safe.net"
      "https://app.diligent-term.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 155
    store: "redis"
  }
}
```
