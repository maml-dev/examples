# 8459 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "manage_users"
        "view_analytics"
        "export_data"
        "write"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "export_data"
        "view_analytics"
        "read"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "manage_billing"
        "view_analytics"
        "export_data"
      ]
      max_seats: 6
    }

    {
      name: "support"
      permissions: [
        "export_data"
        "manage_users"
        "view_analytics"
        "write"
      ]
      max_seats: null
    }
  ]
}
```
