# 6045 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Ctrl+D"
      action: "format"
      when: "global"
    }

    {
      key: "Ctrl+/"
      action: "format"
      when: "editor"
    }

    {
      key: "Ctrl+D"
      action: "toggle_terminal"
      when: "terminal"
    }

    {
      key: "Ctrl+D"
      action: "toggle_terminal"
      when: "terminal"
    }

    {
      key: "Ctrl+`"
      action: "select_all_occurrences"
      when: "global"
    }

    {
      key: "Alt+F7"
      action: "format"
      when: "editor"
    }

    {
      key: "Ctrl+D"
      action: "save"
      when: "debug"
    }
  ]
}
```
