# 15322 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "admired-declaration.net"
  inbound: {
    mx_records: [
      "mx1.admired-declaration.net"
      "mx2.admired-declaration.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.admired-declaration.net"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 466
      per_hour: 4220
    }
  }
}
```
