# 15549 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "viewer"
      permissions: [
        "view_analytics"
        "write"
      ]
      max_seats: 6
    }

    {
      name: "support"
      permissions: [
        "read"
        "export_data"
        "delete"
        "manage_billing"
      ]
      max_seats: 25
    }

    {
      name: "moderator"
      permissions: [
        "manage_users"
        "delete"
        "view_analytics"
      ]
      max_seats: null
    }
  ]
}
```
