# 6743 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "view_analytics"
        "delete"
        "manage_users"
        "write"
        "export_data"
      ]
      max_seats: 30
    }

    {
      name: "billing"
      permissions: [
        "manage_billing"
        "read"
        "delete"
        "export_data"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "write"
        "manage_users"
        "view_analytics"
        "read"
      ]
      max_seats: 35
    }
  ]
}
```
