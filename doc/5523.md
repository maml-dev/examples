# 5523 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "communities"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "staging"
      region: "ap-south"
      team: "tools"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 95
    memory_threshold: 90
    latency_p99_ms: 1113
    error_rate: 0.05
    notification: {
      channel: "#ops-alerts"
      severity: "warning"
    }
  }
}
```
