# 7554 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "PATCH"
      path: "/users/:id"
      handler: "updateUsers"
      auth: true
    }

    {
      method: "PUT"
      path: "/products/:id"
      handler: "deleteProducts"
      auth: false
    }

    {
      method: "GET"
      path: "/posts"
      handler: "deleteOrders"
      auth: false
    }

    {
      method: "POST"
      path: "/posts/:id"
      handler: "getPosts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/products"
      handler: "deleteUsers"
      auth: false
    }
  ]
}
```
