# 16725 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "idealistic-chap.biz"
  inbound: {
    mx_records: [
      "mx1.idealistic-chap.biz"
      "mx2.idealistic-chap.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.idealistic-chap.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 429
      per_hour: 6964
    }
  }
}
```
