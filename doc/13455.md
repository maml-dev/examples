# 13455 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Cmd+K"
      action: "command_palette"
      when: "global"
    }

    {
      key: "F5"
      action: "save"
      when: "terminal"
    }

    {
      key: "Ctrl+D"
      action: "command_palette"
      when: "editor"
    }

    {
      key: "Ctrl+D"
      action: "command_palette"
      when: "global"
    }

    {
      key: "Cmd+K"
      action: "search_project"
      when: "editor"
    }

    {
      key: "Ctrl+`"
      action: "toggle_comment"
      when: "editor"
    }

    {
      key: "Ctrl+`"
      action: "command_palette"
      when: "global"
    }
  ]
}
```
