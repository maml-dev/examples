# 7434 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "ashamed-equal.biz"
  inbound: {
    mx_records: [
      "mx1.ashamed-equal.biz"
      "mx2.ashamed-equal.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.ashamed-equal.biz"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 398
      per_hour: 4876
    }
  }
}
```
