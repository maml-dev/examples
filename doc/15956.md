# 15956 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "POST"
      path: "/posts/:id"
      handler: "getPosts"
      auth: false
    }

    {
      method: "PUT"
      path: "/products"
      handler: "listPosts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/products"
      handler: "deleteOrders"
      auth: false
    }
  ]
}
```
