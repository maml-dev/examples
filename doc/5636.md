# 5636 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.alienated-boyfriend.net"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 9689
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://ill-fowl.name"
      "https://app.gracious-ownership.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 2538
    store: "redis"
  }
}
```
