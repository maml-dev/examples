# 15256 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "viewer"
      permissions: [
        "manage_billing"
        "view_analytics"
      ]
      max_seats: 2
    }

    {
      name: "admin"
      permissions: [
        "write"
        "manage_billing"
        "manage_users"
      ]
      max_seats: 40
    }

    {
      name: "billing"
      permissions: [
        "view_analytics"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "export_data"
        "delete"
        "manage_billing"
        "manage_users"
      ]
      max_seats: 32
    }

    {
      name: "editor"
      permissions: [
        "write"
        "delete"
        "export_data"
        "view_analytics"
      ]
      max_seats: 2
    }
  ]
}
```
