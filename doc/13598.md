# 13598 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "581c50bd-a27d-4b8d-9c5e-bf22a4afa61e"
  Accept-Language: "de-DE"
  Cache-Control: "max-age=3600"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "conscendo"
    "another one": "aro"
  }
}
```
