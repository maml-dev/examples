# 4530 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.easy-courtroom.net"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 7844
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://spirited-sauerkraut.org"
      "https://app.remorseful-hubris.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 201
    store: "memory"
  }
}
```
