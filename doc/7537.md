# 7537 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "unruly-kinase.name"
  inbound: {
    mx_records: [
      "mx1.unruly-kinase.name"
      "mx2.unruly-kinase.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.unruly-kinase.name"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 443
      per_hour: 3601
    }
  }
}
```
