# 8954 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "viewer"
      permissions: [
        "manage_users"
        "read"
        "delete"
      ]
      max_seats: 47
    }

    {
      name: "viewer"
      permissions: [
        "manage_billing"
        "export_data"
        "delete"
      ]
      max_seats: 4
    }

    {
      name: "editor"
      permissions: [
        "write"
        "manage_users"
        "read"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "delete"
        "view_analytics"
        "read"
        "export_data"
      ]
      max_seats: null
    }
  ]
}
```
