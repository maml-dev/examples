# 14136 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.pleased-cash.org"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 6995
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://minty-sesame.biz"
      "https://app.impartial-lender.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 3142
    store: "redis"
  }
}
```
