# 13058 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "export_data"
        "write"
        "view_analytics"
        "read"
      ]
      max_seats: 17
    }

    {
      name: "support"
      permissions: [
        "delete"
        "manage_users"
        "manage_billing"
        "write"
      ]
      max_seats: 21
    }

    {
      name: "support"
      permissions: [
        "view_analytics"
        "export_data"
        "write"
        "read"
      ]
      max_seats: 19
    }

    {
      name: "billing"
      permissions: [
        "export_data"
        "view_analytics"
        "manage_billing"
      ]
      max_seats: null
    }
  ]
}
```
