# 10115 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "well-off-peninsula.info"
  ttl: 600 # seconds
  nameservers: [
    "ns1.wavy-bar.name"
    "ns2.tame-hexagon.com"
  ]

  soa_email: "admin@salty-jungle.name"
  refresh: 14400
  retry: 1800
  expire: 604800
}
```
