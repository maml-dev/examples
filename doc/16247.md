# 16247 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "viewer"
      permissions: [
        "export_data"
        "write"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "manage_users"
        "write"
        "read"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "export_data"
        "view_analytics"
        "write"
      ]
      max_seats: 11
    }

    {
      name: "viewer"
      permissions: [
        "manage_billing"
        "write"
        "manage_users"
        "export_data"
        "read"
      ]
      max_seats: 34
    }

    {
      name: "support"
      permissions: [
        "delete"
        "read"
        "export_data"
      ]
      max_seats: null
    }
  ]
}
```
