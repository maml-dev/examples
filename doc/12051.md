# 12051 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "export_data"
        "manage_billing"
        "delete"
      ]
      max_seats: 31
    }

    {
      name: "viewer"
      permissions: [
        "delete"
        "read"
        "manage_users"
        "view_analytics"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "write"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "view_analytics"
        "manage_users"
        "export_data"
      ]
      max_seats: 34
    }
  ]
}
```
