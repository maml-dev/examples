# 11622 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "worthy-thunderbolt.net"
  inbound: {
    mx_records: [
      "mx1.worthy-thunderbolt.net"
      "mx2.worthy-thunderbolt.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.worthy-thunderbolt.net"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 430
      per_hour: 1891
    }
  }
}
```
