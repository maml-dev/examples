# 10724 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.poor-nerve.com"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 8601
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://wilted-folklore.com"
      "https://app.snoopy-adviser.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: true
    ttl: 3414
    store: "memory"
  }
}
```
