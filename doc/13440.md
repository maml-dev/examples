# 13440 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "portly-carnival.org"
  inbound: {
    mx_records: [
      "mx1.portly-carnival.org"
      "mx2.portly-carnival.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.portly-carnival.org"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 212
      per_hour: 7176
    }
  }
}
```
