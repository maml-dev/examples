# 12296 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "05e994bc-40f7-463b-87d7-6ccb4f248ae5"
  Accept-Language: "en-US"
  Cache-Control: "no-cache"
  X-Powered-By: "Fastify"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "causa"
    "another one": "quis"
  }
}
```
