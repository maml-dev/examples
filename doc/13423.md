# 13423 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "gorgeous-mythology.biz"
  inbound: {
    mx_records: [
      "mx1.gorgeous-mythology.biz"
      "mx2.gorgeous-mythology.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.gorgeous-mythology.biz"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 72
      per_hour: 7183
    }
  }
}
```
