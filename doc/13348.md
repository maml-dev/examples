# 13348 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Ctrl+D"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "Alt+F7"
      action: "toggle_sidebar"
      when: "terminal"
    }

    {
      key: "F5"
      action: "find_references"
      when: "editor"
    }

    {
      key: "Alt+Up"
      action: "find_references"
      when: "debug"
    }

    {
      key: "F5"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+P"
      action: "save"
      when: "debug"
    }
  ]
}
```
