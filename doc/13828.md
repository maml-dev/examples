# 13828 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "junior-cake.org"
  inbound: {
    mx_records: [
      "mx1.junior-cake.org"
      "mx2.junior-cake.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.junior-cake.org"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 64
      per_hour: 4987
    }
  }
}
```
