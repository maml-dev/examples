# 4659 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "PATCH"
      path: "/users"
      handler: "updateProducts"
      auth: false
    }

    {
      method: "PUT"
      path: "/orders"
      handler: "getPosts"
      auth: false
    }

    {
      method: "POST"
      path: "/posts"
      handler: "updatePosts"
      auth: false
    }

    {
      method: "POST"
      path: "/posts/:id"
      handler: "createOrders"
      auth: true
    }

    {
      method: "POST"
      path: "/users"
      handler: "createUsers"
      auth: false
    }

    {
      method: "DELETE"
      path: "/orders/:id"
      handler: "listOrders"
      auth: true
    }
  ]
}
```
