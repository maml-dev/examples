# 15146 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "early-tomography.biz"
  records: [
    {
      type: "NS"
      name: "api"
      value: "44.239.189.160"
      ttl: 3600
    }

    {
      type: "MX"
      name: "mail"
      value: "hard-to-find-barracks.org"
      ttl: 3600
    }

    {
      type: "TXT"
      name: "mail"
      value: "mature-calculus.biz"
      ttl: 3600
    }

    {
      type: "MX"
      name: "mail"
      value: "sentimental-drug.org"
      ttl: 86400
    }

    {
      type: "MX"
      name: "@"
      value: "v=spf1 include:_spf.useless-antelope.com ~all"
      ttl: 3600
    }

    {
      type: "NS"
      name: "www"
      value: "108.199.233.205"
      ttl: 300
    }

    {
      type: "MX"
      name: "api"
      value: "v=spf1 include:_spf.giving-handle.biz ~all"
      ttl: 300
    }
  ]
}
```
