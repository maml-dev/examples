# 12649 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "POST"
      path: "/comments/:id"
      handler: "updateUsers"
      auth: true
    }

    {
      method: "PUT"
      path: "/posts/:id"
      handler: "createProducts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/comments/:id"
      handler: "createUsers"
      auth: false
    }

    {
      method: "PUT"
      path: "/posts/:id"
      handler: "getProducts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/comments/:id"
      handler: "updateOrders"
      auth: false
    }
  ]
}
```
