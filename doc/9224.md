# 9224 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "mysterious-provider.biz"
  inbound: {
    mx_records: [
      "mx1.mysterious-provider.biz"
      "mx2.mysterious-provider.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.mysterious-provider.biz"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 149
      per_hour: 5193
    }
  }
}
```
