# 4757 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "DELETE"
      path: "/orders/:id"
      handler: "listOrders"
      auth: false
    }

    {
      method: "PUT"
      path: "/products/:id"
      handler: "getOrders"
      auth: false
    }

    {
      method: "DELETE"
      path: "/posts/:id"
      handler: "listUsers"
      auth: true
    }

    {
      method: "POST"
      path: "/comments"
      handler: "deleteOrders"
      auth: false
    }

    {
      method: "GET"
      path: "/orders/:id"
      handler: "listUsers"
      auth: false
    }
  ]
}
```
