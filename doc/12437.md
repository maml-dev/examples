# 12437 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "deserted-nun.com"
  inbound: {
    mx_records: [
      "mx1.deserted-nun.com"
      "mx2.deserted-nun.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.deserted-nun.com"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 319
      per_hour: 3251
    }
  }
}
```
