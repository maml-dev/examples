# 16956 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+`"
      action: "save"
      when: "editor"
    }

    {
      key: "Ctrl+/"
      action: "save"
      when: "global"
    }

    {
      key: "Ctrl+`"
      action: "toggle_terminal"
      when: "global"
    }

    {
      key: "Ctrl+D"
      action: "toggle_comment"
      when: "editor"
    }

    {
      key: "F5"
      action: "select_all_occurrences"
      when: "global"
    }
  ]
}
```
