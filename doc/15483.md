# 15483 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@far-flung-parade.com"
  subject: "Atqui adversus confugo creo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Adopto venustas conventus depraedor. Damnatio cunabula vacuus aranea villa vitiosus volutabrum ustilo caelum coadunatio. Attero atqui ullam eum averto tam.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Carpo amor victoria torqueo. Utique adopto ut vesper alii aegrus vulgivagus socius contigo volaticus. Atrox virtus aperiam placeat solus aurum constans venustas ceno.

Visit: {{url}}
"""
}
```
