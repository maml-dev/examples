# 4841 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "GET"
      path: "/orders"
      handler: "getProducts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/orders"
      handler: "deleteOrders"
      auth: false
    }

    {
      method: "POST"
      path: "/orders/:id"
      handler: "deleteProducts"
      auth: false
    }
  ]
}
```
