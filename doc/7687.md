# 7687 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@pertinent-expansion.org"
  subject: "Nam adsidue audacia."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Aequus amitto curia. Collum enim ulciscor confero combibo. Arca vitae asporto comes tepesco.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Ducimus canto spiritus adipiscor tametsi decens. Ait delinquo cupressus callide tristis. Arbor adipiscor tunc praesentium audacia ater temporibus amicitia angelus.

Visit: {{url}}
"""
}
```
