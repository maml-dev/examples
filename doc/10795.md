# 10795 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@improbable-depot.net"
  subject: "Ustulo eum aequus sapiente thalassinus absque."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Patruus voco rem umbra deludo administratio comprehendo cogo titulus quod. Depraedor turbo voluptate avarus recusandae tepidus adipiscor. Voluptates tabula arceo.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Tredecim sol articulus aer terminatio depopulo corporis cupiditate. Nam spoliatio videlicet approbo tripudio terreo unde substantia. Turba error adsum stultus terminatio.

Visit: {{url}}
"""
}
```
