# 5498 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@noteworthy-desk.net"
  subject: "Nihil vero ustilo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Attero possimus sonitus voluptatem suffoco inflammatio tantillus claustrum quibusdam. Aiunt cursim iste. Abscido asperiores subito supellex sulum vociferor capio viscus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Ex corporis depereo contego absconditus correptius corrigo. Defetiscor conforto explicabo. Vito tubineus succurro contigo quod tendo suppono sed.

Visit: {{url}}
"""
}
```
