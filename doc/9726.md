# 9726 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "stingy-plastic.name"
  inbound: {
    mx_records: [
      "mx1.stingy-plastic.name"
      "mx2.stingy-plastic.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.stingy-plastic.name"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 223
      per_hour: 7565
    }
  }
}
```
