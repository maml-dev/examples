# 16934 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "glorious-extension.org"
  inbound: {
    mx_records: [
      "mx1.glorious-extension.org"
      "mx2.glorious-extension.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.glorious-extension.org"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 128
      per_hour: 6997
    }
  }
}
```
