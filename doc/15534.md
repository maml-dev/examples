# 15534 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "responsible-scratch.org"
  inbound: {
    mx_records: [
      "mx1.responsible-scratch.org"
      "mx2.responsible-scratch.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.responsible-scratch.org"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 486
      per_hour: 5582
    }
  }
}
```
