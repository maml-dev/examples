# 4884 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "ad0843a9-2664-49e7-9760-4148fa627593"
  Accept-Language: "en-US"
  Cache-Control: "public, max-age=86400"
  X-Powered-By: "Express"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "cupiditas"
    "another one": "confero"
  }
}
```
