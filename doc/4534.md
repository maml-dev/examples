# 4534 - Backup Strategy

Backup schedule and retention policy. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  source: {
    type: "mongodb"
    host: "localhost"
    databases: [
      "reorganisation"
      "negotiation"
    ]
  }

  # Backup schedule
  schedule: {
    full: "0 2 * * 0" # weekly Sunday 2am
    incremental: "0 2 * * 1-6" # daily except Sunday
    snapshot: "0 */4 * * *" # every 4 hours
  }

  retention: {
    daily: 10
    weekly: 12
    monthly: 14
  }

  destination: {
    type: "s3"
    path: "s3://backups-bug"
    encryption: true
    compression: "zstd"
  }
}
```
