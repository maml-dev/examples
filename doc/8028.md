# 8028 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "sarcastic-grandpa.name"
  inbound: {
    mx_records: [
      "mx1.sarcastic-grandpa.name"
      "mx2.sarcastic-grandpa.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.sarcastic-grandpa.name"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 62
      per_hour: 8687
    }
  }
}
```
