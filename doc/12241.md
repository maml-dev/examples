# 12241 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "POST"
      path: "/orders"
      handler: "deleteOrders"
      auth: false
    }

    {
      method: "POST"
      path: "/posts/:id"
      handler: "updateOrders"
      auth: true
    }

    {
      method: "GET"
      path: "/products"
      handler: "createPosts"
      auth: true
    }
  ]
}
```
