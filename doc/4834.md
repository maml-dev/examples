# 4834 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "dual-midwife.net"
  inbound: {
    mx_records: [
      "mx1.dual-midwife.net"
      "mx2.dual-midwife.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.dual-midwife.net"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 64
      per_hour: 7347
    }
  }
}
```
