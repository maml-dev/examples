# 12234 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.complicated-finer.net"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 1058
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://hairy-steeple.net"
      "https://app.private-fork.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 322
    store: "redis"
  }
}
```
