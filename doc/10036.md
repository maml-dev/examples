# 10036 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "golden-railway.net"
  inbound: {
    mx_records: [
      "mx1.golden-railway.net"
      "mx2.golden-railway.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.golden-railway.net"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 420
      per_hour: 6594
    }
  }
}
```
