# 7195 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@moral-polarisation.info"
  subject: "Vitiosus viduo stipes fugiat."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Ciminatio vitiosus cimentarius aegre truculenter conforto strenuus decipio. Sursum congregatio vito dolore decumbo neque armarium. Aliquid deludo laborum vere praesentium absens conventus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Vivo terror degenero celo vito tutis celo vicinus. Brevis tracto crastinus cuius voluptas. Rerum audacia carcer callide coadunatio desparatus truculenter delectus atqui.

Visit: {{url}}
"""
}
```
