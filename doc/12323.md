# 12323 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "puzzled-euphonium.org"
  inbound: {
    mx_records: [
      "mx1.puzzled-euphonium.org"
      "mx2.puzzled-euphonium.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.puzzled-euphonium.org"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 328
      per_hour: 1033
    }
  }
}
```
