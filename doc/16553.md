# 16553 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "view_analytics"
        "write"
        "read"
      ]
      max_seats: 25
    }

    {
      name: "moderator"
      permissions: [
        "delete"
        "manage_users"
        "manage_billing"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "export_data"
        "delete"
      ]
      max_seats: 6
    }
  ]
}
```
