# 7351 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PATCH"
      path: "/orders"
      handler: "updateOrders"
      auth: false
    }

    {
      method: "PUT"
      path: "/posts/:id"
      handler: "createUsers"
      auth: false
    }

    {
      method: "DELETE"
      path: "/products/:id"
      handler: "getUsers"
      auth: true
    }

    {
      method: "PATCH"
      path: "/posts/:id"
      handler: "createUsers"
      auth: false
    }

    {
      method: "GET"
      path: "/comments"
      handler: "getUsers"
      auth: true
    }

    {
      method: "DELETE"
      path: "/orders"
      handler: "getOrders"
      auth: true
    }
  ]
}
```
