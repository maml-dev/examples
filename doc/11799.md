# 11799 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@neglected-fisherman.info"
  subject: "Adulescens vapulus vae vomito succedo textus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Spoliatio truculenter ambitus quod vinculum tactus arceo creber. Compono tepesco pecto deprecator quidem balbus tamen textor. Demens corona addo sed necessitatibus solium vociferor.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Volutabrum caste vinculum celer patruus. Fugit tenax depulso. Quod ara cena quas.

Visit: {{url}}
"""
}
```
