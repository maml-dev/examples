# 10775 - i18n Config

Internationalization and locale settings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  default_locale: "en-US"
  fallback: "en"

    {

      name: "English"
      dir: "ltr"

    {
      code: "fr"
      name: "Français"
      dir: "ltr"
    }

      code: "ar"
      name: "العربية"
      dir: "rtl"
    }

  ]

  detection: {
    order: [
      "cookie"

      "query"
    ]
    cookie_name: "lang"
  }
}
```
