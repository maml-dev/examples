# 5303 - SSH Config

SSH client host configuration. This is an example of a [MAML](https://maml.dev) document.

{
  host: "dev-server"
  hostname: "171.108.35.47"
  user: "stuart47"
  port: 2200
  identity_file: "~/.ssh/id_ed25519"

  forward_agent: false
  server_alive_interval: 120
  compression: true
}
