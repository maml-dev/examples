# 9657 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "PATCH"
      path: "/posts/:id"
      handler: "deleteProducts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/orders/:id"
      handler: "listPosts"
      auth: true
    }

    {
      method: "GET"
      path: "/posts"
      handler: "updateUsers"
      auth: false
    }
  ]
}
```
