# 16122 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.first-cop-out.info"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 2491
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://unlined-gallery.name"
      "https://app.both-omelet.info"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 121
    store: "memory"
  }
}
```
