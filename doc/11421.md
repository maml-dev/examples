# 11421 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.upset-video.com"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 6225
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://favorable-tinderbox.name"
      "https://app.subdued-gift.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: true
    ttl: 940
    store: "memory"
  }
}
```
