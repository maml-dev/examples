# 7145 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PUT"
      path: "/posts/:id"
      handler: "updateUsers"
      auth: true
    }

    {
      method: "DELETE"
      path: "/products/:id"
      handler: "createUsers"
      auth: true
    }

    {
      method: "PUT"
      path: "/users"
      handler: "updateProducts"
      auth: true
    }
  ]
}
```
