# 13236 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.rusty-bonfire.com"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 8151
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://cheerful-cafe.name"
      "https://app.short-mouser.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: true
    ttl: 486
    store: "memory"
  }
}
```
