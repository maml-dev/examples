# 7223 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "alarmed-apricot.info"
  inbound: {
    mx_records: [
      "mx1.alarmed-apricot.info"
      "mx2.alarmed-apricot.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.alarmed-apricot.info"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 210
      per_hour: 7789
    }
  }
}
```
