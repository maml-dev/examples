# 5430 - Theme Config

Design system theme configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  name: "impractical Theme"
  # Color palette
  colors: {
    primary: "#ddd723"
    secondary: "#ba7a41"
    accent: "#ed8ce8"
    background: "#f8f9fa"
    text: "#333333"

    error: "#dc3545"
    warning: "#ffc107"
    success: "#28a745"
  }

  # Typography
  typography: {
    font_family: "Inter, sans-serif"
    base_size: 14
    line_height: 1.5
    headings: {
      font_family: "Inter, sans-serif"
      weight: 700
    }
  }

  spacing: {
    unit: 4
    scale: [
      0
      4
      8
      16
      24
      32
      48
    ]
  }
  border_radius: 12
}
```
