# 13052 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "bad-role.biz"
  records: [
    {
      type: "MX"
      name: "cdn"
      value: "worthless-import.info"
      ttl: 86400
    }

    {
      type: "NS"
      name: "@"
      value: "v=spf1 include:_spf.elderly-awareness.info ~all"
      ttl: 300
    }

    {
      type: "CNAME"
      name: "@"
      value: "strident-promise.net"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "staging"
      value: "black-collectivization.com"
      ttl: 300
    }
  ]
}
```
