# 12851 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "manage_billing"
        "write"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "export_data"
        "delete"
        "read"
      ]
      max_seats: 9
    }

    {
      name: "moderator"
      permissions: [
        "manage_billing"
        "view_analytics"
        "export_data"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "manage_billing"
        "view_analytics"
        "write"
        "delete"
      ]
      max_seats: 27
    }
  ]
}
```
