# 10155 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Alt+F7"
      action: "format"
      when: "editor"
    }

    {
      key: "Ctrl+/"
      action: "debug_run"
      when: "editor"
    }

    {
      key: "Ctrl+`"
      action: "command_palette"
      when: "global"
    }

    {
      key: "Alt+Up"
      action: "debug_run"
      when: "global"
    }

    {
      key: "Cmd+Shift+L"
      action: "toggle_comment"
      when: "debug"
    }
  ]
}
```
