# 6897 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@ragged-stay.org"
  subject: "Trucido statua decet."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Amoveo somnus aedificium stipes demum thorax depraedor credo deputo benevolentia. Carus dapifer cognatus attero. Voluptatem copiose dolore vomica quasi celebrer ater.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Adsuesco cur cervus depopulo dolorum civis commodi civitas tenuis. Mollitia supplanto ducimus beatus acies. Volubilis constans denuncio utilis ancilla benevolentia thesaurus termes aspernatur.

Visit: {{url}}
"""
}
```
