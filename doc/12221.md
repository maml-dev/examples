# 12221 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.adolescent-bowling.name"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 5921
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://apprehensive-illusion.name"
      "https://app.helpful-character.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: true
    ttl: 1761
    store: "memory"
  }
}
```
