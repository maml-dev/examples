# 13657 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "first-asset.com"
  records: [
    {
      type: "A"
      name: "staging"
      value: "orange-chap.org"
      ttl: 3600
    }

    {
      type: "MX"
      name: "api"
      value: "v=spf1 include:_spf.gruesome-substitution.net ~all"
      ttl: 86400
    }

    {
      type: "NS"
      name: "*"
      value: "241.250.168.189"
      ttl: 300
    }

    {
      type: "TXT"
      name: "*"
      value: "121.160.152.141"
      ttl: 300
    }
  ]
}
```
