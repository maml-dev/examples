# 9539 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "systems"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 15 # seconds
    labels: {
      env: "staging"
      region: "eu-west"
      team: "automotive"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 89
    memory_threshold: 92
    latency_p99_ms: 1775
    error_rate: 0.01
    notification: {
      channel: "#ops-alerts"
      severity: "warning"
    }
  }
}
```
