# 12226 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "synergies"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 10 # seconds
    labels: {
      env: "staging"
      region: "ap-south"
      team: "baby"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 93
    memory_threshold: 94
    latency_p99_ms: 552
    error_rate: 0.05
    notification: {
      channel: "#oncall"
      severity: "info"
    }
  }
}
```
