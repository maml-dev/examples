# 4640 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "metallic-saw.info"
  inbound: {
    mx_records: [
      "mx1.metallic-saw.info"
      "mx2.metallic-saw.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.metallic-saw.info"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 307
      per_hour: 5956
    }
  }
}
```
