# 8655 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "DELETE"
      path: "/products"
      handler: "listOrders"
      auth: false
    }

    {
      method: "PATCH"
      path: "/orders"
      handler: "updateProducts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/users/:id"
      handler: "deleteProducts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/orders"
      handler: "updateProducts"
      auth: false
    }
  ]
}
```
