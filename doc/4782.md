# 4782 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "b88d59ef-5630-4376-af82-6c3aebafded0"
  Accept-Language: "de-DE"
  Cache-Control: "max-age=3600"
  X-Powered-By: "Express"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "super"
    "another one": "vulnero"
  }
}
```
