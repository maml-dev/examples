# 10296 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@everlasting-trench.biz"
  subject: "Cura careo considero volubilis alienus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Cruentus complectus attollo decretum tutamen abutor conatus adversus voro vomito. Ancilla circumvenio denique artificiose deorsum claro spero atque valens. Credo cavus laudantium.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Cura ratione via aveho similique ager vado. Defaeco cuius trado absque textor contra reprehenderit. Solutio alienus decet sit taceo callide advoco crustulum conspergo virtus.

Visit: {{url}}
"""
}
```
