# 10452 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "read"
        "view_analytics"
        "export_data"
      ]
      max_seats: 19
    }

    {
      name: "support"
      permissions: [
        "manage_users"
        "read"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "export_data"
        "write"
        "delete"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "read"
        "view_analytics"
        "manage_billing"
        "delete"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "manage_billing"
        "export_data"
      ]
      max_seats: null
    }
  ]
}
```
