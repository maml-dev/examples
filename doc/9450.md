# 9450 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "GET"
      path: "/users"
      handler: "createProducts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/posts/:id"
      handler: "deleteProducts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/products"
      handler: "createUsers"
      auth: false
    }

    {
      method: "PATCH"
      path: "/products/:id"
      handler: "deletePosts"
      auth: true
    }
  ]
}
```
