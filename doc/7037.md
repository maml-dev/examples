# 7037 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "government-worker"
    namespace: "production"
    labels: {
      app: "space"
      tier: "data"
    }
  }

  # Deployment spec
  spec: {
    replicas: 3
    container: {
      image: "pearl:1.8.7"
      port: 8080
      resources: {
        cpu_limit: "1000m"
        memory_limit: "1Gi"
      }
    }

    health_check: {
      path: "/health"
      interval: 30
      timeout: 10
    }
  }
}
```
