# 11696 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@other-giant.name"
  subject: "Velum ager deludo temperantia amicitia vir."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Praesentium utpote caecus. Cultura virtus callide. Sum celer adamo testimonium.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Cimentarius socius stips vereor voluptatibus acer accedo decens. Cruentus recusandae exercitationem curo nulla cognomen. Abduco videlicet aequus pel.

Visit: {{url}}
"""
}
```
