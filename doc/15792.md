# 15792 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@energetic-developmental.name"
  subject: "Cunae ascit arx truculenter conculco."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Crapula uredo inflammatio. Utrum demoror confido. Defaeco attero conturbo soleo.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Vitae utor aliquam curiositas vitiosus congregatio. Demergo tamen acidus. Coniecto reiciendis abeo atrocitas speculum caelestis cilicium peior usitas.

Visit: {{url}}
"""
}
```
