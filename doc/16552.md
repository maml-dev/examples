# 16552 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "read"
        "export_data"
        "view_analytics"
        "manage_users"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "manage_users"
        "read"
        "write"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "delete"
        "read"
        "manage_users"
      ]
      max_seats: 19
    }

    {
      name: "admin"
      permissions: [
        "manage_users"
        "write"
        "manage_billing"
        "read"
      ]
      max_seats: null
    }
  ]
}
```
