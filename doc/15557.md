# 15557 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "viewer"
      permissions: [
        "write"
        "export_data"
        "manage_billing"
      ]
      max_seats: 4
    }

    {
      name: "support"
      permissions: [
        "manage_billing"
        "manage_users"
        "view_analytics"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "view_analytics"
        "write"
        "export_data"
      ]
      max_seats: 46
    }
  ]
}
```
