# 5622 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.funny-exasperation.com"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 5165
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://ragged-elevator.com"
      "https://app.reckless-pension.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 1710
    store: "memory"
  }
}
```
