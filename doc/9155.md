# 9155 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "intent-essence.net"
  records: [
    {
      type: "A"
      name: "@"
      value: "shocked-merit.org"
      ttl: 86400
    }

    {
      type: "MX"
      name: "www"
      value: "edible-embossing.net"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "cdn"
      value: "hidden-swine.com"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "staging"
      value: "v=spf1 include:_spf.apt-divine.biz ~all"
      ttl: 86400
    }

    {
      type: "A"
      name: "staging"
      value: "hopeful-poppy.org"
      ttl: 3600
    }
  ]
}
```
