# 10756 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "DELETE"
      path: "/products/:id"
      handler: "listOrders"
      auth: false
    }

    {
      method: "GET"
      path: "/orders"
      handler: "updateUsers"
      auth: false
    }

    {
      method: "PATCH"
      path: "/posts/:id"
      handler: "listPosts"
      auth: false
    }

    {
      method: "PUT"
      path: "/products/:id"
      handler: "getUsers"
      auth: true
    }
  ]
}
```
