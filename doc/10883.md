# 10883 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "6ba00cc5-ea94-4656-a5de-7b4b32adfc34"
  Accept-Language: "ja-JP"
  Cache-Control: "public, max-age=86400"
  X-Powered-By: "Koa"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "canonicus"
    "another one": "arcesso"
  }
}
```
