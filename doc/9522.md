# 9522 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.rural-outlaw.info"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 2341
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://metallic-siege.info"
      "https://app.wiggly-cruelty.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 2383
    store: "memory"
  }
}
```
