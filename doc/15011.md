# 15011 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "faint-drive.org"
  ttl: 86400 # seconds
  nameservers: [
    "ns1.velvety-programme.com"
    "ns2.idolized-crocodile.info"
  ]

  soa_email: "admin@classic-costume.com"
  refresh: 3600
  retry: 1800
  expire: 604800
}
```
