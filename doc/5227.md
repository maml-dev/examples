# 5227 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.youthful-brief.biz"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 4865
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://yummy-molasses.net"
      "https://app.stylish-doorpost.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 1662
    store: "memory"
  }
}
```
