# 10327 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.athletic-godparent.com"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 3605
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://clear-underpants.name"
      "https://app.regal-executor.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 3441
    store: "redis"
  }
}
```
