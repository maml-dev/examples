# 6547 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "POST"
      path: "/products"
      handler: "listUsers"
      auth: false
    }

    {
      method: "GET"
      path: "/users"
      handler: "createUsers"
      auth: false
    }

    {
      method: "GET"
      path: "/users/:id"
      handler: "createOrders"
      auth: true
    }
  ]
}
```
