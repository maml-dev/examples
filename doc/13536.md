# 13536 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "warped-median.biz"
  inbound: {
    mx_records: [
      "mx1.warped-median.biz"
      "mx2.warped-median.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.warped-median.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 438
      per_hour: 5318
    }
  }
}
```
