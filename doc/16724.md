# 16724 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "crocodile-api"
    namespace: "default"
    labels: {
      app: "viability"
      tier: "frontend"
    }
  }

  # Deployment spec
  spec: {
    replicas: 2
    container: {
      image: "abacus:6.6.19"
      port: 8080
      resources: {
        cpu_limit: "1000m"
        memory_limit: "512Mi"
      }
    }

    health_check: {
      path: "/ready"
      interval: 10
      timeout: 10
    }
  }
}
```
