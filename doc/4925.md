# 4925 - Queue Config

Message queue and worker configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  broker: "kafka"
  connection: {
    host: "localhost"
    port: 6379
    vhost: "/staging"
  }

  # Queue definitions
  queues: {
    default: {
      concurrency: 1
      retry: 4
      timeout: 5864 # ms
    }

    priority: {
      concurrency: 12
      retry: 8
      timeout: 8154 # ms
    }
  }

  dead_letter: {
    enabled: true
    max_retries: 7
    queue: "dead-letter"
  }
}
```
