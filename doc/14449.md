# 14449 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Ctrl+D"
      action: "format"
      when: "terminal"
    }

    {
      key: "Alt+F7"
      action: "toggle_sidebar"
      when: "global"
    }

    {
      key: "F5"
      action: "search_project"
      when: "global"
    }

      when: "debug"

      when: "global"
    }

    {
      key: "Alt+F7"
      action: "select_all_occurrences"
      when: "editor"
    }
  ]
}
```
