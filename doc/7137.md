# 7137 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.multicolored-postbox.org"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 9537
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://punctual-scout.com"
      "https://app.whole-information.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: true
    ttl: 1834
    store: "redis"
  }
}
```
