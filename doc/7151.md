# 7151 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "viewer"
      permissions: [
        "manage_billing"
        "read"
        "write"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "export_data"
        "read"
        "delete"
        "write"
      ]
      max_seats: 31
    }

    {
      name: "support"
      permissions: [
        "manage_users"
        "view_analytics"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "write"
        "manage_users"
        "read"
      ]
      max_seats: 47
    }
  ]
}
```
