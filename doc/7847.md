# 7847 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "PUT"
      path: "/comments"
      handler: "listPosts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/comments"
      handler: "updateProducts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/comments/:id"
      handler: "createOrders"
      auth: false
    }

    {
      method: "DELETE"
      path: "/comments"
      handler: "getOrders"
      auth: false
    }

    {
      method: "GET"
      path: "/comments"
      handler: "createUsers"
      auth: false
    }

    {
      method: "GET"
      path: "/users"
      handler: "listUsers"
      auth: true
    }
  ]
}
```
