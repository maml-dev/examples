# 8958 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "swift-makeover.com"
  records: [
    {
      type: "A"
      name: "api"
      value: "47.196.250.150"
      ttl: 86400
    }

    {
      type: "MX"
      name: "@"
      value: "gloomy-legislature.biz"
      ttl: 3600
    }

    {
      type: "TXT"
      name: "@"
      value: "lustrous-confusion.biz"
      ttl: 3600
    }

    {
      type: "MX"
      name: "mail"
      value: "sleepy-case.name"
      ttl: 300
    }

    {
      type: "TXT"
      name: "mail"
      value: "warlike-cauliflower.com"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "mail"
      value: "v=spf1 include:_spf.wise-casket.biz ~all"
      ttl: 3600
    }

    {
      type: "A"
      name: "cdn"
      value: "quintessential-hydrocarbon.name"
      ttl: 3600
    }
  ]
}
```
