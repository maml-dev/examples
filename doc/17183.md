# 17183 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@burly-waist.name"
  subject: "Absconditus corporis sol adipisci cresco omnis."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Adimpleo amor statim. Similique degusto antea tergum aspicio chirographum. Cupressus admitto despecto.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Voco subito aeternus peior necessitatibus. Infit sperno deficio theca clarus clarus bene. Suppono crustulum facere adopto.

Visit: {{url}}
"""
}
```
