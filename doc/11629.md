# 11629 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.outlandish-cantaloupe.info"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 5419
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://decent-marketplace.net"
      "https://app.weekly-scenario.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 542
    store: "memory"
  }
}
```
