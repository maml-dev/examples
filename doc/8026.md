# 8026 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "solutions"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "staging"
      region: "eu-west"
      team: "garden"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 78
    memory_threshold: 79
    latency_p99_ms: 1066
    error_rate: 0.02
    notification: {
      channel: "#incidents"
      severity: "critical"
    }
  }
}
```
