# 14360 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "DELETE"
      path: "/comments/:id"
      handler: "getOrders"
      auth: true
    }

    {
      method: "GET"
      path: "/users/:id"
      handler: "deletePosts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/products/:id"
      handler: "deleteProducts"
      auth: false
    }

    {
      method: "GET"
      path: "/posts"
      handler: "createPosts"
      auth: true
    }
  ]
}
```
