# 7423 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "supply-chains"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 15 # seconds
    labels: {
      env: "prod"
      region: "us-east"
      team: "shoes"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 77
    memory_threshold: 77
    latency_p99_ms: 1830
    error_rate: 0.05
    notification: {
      channel: "#ops-alerts"
      severity: "warning"
    }
  }
}
```
