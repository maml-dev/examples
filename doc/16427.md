# 16427 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "second-hand-brochure.info"
  inbound: {
    mx_records: [
      "mx1.second-hand-brochure.info"
      "mx2.second-hand-brochure.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.second-hand-brochure.info"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 206
      per_hour: 9974
    }
  }
}
```
