# 13781 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "9d9ca479-d45f-46af-9e9d-b59091539ca9"
  Accept-Language: "en-US"
  Cache-Control: "max-age=3600"
  X-Powered-By: "Koa"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "soleo"
    "another one": "color"
  }
}
```
