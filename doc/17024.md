# 17024 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.corrupt-impact.org"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 8661
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://squeaky-hunger.name"
      "https://app.indelible-labourer.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 2938
    store: "memory"
  }
}
```
