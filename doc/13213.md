# 13213 - Logger Config

Structured logging configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  level: "fatal"
  format: "logfmt"
  timestamp: true
  caller: false # include file:line

  output: "stdout"
  rotation: true
  max_size_mb: 411
  max_age_days: 72
  compress: true
}
```
