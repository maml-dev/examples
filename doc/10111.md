# 10111 - Linter Config

Code linter rule configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  parser: "espree"
  env: "es2024"
  indent: 2
  semicolons: true
  quotes: "double"

  # Formatting
  max_line_length: 120
  trailing_comma: "none"
  no_unused_vars: true # error
  no_console: false # warn
}
```
