# 7460 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Ctrl+B"
      action: "debug_run"
      when: "editor"
    }

    {
      key: "Ctrl+B"
      action: "debug_run"
      when: "editor"
    }

    {
      key: "Ctrl+/"
      action: "select_all_occurrences"
      when: "global"
    }

    {
      key: "Ctrl+`"
      action: "select_all_occurrences"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+P"
      action: "save"
      when: "editor"
    }

    {
      key: "Ctrl+S"
      action: "search_project"
      when: "global"
    }

    {
      key: "Alt+F7"
      action: "toggle_comment"
      when: "debug"
    }
  ]
}
```
