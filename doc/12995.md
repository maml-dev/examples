# 12995 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "f4be324b-8a67-4f79-8c3b-9aff73f3e61a"
  Accept-Language: "fr-FR"
  Cache-Control: "max-age=3600"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "vulnus"
    "another one": "cum"
  }
}
```
