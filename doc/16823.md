# 16823 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "astonishing-handover.biz"
  inbound: {
    mx_records: [
      "mx1.astonishing-handover.biz"
      "mx2.astonishing-handover.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.astonishing-handover.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 110
      per_hour: 3394
    }
  }
}
```
