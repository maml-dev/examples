# 6228 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.square-phrase.info"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 2436
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://handsome-tail.biz"
      "https://app.hoarse-forager.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 3565
    store: "redis"
  }
}
```
