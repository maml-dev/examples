# 10986 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@untried-monasticism.info"
  subject: "Campana cunae trans apostolus comparo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Tersus creator tempore nobis defessus alter dicta deporto. Benigne colo articulus copia terga charisma consectetur copia auctor. Tremo atque tempore verbum talis caries.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Audeo consuasor conventus contabesco recusandae conculco eligendi terminatio. Aperiam delinquo damno. Pax curriculum arbor alveus tribuo cruciamentum.

Visit: {{url}}
"""
}
```
