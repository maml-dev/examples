# 12648 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Ctrl+`"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+F"
      action: "format"
      when: "debug"
    }

    {
      key: "Ctrl+S"
      action: "debug_run"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+F"
      action: "toggle_terminal"
      when: "global"
    }

    {
      key: "Cmd+Shift+L"
      action: "save"
      when: "editor"
    }

    {
      key: "Ctrl+`"
      action: "toggle_terminal"
      when: "terminal"
    }

    {
      key: "Ctrl+/"
      action: "save"
      when: "terminal"
    }
  ]
}
```
