# 4819 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "everlasting-kick.com"
  ttl: 300 # seconds
  nameservers: [
    "ns1.alarmed-pick.biz"
    "ns2.smoggy-gallery.com"
  ]

  soa_email: "admin@elderly-flint.info"
  refresh: 7200
  retry: 600
  expire: 604800
}
```
