# 15101 - Redis Config

Redis cache configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  host: "redis.internal"
  port: 6379
  db: 14
  password: null

  prefix: "passport:"
  ttl: 60423 # seconds
  max_retries: 2
}
```
