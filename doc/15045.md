# 15045 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Ctrl+S"
      action: "debug_run"
      when: "global"
    }

    {
      key: "Ctrl+S"
      action: "command_palette"
      when: "global"
    }

    {
      key: "Ctrl+Shift+F"
      action: "save"
      when: "editor"
    }

    {
      key: "Ctrl+S"
      action: "search_project"
      when: "global"
    }

    {
      key: "Alt+Up"
      action: "command_palette"
      when: "debug"
    }
  ]
}
```
