# 11120 - Logger Config

Structured logging configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  level: "fatal"
  format: "json"
  timestamp: true
  caller: true # include file:line

  output: "stderr"
  rotation: true
  max_size_mb: 51
  max_age_days: 68
  compress: true
}
```
