# 7041 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "secret-plastic.net"
  records: [
    {
      type: "MX"
      name: "cdn"
      value: "72.29.230.30"
      ttl: 86400
    }

    {
      type: "MX"
      name: "cdn"
      value: "166.29.112.112"
      ttl: 300
    }

    {
      type: "MX"
      name: "*"
      value: "v=spf1 include:_spf.mad-nudge.net ~all"
      ttl: 3600
    }

    {
      type: "NS"
      name: "@"
      value: "206.234.9.162"
      ttl: 300
    }

    {
      type: "A"
      name: "@"
      value: "89.64.182.9"
      ttl: 300
    }
  ]
}
```
