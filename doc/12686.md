# 12686 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "2052e8f4-9c18-4510-a0e4-df29567ee6c7"
  Accept-Language: "ja-JP"
  Cache-Control: "max-age=3600"
  X-Powered-By: "Fastify"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "venia"
    "another one": "quae"
  }
}
```
