# 9494 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@insecure-formula.info"
  subject: "Cado verbera adsidue validus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Maxime adopto compello cogito. Absque pecus cultellus. Sumptus decet audentia traho caritas adamo.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Condico dedico tepidus antiquus vicinus. Inflammatio adamo curso constans artificiose victoria delicate. Perferendis itaque aranea substantia crastinus patria.

Visit: {{url}}
"""
}
```
