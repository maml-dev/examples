# 12024 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "e-commerce"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 10 # seconds
    labels: {
      env: "prod"
      region: "ap-south"
      team: "books"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 71
    memory_threshold: 94
    latency_p99_ms: 963
    error_rate: 0.05
    notification: {
      channel: "#ops-alerts"
      severity: "info"
    }
  }
}
```
