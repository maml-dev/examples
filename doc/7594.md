# 7594 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@interesting-casket.org"
  subject: "Vapulus circumvenio admoneo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Valeo sophismata venia ulterius conscendo. Astrum adulatio carus arcesso delectatio convoco alter alveus cavus. Verecundia enim sumptus conduco defetiscor volva tibi arguo.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Unus aestivus acies asperiores optio decimus facilis appono assumenda. Spectaculum sordeo turba ratione. Ventosus cuppedia veniam acerbitas thermae.

Visit: {{url}}
"""
}
```
