# 13938 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "rectangular-barracks.net"
  inbound: {
    mx_records: [
      "mx1.rectangular-barracks.net"
      "mx2.rectangular-barracks.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.rectangular-barracks.net"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 500
      per_hour: 9940
    }
  }
}
```
