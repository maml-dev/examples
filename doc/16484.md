# 16484 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@rotten-steak.biz"
  subject: "Abeo spargo argentum."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Villa voluptatibus dolor cupio. Deludo possimus coniuratio aeger rem triumphus. Agnitio voluptates caterva speciosus abscido sophismata solum vomer.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Aeger absum sodalitas necessitatibus incidunt alias amiculum aer. Stella vero beatae sint. Cinis arbustum desipio.

Visit: {{url}}
"""
}
```
