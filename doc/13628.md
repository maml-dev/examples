# 13628 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "systems"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 10 # seconds
    labels: {
      env: "prod"
      region: "us-east"
      team: "health"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 94
    memory_threshold: 83
    latency_p99_ms: 1149
    error_rate: 0.05
    notification: {
      channel: "#incidents"
      severity: "info"
    }
  }
}
```
