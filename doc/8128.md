# 8128 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "functionalities"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 15 # seconds
    labels: {
      env: "prod"
      region: "ap-south"
      team: "music"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 72
    memory_threshold: 75
    latency_p99_ms: 418
    error_rate: 0.05
    notification: {
      channel: "#oncall"
      severity: "info"
    }
  }
}
```
