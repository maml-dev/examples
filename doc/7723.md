# 7723 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "pastel-awareness.net"
  inbound: {
    mx_records: [
      "mx1.pastel-awareness.net"
      "mx2.pastel-awareness.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.pastel-awareness.net"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 224
      per_hour: 3898
    }
  }
}
```
