# 10042 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+D"
      action: "search_project"
      when: "global"
    }

    {
      key: "Ctrl+D"
      action: "toggle_sidebar"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+P"
      action: "format"
      when: "global"
    }

    {
      key: "Ctrl+S"
      action: "save"
      when: "global"
    }

    {
      key: "Cmd+Shift+L"
      action: "search_project"
      when: "editor"
    }

    {
      key: "Cmd+K"
      action: "search_project"
      when: "editor"
    }
  ]
}
```
