# 6310 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "inconsequential-secret.biz"
  ttl: 86400 # seconds
  nameservers: [
    "ns1.overdue-deck.info"
    "ns2.livid-sonata.name"
  ]

  soa_email: "admin@wasteful-following.name"
  refresh: 3600
  retry: 600
  expire: 604800
}
```
