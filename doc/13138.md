# 13138 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "pleasing-cardboard.biz"
  inbound: {
    mx_records: [
      "mx1.pleasing-cardboard.biz"
      "mx2.pleasing-cardboard.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.pleasing-cardboard.biz"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 349
      per_hour: 3284
    }
  }
}
```
