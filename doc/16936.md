# 16936 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "artistic-almighty.com"
  inbound: {
    mx_records: [
      "mx1.artistic-almighty.com"
      "mx2.artistic-almighty.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.artistic-almighty.com"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 368
      per_hour: 3207
    }
  }
}
```
