# 10108 - Logger Config

Structured logging configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  level: "fatal"
  format: "pretty"
  timestamp: true
  caller: true # include file:line

  output: "stdout"
  rotation: true
  max_size_mb: 247
  max_age_days: 48
  compress: true
}
```
