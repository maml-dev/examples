# 16547 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "GET"
      path: "/orders/:id"
      handler: "updateProducts"
      auth: true
    }

    {
      method: "POST"
      path: "/orders"
      handler: "createProducts"
      auth: true
    }

    {
      method: "POST"
      path: "/comments"
      handler: "listProducts"
      auth: true
    }
  ]
}
```
