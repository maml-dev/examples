# 15291 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@svelte-thread.org"
  subject: "Depereo voluptatibus cenaculum denuncio."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Non officiis caries enim. Testimonium vaco capillus culpa cavus tardus corporis patruus. Adiuvo trans contigo aedificium sophismata caecus valens acies ascit crur.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Incidunt desidero eveniet conduco allatus depulso statim. Harum amita vereor contigo attero tepesco capto cum. Spes voluptas pecco.

Visit: {{url}}
"""
}
```
