# 5260 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "excellent-defendant.org"
  records: [
    {
      type: "NS"
      name: "www"
      value: "234.171.171.143"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "@"
      value: "knowledgeable-switch.biz"
      ttl: 300
    }

    {
      type: "TXT"
      name: "cdn"
      value: "v=spf1 include:_spf.utter-stool.info ~all"
      ttl: 86400
    }

    {
      type: "A"
      name: "mail"
      value: "waterlogged-electronics.biz"
      ttl: 300
    }
  ]
}
```
