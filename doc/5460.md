# 5460 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "delete"
        "read"
        "export_data"
        "manage_users"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "view_analytics"
        "read"
        "manage_billing"
        "write"
      ]
      max_seats: 9
    }

    {
      name: "billing"
      permissions: [
        "write"
        "manage_billing"
      ]
      max_seats: null
    }
  ]
}
```
