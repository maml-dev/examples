# 8556 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "physical-basket.name"
  records: [
    {
      type: "NS"
      name: "@"
      value: "pretty-alb.org"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "@"
      value: "strident-castanet.org"
      ttl: 300
    }

    {
      type: "CNAME"
      name: "api"
      value: "v=spf1 include:_spf.dead-defendant.biz ~all"
      ttl: 3600
    }

    {
      type: "A"
      name: "api"
      value: "182.109.136.252"
      ttl: 300
    }

    {
      type: "TXT"
      name: "cdn"
      value: "105.234.119.193"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "cdn"
      value: "v=spf1 include:_spf.hungry-bid.biz ~all"
      ttl: 300
    }

    {
      type: "NS"
      name: "*"
      value: "221.26.82.253"
      ttl: 300
    }
  ]
}
```
