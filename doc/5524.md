# 5524 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.ample-litter.info"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 3025
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://boring-object.net"
      "https://app.fortunate-hamburger.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 2955
    store: "redis"
  }
}
```
