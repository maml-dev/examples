# 9721 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.showy-nectarine.net"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 8120
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://impure-bookcase.biz"
      "https://app.prudent-grandpa.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 3488
    store: "memory"
  }
}
```
