# 9233 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "lively-sauerkraut.net"
  inbound: {
    mx_records: [
      "mx1.lively-sauerkraut.net"
      "mx2.lively-sauerkraut.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.lively-sauerkraut.net"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 83
      per_hour: 1635
    }
  }
}
```
