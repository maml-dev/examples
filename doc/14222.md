# 14222 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.unused-shoulder.info"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 6575
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://incomparable-bonnet.org"
      "https://app.mediocre-millet.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 2450
    store: "redis"
  }
}
```
