# 4655 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "DELETE"
      path: "/orders"
      handler: "deletePosts"
      auth: true
    }

    {
      method: "GET"
      path: "/posts"
      handler: "listOrders"
      auth: false
    }

    {
      method: "PATCH"
      path: "/orders"
      handler: "createPosts"
      auth: false
    }
  ]
}
```
