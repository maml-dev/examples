# 14954 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Ctrl+Shift+F"
      action: "format"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+P"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "Ctrl+S"
      action: "command_palette"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+P"
      action: "search_project"
      when: "global"
    }
  ]
}
```
