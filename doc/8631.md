# 8631 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "rich-stir-fry.net"
  inbound: {
    mx_records: [
      "mx1.rich-stir-fry.net"
      "mx2.rich-stir-fry.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.rich-stir-fry.net"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 431
      per_hour: 7582
    }
  }
}
```
