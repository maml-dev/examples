# 14253 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "pointed-wallaby.net"
  records: [
    {
      type: "TXT"
      name: "*"
      value: "10.227.142.201"
      ttl: 300
    }

    {
      type: "TXT"
      name: "*"
      value: "207.50.63.232"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "cdn"
      value: "30.18.193.235"
      ttl: 86400
    }

    {
      type: "A"
      name: "cdn"
      value: "70.251.212.62"
      ttl: 86400
    }
  ]
}
```
