# 9844 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "vivid-taxicab.name"
  records: [
    {
      type: "MX"
      name: "@"
      value: "v=spf1 include:_spf.radiant-clamp.org ~all"
      ttl: 300
    }

    {
      type: "NS"
      name: "@"
      value: "noted-suv.org"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "api"
      value: "18.26.81.176"
      ttl: 86400
    }

    {
      type: "MX"
      name: "@"
      value: "213.217.225.43"
      ttl: 300
    }

    {
      type: "CNAME"
      name: "www"
      value: "224.223.82.76"
      ttl: 300
    }

    {
      type: "NS"
      name: "api"
      value: "183.211.55.43"
      ttl: 300
    }

    {
      type: "NS"
      name: "staging"
      value: "1.150.222.190"
      ttl: 300
    }
  ]
}
```
