# 5840 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "gorgeous-colonialism.biz"
  inbound: {
    mx_records: [
      "mx1.gorgeous-colonialism.biz"
      "mx2.gorgeous-colonialism.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.gorgeous-colonialism.biz"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 153
      per_hour: 1251
    }
  }
}
```
