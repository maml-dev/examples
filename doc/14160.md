# 14160 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Cmd+K"
      action: "toggle_sidebar"
      when: "editor"
    }

    {
      key: "Ctrl+B"
      action: "search_project"
      when: "debug"
    }

    {
      key: "Ctrl+/"
      action: "toggle_comment"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+P"
      action: "format"
      when: "global"
    }

    {
      key: "Cmd+K"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Ctrl+D"
      action: "toggle_comment"
      when: "global"
    }
  ]
}
```
