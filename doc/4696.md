# 4696 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@entire-courtroom.name"
  subject: "Demulceo urbs cognatus conor."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Laboriosam universe deleo cursus deputo sint concido possimus conatus ulciscor. Minima spiculum consequatur. Undique aperte occaecati dicta tricesimus cibus eligendi subvenio vigor.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Coma utique custodia. Video vado constans talio alo. Video voluptate solio vito vestrum demo.

Visit: {{url}}
"""
}
```
