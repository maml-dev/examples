# 13100 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@assured-scarification.net"
  subject: "Barba adficio calculus vir."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Despecto tabgo totus tabella. Voveo deleniti decretum. Versus auctus umerus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Incidunt stella vorago aeneus tonsor audacia utpote arguo error. Corrumpo sordeo vito tamen abundans aiunt. Sumo aestus sophismata triumphus territo utrum conspergo sequi sumo.

Visit: {{url}}
"""
}
```
