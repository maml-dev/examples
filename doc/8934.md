# 8934 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.idealistic-majority.net"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 7457
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://sudden-dusk.info"
      "https://app.deadly-creature.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 2757
    store: "memory"
  }
}
```
