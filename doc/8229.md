# 8229 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.inferior-jump.biz"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 2212
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://upright-adviser.name"
      "https://app.clueless-elevator.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 1151
    store: "redis"
  }
}
```
