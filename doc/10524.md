# 10524 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.same-rim.org"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 6548
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://intent-duffel.info"
      "https://app.old-cosset.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: true
    ttl: 3078
    store: "memory"
  }
}
```
