# 16833 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "aggravating-comestible.name"
  inbound: {
    mx_records: [
      "mx1.aggravating-comestible.name"
      "mx2.aggravating-comestible.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.aggravating-comestible.name"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 61
      per_hour: 1602
    }
  }
}
```
