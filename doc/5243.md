# 5243 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Cmd+K"
      action: "format"
      when: "debug"
    }

    {
      key: "Alt+Up"
      action: "find_references"
      when: "editor"
    }

    {
      key: "Ctrl+D"
      action: "toggle_terminal"
      when: "global"
    }

    {
      key: "Ctrl+S"
      action: "toggle_sidebar"
      when: "editor"
    }

    {
      key: "Ctrl+B"
      action: "search_project"
      when: "editor"
    }

    {
      key: "Cmd+Shift+L"
      action: "command_palette"
      when: "debug"
    }

    {
      key: "Ctrl+S"
      action: "search_project"
      when: "editor"
    }
  ]
}
```
