# 8245 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "GET"
      path: "/users/:id"
      handler: "listPosts"
      auth: true
    }

    {
      method: "GET"
      path: "/users"
      handler: "listOrders"
      auth: false
    }

    {
      method: "POST"
      path: "/posts"
      handler: "deleteUsers"
      auth: false
    }

    {
      method: "GET"
      path: "/posts"
      handler: "deletePosts"
      auth: false
    }

    {
      method: "PUT"
      path: "/users"
      handler: "updateOrders"
      auth: false
    }

    {
      method: "POST"
      path: "/users/:id"
      handler: "listUsers"
      auth: false
    }

    {
      method: "POST"
      path: "/users"
      handler: "updateProducts"
      auth: true
    }
  ]
}
```
