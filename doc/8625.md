# 8625 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "cute-fort.name"
  inbound: {
    mx_records: [
      "mx1.cute-fort.name"
      "mx2.cute-fort.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.cute-fort.name"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 380
      per_hour: 6165
    }
  }
}
```
