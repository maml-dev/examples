# 16048 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "frizzy-alliance.biz"
  records: [
    {
      type: "MX"
      name: "mail"
      value: "41.200.242.231"
      ttl: 86400
    }

    {
      type: "NS"
      name: "api"
      value: "v=spf1 include:_spf.worthy-chainstay.com ~all"
      ttl: 86400
    }

    {
      type: "CNAME"
      name: "*"
      value: "v=spf1 include:_spf.messy-blowgun.name ~all"
      ttl: 3600
    }

    {
      type: "MX"
      name: "staging"
      value: "v=spf1 include:_spf.crooked-mobility.com ~all"
      ttl: 3600
    }

    {
      type: "TXT"
      name: "mail"
      value: "v=spf1 include:_spf.profuse-underpants.com ~all"
      ttl: 86400
    }
  ]
}
```
