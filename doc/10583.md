# 10583 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "f2e8da2e-0c70-484c-88bc-a3dc5970e7b5"
  Accept-Language: "fr-FR"
  Cache-Control: "no-cache"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "rerum"
    "another one": "canonicus"
  }
}
```
