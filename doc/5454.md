# 5454 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "export_data"
        "delete"
        "manage_billing"
        "manage_users"
        "read"
      ]
      max_seats: 3
    }

    {
      name: "moderator"
      permissions: [
        "read"
        "view_analytics"
        "export_data"
        "delete"
        "manage_users"
      ]
      max_seats: 34
    }

    {
      name: "billing"
      permissions: [
        "manage_users"
        "export_data"
        "write"
        "manage_billing"
        "delete"
      ]
      max_seats: 8
    }
  ]
}
```
