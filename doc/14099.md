# 14099 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "46859e26-bc59-467c-ae35-9874bc9c75d3"
  Accept-Language: "en-US"
  Cache-Control: "public, max-age=86400"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "casus"
    "another one": "demoror"
  }
}
```
