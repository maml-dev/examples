# 12155 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "read"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "delete"
        "read"
        "manage_users"
        "manage_billing"
      ]
      max_seats: 41
    }

    {
      name: "support"
      permissions: [
        "view_analytics"
        "manage_users"
      ]
      max_seats: 38
    }

    {
      name: "billing"
      permissions: [
        "manage_users"
        "read"
        "delete"
        "export_data"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "read"
        "manage_users"
        "view_analytics"
        "delete"
      ]
      max_seats: null
    }
  ]
}
```
