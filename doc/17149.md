# 17149 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "dead-nun.name"
  records: [
    {
      type: "A"
      name: "*"
      value: "v=spf1 include:_spf.obvious-sock.name ~all"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "cdn"
      value: "95.110.36.231"
      ttl: 3600
    }

    {
      type: "A"
      name: "mail"
      value: "v=spf1 include:_spf.orderly-waterspout.org ~all"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "@"
      value: "254.56.99.12"
      ttl: 300
    }

    {
      type: "MX"
      name: "*"
      value: "infamous-blossom.net"
      ttl: 3600
    }
  ]
}
```
