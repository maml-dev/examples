# 9322 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "web services"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 60 # seconds
    labels: {
      env: "staging"
      region: "eu-west"
      team: "outdoors"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 92
    memory_threshold: 77
    latency_p99_ms: 1763
    error_rate: 0.02
    notification: {
      channel: "#ops-alerts"
      severity: "warning"
    }
  }
}
```
