# 7297 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@ornery-ghost.info"
  subject: "Infit voluptas vulgus commemoro."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Neque subvenio architecto admiratio comis arcesso tenuis spiculum. Eaque doloribus facilis tunc succurro tantillus ventito voluptas. Caritas villa vobis.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Decor ago exercitationem vulgus defleo articulus bene vorax tamen. Vomer ambitus ager. Tolero thorax corpus demum defaeco quos speculum sto conculco.

Visit: {{url}}
"""
}
```
