# 9837 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "wriggler-api"
    namespace: "production"
    labels: {
      app: "vanadyl"
      tier: "frontend"
    }
  }

  # Deployment spec
  spec: {
    replicas: 1
    container: {
      image: "formula:9.3.6"
      port: 8000
      resources: {
        cpu_limit: "1000m"
        memory_limit: "512Mi"
      }
    }

    health_check: {
      path: "/health"
      interval: 30
      timeout: 10
    }
  }
}
```
