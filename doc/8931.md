# 8931 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "solutions"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 60 # seconds
    labels: {
      env: "prod"
      region: "ap-south"
      team: "tools"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 93
    memory_threshold: 90
    latency_p99_ms: 342
    error_rate: 0.02
    notification: {
      channel: "#oncall"
      severity: "critical"
    }
  }
}
```
