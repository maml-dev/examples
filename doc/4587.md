# 4587 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@essential-humor.net"
  subject: "Tamdiu coniecto valetudo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Contabesco animus sulum titulus statua animus aegrus desipio tardus. Desipio conforto doloribus tempore stips tibi voluptatibus abutor aperiam. Advenio blandior studio defluo subseco.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

In subseco ascit appositus cubo surculus video. Tempus callide adflicto creator solutio voluptate conculco. Delectus varietas testimonium demo sodalitas peior civitas benigne.

Visit: {{url}}
"""
}
```
