# 17241 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "GET"
      path: "/users/:id"
      handler: "listPosts"
      auth: true
    }

    {
      method: "POST"
      path: "/posts"
      handler: "updatePosts"
      auth: true
    }

    {
      method: "POST"
      path: "/orders"
      handler: "getProducts"
      auth: true
    }
  ]
}
```
