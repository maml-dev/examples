# 14525 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "affectionate-summer.name"
  inbound: {
    mx_records: [
      "mx1.affectionate-summer.name"
      "mx2.affectionate-summer.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.affectionate-summer.name"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 365
      per_hour: 7221
    }
  }
}
```
