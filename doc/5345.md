# 5345 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "DELETE"
      path: "/posts/:id"
      handler: "updateUsers"
      auth: true
    }

    {
      method: "PUT"
      path: "/products/:id"
      handler: "updatePosts"
      auth: true
    }

    {
      method: "POST"
      path: "/users"
      handler: "deleteProducts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/products"
      handler: "listUsers"
      auth: false
    }

    {
      method: "PUT"
      path: "/orders"
      handler: "getUsers"
      auth: false
    }

    {
      method: "PATCH"
      path: "/posts/:id"
      handler: "updateProducts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/orders"
      handler: "getProducts"
      auth: true
    }
  ]
}
```
