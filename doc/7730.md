# 7730 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "hard-to-find-obedience.net"
  inbound: {
    mx_records: [
      "mx1.hard-to-find-obedience.net"
      "mx2.hard-to-find-obedience.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.hard-to-find-obedience.net"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 330
      per_hour: 8409
    }
  }
}
```
