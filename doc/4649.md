# 4649 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "manage_billing"
        "view_analytics"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "manage_billing"
        "read"
        "manage_users"
      ]
      max_seats: 50
    }

    {
      name: "viewer"
      permissions: [
        "export_data"
        "delete"
        "view_analytics"
        "manage_billing"
      ]
      max_seats: 40
    }

    {
      name: "viewer"
      permissions: [
        "write"
        "delete"
      ]
      max_seats: 19
    }

    {
      name: "editor"
      permissions: [
        "write"
        "view_analytics"
        "delete"
        "manage_users"
        "manage_billing"
      ]
      max_seats: 28
    }
  ]
}
```
