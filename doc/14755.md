# 14755 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "GET"
      path: "/orders"
      handler: "getPosts"
      auth: true
    }

    {
      method: "GET"
      path: "/orders/:id"
      handler: "listOrders"
      auth: false
    }

    {
      method: "PUT"
      path: "/comments/:id"
      handler: "createUsers"
      auth: false
    }

    {
      method: "DELETE"
      path: "/users/:id"
      handler: "updatePosts"
      auth: true
    }
  ]
}
```
