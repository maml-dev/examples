# 14648 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PATCH"
      path: "/orders/:id"
      handler: "getOrders"
      auth: true
    }

    {
      method: "GET"
      path: "/comments/:id"
      handler: "createOrders"
      auth: true
    }

    {
      method: "DELETE"
      path: "/products/:id"
      handler: "listUsers"
      auth: true
    }

    {
      method: "PATCH"
      path: "/users/:id"
      handler: "updateProducts"
      auth: true
    }

    {
      method: "PUT"
      path: "/posts/:id"
      handler: "getUsers"
      auth: true
    }
  ]
}
```
