# 4472 - Docker Compose

Multi-container application definition. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  version: "3.8"
  services: {
    app: {
      image: "node:18-alpine"

        "3527:3991"
      ]
      environment: {
        NODE_ENV: "production"

      depends_on: [
        "db"
        "redis"
      ]
    }

    db: {
      image: "postgres:16"

      image: "redis:7-alpine"

        "6379:6379"
      ]
    }
  }

  volumes: {
    db_data: {}
  }
}
```
