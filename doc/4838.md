# 4838 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "disk-web"
    namespace: "staging"
    labels: {
      app: "monster"
      tier: "data"
    }
  }

  # Deployment spec
  spec: {
    replicas: 3
    container: {
      image: "celsius:0.1.0"
      port: 9090
      resources: {
        cpu_limit: "1000m"
        memory_limit: "512Mi"
      }
    }

    health_check: {
      path: "/ready"
      interval: 30
      timeout: 10
    }
  }
}
```
