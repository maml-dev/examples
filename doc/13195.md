# 13195 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@aggressive-detective.biz"
  subject: "Taedium cumque taceo cimentarius."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Deputo surculus comburo amplitudo. Adipiscor pecto laboriosam cum ambulo accommodo. Adeo sed caries verbum deficio quidem.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Claudeo cogo crux earum sperno cinis neque. Acerbitas sumptus distinctio cicuta surculus vulgivagus valeo conventus ustulo suadeo. Tondeo distinctio volup dapifer ullam subnecto decimus collum.

Visit: {{url}}
"""
}
```
