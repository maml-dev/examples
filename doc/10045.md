# 10045 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "striking-possession.info"
  records: [
    {
      type: "TXT"
      name: "api"
      value: "v=spf1 include:_spf.wretched-offset.org ~all"
      ttl: 300
    }

    {
      type: "NS"
      name: "@"
      value: "v=spf1 include:_spf.calculating-elevator.net ~all"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "www"
      value: "163.250.15.0"
      ttl: 86400
    }

    {
      type: "MX"
      name: "cdn"
      value: "64.171.219.15"
      ttl: 86400
    }
  ]
}
```
