# 16534 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "hungry-chapel.biz"
  inbound: {
    mx_records: [
      "mx1.hungry-chapel.biz"
      "mx2.hungry-chapel.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.hungry-chapel.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 135
      per_hour: 5766
    }
  }
}
```
