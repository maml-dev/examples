# 14092 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "b5242afc-f2f2-45cb-8add-e2b3f5732c4d"
  Accept-Language: "fr-FR"
  Cache-Control: "max-age=3600"
  X-Powered-By: "Express"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "illo"
    "another one": "deputo"
  }
}
```
