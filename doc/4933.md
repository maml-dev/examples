# 4933 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "troubled-airline.net"
  inbound: {
    mx_records: [
      "mx1.troubled-airline.net"
      "mx2.troubled-airline.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.troubled-airline.net"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 213
      per_hour: 3775
    }
  }
}
```
