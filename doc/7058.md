# 7058 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "GET"
      path: "/orders/:id"
      handler: "updateOrders"
      auth: true
    }

    {
      method: "GET"
      path: "/comments/:id"
      handler: "createProducts"
      auth: true
    }

    {
      method: "GET"
      path: "/orders/:id"
      handler: "listOrders"
      auth: true
    }

    {
      method: "PATCH"
      path: "/comments/:id"
      handler: "listUsers"
      auth: false
    }

    {
      method: "POST"
      path: "/comments/:id"
      handler: "deletePosts"
      auth: true
    }

    {
      method: "PUT"
      path: "/comments"
      handler: "updateProducts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/products"
      handler: "deleteUsers"
      auth: false
    }
  ]
}
```
