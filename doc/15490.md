# 15490 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "6061c5ea-b626-41b7-8ff5-048a8cb31ae1"
  Accept-Language: "en-US"
  Cache-Control: "max-age=3600"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "delicate"
    "another one": "territo"
  }
}
```
