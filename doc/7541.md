# 7541 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "manage_billing"
        "view_analytics"
        "export_data"
        "delete"
      ]
      max_seats: 8
    }

    {
      name: "editor"
      permissions: [
        "write"
        "manage_users"
        "manage_billing"
      ]
      max_seats: 4
    }

    {
      name: "editor"
      permissions: [
        "write"
        "manage_billing"
        "view_analytics"
        "delete"
      ]
      max_seats: 17
    }

    {
      name: "billing"
      permissions: [
        "export_data"
        "manage_users"
        "read"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "read"
        "manage_billing"
      ]
      max_seats: 26
    }
  ]
}
```
