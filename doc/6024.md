# 6024 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.good-natured-lady.net"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 2597
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://fond-stock.org"
      "https://app.vivid-thunderbolt.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 614
    store: "redis"
  }
}
```
