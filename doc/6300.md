# 6300 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@stark-papa.org"
  subject: "Sto bonus demulceo sto aureus adsum."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Calco quaerat depulso articulus communis vestigium aedificium callide aestus. Certe veritas cupressus solitudo. Audax viriliter spoliatio animadverto volup damno veritatis vesco baiulus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Vitium tego adimpleo deficio creptio exercitationem. Conculco una venio sint molestiae. Anser tertius clam aspicio cui conicio iusto.

Visit: {{url}}
"""
}
```
