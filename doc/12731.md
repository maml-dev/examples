# 12731 - Theme Config

Design system theme configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  name: "total Theme"
  # Color palette
  colors: {
    primary: "#ee1fc7"
    secondary: "#f6b2ba"
    accent: "#ed0e4c"

    text: "#333333"

    error: "#dc3545"
    warning: "#ffc107"
    success: "#28a745"
  }

  # Typography
  typography: {
    font_family: "system-ui, sans-serif"
    base_size: 14

      font_family: "\"Space Grotesk\", sans-serif"

    unit: 8
    scale: [
      0
      4
      8
      16
      24
      32
      48
    ]
  }
  border_radius: 4
}
```
