# 8596 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@putrid-membership.info"
  subject: "Carus consequatur coma."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Soluta utrum crepusculum vitae acies. Quasi baiulus contigo acer. Chirographum talio dolorum tondeo patria vinculum.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Color facere confido cotidie cupiditas. Sodalitas praesentium supellex depopulo turpis agnitio textilis cubitum utroque accusator. Coniuratio aestus volo perferendis abutor inflammatio taceo ascit tener calamitas.

Visit: {{url}}
"""
}
```
