# 15345 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "official-procurement.com"
  records: [
    {
      type: "TXT"
      name: "api"
      value: "4.123.106.91"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "www"
      value: "98.212.46.95"
      ttl: 3600
    }

    {
      type: "A"
      name: "*"
      value: "159.184.253.38"
      ttl: 300
    }

    {
      type: "MX"
      name: "staging"
      value: "dearest-tennis.org"
      ttl: 86400
    }

    {
      type: "TXT"
      name: "@"
      value: "152.195.53.247"
      ttl: 86400
    }
  ]
}
```
