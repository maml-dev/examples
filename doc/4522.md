# 4522 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "assist-web"
    namespace: "staging"
    labels: {
      app: "descendant"
      tier: "frontend"
    }
  }

  # Deployment spec
  spec: {
    replicas: 1
    container: {
      image: "diagram:9.9.20"
      port: 8080
      resources: {
        cpu_limit: "500m"
        memory_limit: "512Mi"
      }
    }

    health_check: {
      path: "/healthz"
      interval: 15
      timeout: 3
    }
  }
}
```
