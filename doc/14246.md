# 14246 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "warlike-championship.net"
  records: [
    {
      type: "TXT"
      name: "staging"
      value: "235.146.234.216"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "mail"
      value: "196.186.232.19"
      ttl: 3600
    }

    {
      type: "TXT"
      name: "mail"
      value: "crazy-fowl.biz"
      ttl: 300
    }

    {
      type: "MX"
      name: "www"
      value: "188.3.176.93"
      ttl: 300
    }

    {
      type: "NS"
      name: "www"
      value: "249.233.76.209"
      ttl: 300
    }
  ]
}
```
