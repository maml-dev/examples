# 8522 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.rare-godfather.com"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 128
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://accomplished-marten.org"
      "https://app.zealous-atrium.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 396
    store: "redis"
  }
}
```
