# 15355 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "DELETE"
      path: "/users"
      handler: "updateProducts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/posts/:id"
      handler: "getUsers"
      auth: true
    }

    {
      method: "PUT"
      path: "/products"
      handler: "listProducts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/posts"
      handler: "updatePosts"
      auth: false
    }

    {
      method: "GET"
      path: "/posts"
      handler: "listProducts"
      auth: false
    }
  ]
}
```
