# 17227 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "mature-priesthood.biz"
  inbound: {
    mx_records: [
      "mx1.mature-priesthood.biz"
      "mx2.mature-priesthood.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.mature-priesthood.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 429
      per_hour: 1494
    }
  }
}
```
