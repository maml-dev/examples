# 13688 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@messy-dwell.net"
  subject: "Cometes tredecim tamisium tametsi ascisco."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Conqueror spargo delectus adulatio cruciamentum defaeco demulceo. Utpote vilitas taceo defleo aeneus. Amicitia autem cribro cunae curia.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Vulnero varietas triumphus ventosus aveho tracto aufero conservo. Aestivus adversus minima trans tricesimus. Auctor usus via desidero appositus animus vorax civis conculco.

Visit: {{url}}
"""
}
```
