# 4934 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "pointed-desk.org"
  inbound: {
    mx_records: [
      "mx1.pointed-desk.org"
      "mx2.pointed-desk.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.pointed-desk.org"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 382
      per_hour: 6188
    }
  }
}
```
