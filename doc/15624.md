# 15624 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "paradigms"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 10 # seconds
    labels: {
      env: "prod"
      region: "us-east"
      team: "books"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 82
    memory_threshold: 92
    latency_p99_ms: 631
    error_rate: 0.01
    notification: {
      channel: "#incidents"
      severity: "warning"
    }
  }
}
```
