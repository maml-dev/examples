# 9930 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.utilized-import.name"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 4806
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://pretty-scout.com"
      "https://app.outgoing-barge.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: true
    ttl: 477
    store: "memory"
  }
}
```
