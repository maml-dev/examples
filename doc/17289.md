# 17289 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@inborn-stitcher.biz"
  subject: "Adsidue bis decens aspicio benevolentia sed."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Terror approbo comptus clibanus timidus celebrer sed fuga confugo. Dicta molestias verto angelus coma audeo vinculum possimus cresco. Accommodo non corrupti ambitus basium.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Virga arto vito deinde astrum comes enim laudantium aspicio. Stips demens carmen sufficio tam. Capio cilicium soleo spero.

Visit: {{url}}
"""
}
```
