# 12836 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "present-cake.org"
  inbound: {
    mx_records: [
      "mx1.present-cake.org"
      "mx2.present-cake.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.present-cake.org"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 253
      per_hour: 5320
    }
  }
}
```
