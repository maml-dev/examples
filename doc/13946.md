# 13946 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "GET"
      path: "/comments/:id"
      handler: "listOrders"
      auth: false
    }

    {
      method: "DELETE"
      path: "/posts"
      handler: "listPosts"
      auth: false
    }

    {
      method: "POST"
      path: "/users"
      handler: "deleteUsers"
      auth: true
    }

    {
      method: "POST"
      path: "/orders"
      handler: "updateUsers"
      auth: false
    }

    {
      method: "GET"
      path: "/posts/:id"
      handler: "listPosts"
      auth: true
    }
  ]
}
```
