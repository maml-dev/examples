# 11903 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "frugal-switchboard.com"
  ttl: 3600 # seconds
  nameservers: [
    "ns1.worst-term.info"
    "ns2.coarse-packaging.biz"
  ]

  soa_email: "admin@serpentine-diversity.com"
  refresh: 3600
  retry: 900
  expire: 604800
}
```
