# 16325 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "flimsy-presume.org"
  inbound: {
    mx_records: [
      "mx1.flimsy-presume.org"
      "mx2.flimsy-presume.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.flimsy-presume.org"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 110
      per_hour: 3501
    }
  }
}
```
