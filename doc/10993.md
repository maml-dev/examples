# 10993 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@closed-bathhouse.info"
  subject: "Absconditus avaritia decens curia."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Talis desino vestrum nulla atrocitas stips cohors vomica usus tendo. Sumo vespillo alioqui tego auctor. Admiratio auditor ago sum amet.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Vicissitudo demitto ventosus optio vacuus vulnus vulgus caput tunc. Conforto calculus suffoco. Alius solus capitulus pel alveus aer tamisium.

Visit: {{url}}
"""
}
```
