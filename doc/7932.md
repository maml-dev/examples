# 7932 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "honored-lashes.com"
  inbound: {
    mx_records: [
      "mx1.honored-lashes.com"
      "mx2.honored-lashes.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.honored-lashes.com"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 401
      per_hour: 2948
    }
  }
}
```
