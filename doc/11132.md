# 11132 - Theme Config

Design system theme configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  name: "rare Theme"
  # Color palette
  colors: {
    primary: "#035653"
    secondary: "#260fbd"
    accent: "#d6837e"
    background: "#f8f9fa"
    text: "#1a1a1a"

    error: "#dc3545"
    warning: "#ffc107"
    success: "#28a745"
  }

  # Typography
  typography: {
    font_family: "system-ui, sans-serif"
    base_size: 18
    line_height: 1.5
    headings: {
      font_family: "\"Space Grotesk\", sans-serif"
      weight: 800
    }

  spacing: {
    unit: 8
    scale: [
      0
      4
      8
      16
      24
      32
      48
    ]
  }
  border_radius: 4
}
```
