# 9857 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Ctrl+B"
      action: "search_project"
      when: "terminal"
    }

    {
      key: "Alt+F7"
      action: "search_project"
      when: "debug"
    }

    {
      key: "Alt+F7"
      action: "find_references"
      when: "editor"
    }

    {
      key: "F5"
      action: "find_references"
      when: "global"
    }

    {
      key: "Ctrl+S"
      action: "debug_run"
      when: "debug"
    }
  ]
}
```
