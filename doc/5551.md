# 5551 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Alt+F7"
      action: "toggle_sidebar"
      when: "editor"
    }

    {
      key: "Ctrl+B"
      action: "select_all_occurrences"
      when: "editor"
    }

    {
      key: "Alt+Up"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Alt+Up"
      action: "command_palette"
      when: "global"
    }

    {
      key: "Ctrl+/"
      action: "select_all_occurrences"
      when: "global"
    }
  ]
}
```
