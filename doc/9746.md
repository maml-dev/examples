# 9746 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "export_data"
        "manage_billing"
      ]
      max_seats: 12
    }

    {
      name: "support"
      permissions: [
        "delete"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "view_analytics"
        "read"
        "manage_users"
        "delete"
        "write"
      ]
      max_seats: null
    }
  ]
}
```
