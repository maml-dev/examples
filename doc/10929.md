# 10929 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "genuine-nougat.org"
  inbound: {
    mx_records: [
      "mx1.genuine-nougat.org"
      "mx2.genuine-nougat.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.genuine-nougat.org"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 429
      per_hour: 5300
    }
  }
}
```
