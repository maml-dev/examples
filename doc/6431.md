# 6431 - CI Pipeline

Continuous integration pipeline definition. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  name: "CI Pipeline"
  trigger: {
    branches: [
      "main"
      "develop"

    paths: [
      "src/**"
      "tests/**"
    ]
  }

  stages: {
    # Code quality

      image: "node:18"

    build: {
      image: "node:20"
      command: "npm run build"
      artifacts: [
        "dist/**"

      ]
    }
  }
}
```
