# 11355 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "strange-cork.com"
  records: [
    {
      type: "A"
      name: "api"
      value: "sniveling-smog.info"
      ttl: 86400
    }

    {
      type: "CNAME"
      name: "*"
      value: "v=spf1 include:_spf.willing-dress.biz ~all"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "www"
      value: "peppery-sonnet.org"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "api"
      value: "v=spf1 include:_spf.thin-conversation.name ~all"
      ttl: 300
    }

    {
      type: "CNAME"
      name: "www"
      value: "celebrated-editor.net"
      ttl: 86400
    }

    {
      type: "CNAME"
      name: "*"
      value: "v=spf1 include:_spf.major-shark.com ~all"
      ttl: 86400
    }
  ]
}
```
