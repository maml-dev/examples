# 10750 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PATCH"
      path: "/users"
      handler: "deleteProducts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/products"
      handler: "listOrders"
      auth: true
    }

    {
      method: "POST"
      path: "/orders/:id"
      handler: "getOrders"
      auth: true
    }
  ]
}
```
