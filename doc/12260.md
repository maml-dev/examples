# 12260 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "GET"
      path: "/orders"
      handler: "listProducts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/posts/:id"
      handler: "deleteUsers"
      auth: false
    }

    {
      method: "DELETE"
      path: "/orders/:id"
      handler: "updateUsers"
      auth: false
    }
  ]
}
```
