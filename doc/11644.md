# 11644 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "read"
        "view_analytics"
        "manage_billing"
      ]
      max_seats: 3
    }

    {
      name: "viewer"
      permissions: [
        "manage_billing"
        "read"
        "manage_users"
        "view_analytics"
        "write"
      ]
      max_seats: 38
    }

    {
      name: "viewer"
      permissions: [
        "manage_billing"
        "view_analytics"
        "read"
        "delete"
        "write"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "manage_users"
        "write"
        "delete"
      ]
      max_seats: 35
    }
  ]
}
```
