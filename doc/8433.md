# 8433 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.eminent-rawhide.info"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 5014
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://mysterious-boyfriend.com"
      "https://app.wicked-colon.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 1891
    store: "redis"
  }
}
```
