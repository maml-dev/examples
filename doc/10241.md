# 10241 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "write"
        "export_data"
        "read"
        "manage_users"
        "view_analytics"
      ]
      max_seats: 16
    }

    {
      name: "support"
      permissions: [
        "view_analytics"
        "delete"
        "write"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "manage_billing"
        "read"
      ]
      max_seats: 42
    }

    {
      name: "moderator"
      permissions: [
        "delete"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "export_data"
        "read"
        "manage_users"
      ]
      max_seats: 22
    }
  ]
}
```
