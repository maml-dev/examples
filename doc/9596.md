# 9596 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@hopeful-taxicab.biz"
  subject: "Aranea vitae tamen."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Vel urbs laudantium arma. Combibo solitudo degero. Talio ademptio ambitus cupressus valetudo odio natus assentator.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Velut inflammatio thymum thalassinus barba arma. Truculenter victus repudiandae succedo. Alveus vulpes aliquid.

Visit: {{url}}
"""
}
```
