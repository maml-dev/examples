# 11637 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "violent-deployment.com"
  inbound: {
    mx_records: [
      "mx1.violent-deployment.com"
      "mx2.violent-deployment.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.violent-deployment.com"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 197
      per_hour: 9674
    }
  }
}
```
