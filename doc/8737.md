# 8737 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "noteworthy-extension.net"
  inbound: {
    mx_records: [
      "mx1.noteworthy-extension.net"
      "mx2.noteworthy-extension.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.noteworthy-extension.net"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 160
      per_hour: 8905
    }
  }
}
```
