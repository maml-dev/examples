# 16053 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "manage_billing"
        "manage_users"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "manage_users"
        "delete"
        "export_data"
        "read"
        "write"
      ]
      max_seats: 11
    }

    {
      name: "admin"
      permissions: [
        "manage_billing"
        "view_analytics"
      ]
      max_seats: 22
    }

    {
      name: "viewer"
      permissions: [
        "export_data"
        "delete"
        "manage_billing"
      ]
      max_seats: null
    }
  ]
}
```
