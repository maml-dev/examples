# 11489 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "d8c954bd-c582-40ee-ab8a-60981d767233"
  Accept-Language: "fr-FR"
  Cache-Control: "no-cache"
  X-Powered-By: "Koa"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "calamitas"
    "another one": "cohaero"
  }
}
```
