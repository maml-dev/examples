# 14056 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Ctrl+S"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+F"
      action: "format"
      when: "debug"
    }

    {
      key: "Ctrl+S"
      action: "toggle_comment"
      when: "editor"
    }

    {
      key: "Cmd+K"
      action: "toggle_terminal"
      when: "terminal"
    }
  ]
}
```
