# 9000 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@palatable-cuckoo.info"
  subject: "Cui amplitudo curiositas conscendo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Vester demoror praesentium centum pecus vinco cito assentator curiositas. Ver quam curatio depereo trucido aveho. Curis harum despecto vilis vereor sperno talis volup acer.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Defungo carbo conculco et terror tandem. Itaque canto amaritudo cado dedecor voluptate suscipio cras aptus. Caterva sordeo umquam testimonium acies patria culpo.

Visit: {{url}}
"""
}
```
