# 7536 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "sick-fog.com"
  inbound: {
    mx_records: [
      "mx1.sick-fog.com"
      "mx2.sick-fog.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.sick-fog.com"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 151
      per_hour: 6630
    }
  }
}
```
