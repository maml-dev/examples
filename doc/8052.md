# 8052 - Font Stack

Typography font family definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  fonts: [
    {
      family: "JetBrains Mono"
      category: "sans-serif"
      weights: [
        100
        500
        600
        800
        900
      ]
      variable: true
    }

    {
      family: "Geist"
      category: "display"
      weights: [
        300
        500
        600
      ]
      variable: false
    }

    {
      family: "JetBrains Mono"
      category: "monospace"
      weights: [
        100
        400
        700
        900
      ]
      variable: false
    }
  ]
}
```
