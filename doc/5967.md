# 5967 - Dashboard Layout

Dashboard widget layout configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  title: "Hessel, Rohan and Hickle Dashboard"
  refresh_interval: 30 # seconds
  widgets: [
    {
      type: "chart"
      title: "Signups"
      source: "/api/metrics/revenue"
      chart_type: "area"
      period: "90d"

    {
      type: "stat"
      title: "Uptime"

      type: "table"

    }
  ]

  theme: "auto"
}
```
