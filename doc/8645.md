# 8645 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "export_data"
        "write"
        "read"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "write"
        "delete"
        "read"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "export_data"
        "write"
        "view_analytics"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "manage_billing"
        "write"
        "export_data"
        "view_analytics"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "manage_billing"
        "manage_users"
        "delete"
        "read"
      ]
      max_seats: null
    }
  ]
}
```
