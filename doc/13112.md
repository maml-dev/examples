# 13112 - SSH Config

SSH client host configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  host: "production"
  hostname: "3.69.172.131"
  user: "sadie_hackett"
  port: 2222
  identity_file: "~/.ssh/id_ed25519"

  forward_agent: true
  server_alive_interval: 30
  compression: true
}
```
