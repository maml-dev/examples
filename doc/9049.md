# 9049 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Alt+F7"
      action: "toggle_sidebar"
      when: "debug"
    }

    {
      key: "Cmd+K"
      action: "format"
      when: "terminal"
    }

    {
      key: "Ctrl+S"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "Cmd+K"
      action: "search_project"
      when: "editor"
    }

    {
      key: "Ctrl+`"
      action: "toggle_comment"
      when: "terminal"
    }

    {
      key: "F5"
      action: "search_project"
      when: "debug"
    }
  ]
}
```
