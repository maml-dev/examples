# 11321 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "hateful-skeleton.org"
  inbound: {
    mx_records: [
      "mx1.hateful-skeleton.org"
      "mx2.hateful-skeleton.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.hateful-skeleton.org"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 265
      per_hour: 9745
    }
  }
}
```
