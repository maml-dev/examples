# 5929 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "flat-worker"
    namespace: "staging"
    labels: {
      app: "mom"
      tier: "frontend"
    }
  }

  # Deployment spec
  spec: {
    replicas: 5
    container: {
      image: "hyphenation:4.20.1"
      port: 9090
      resources: {
        cpu_limit: "1000m"
        memory_limit: "512Mi"
      }
    }

    health_check: {
      path: "/health"
      interval: 10
      timeout: 10
    }
  }
}
```
