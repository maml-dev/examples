# 16821 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "wrathful-galoshes.biz"
  inbound: {
    mx_records: [
      "mx1.wrathful-galoshes.biz"
      "mx2.wrathful-galoshes.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.wrathful-galoshes.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 332
      per_hour: 6803
    }
  }
}
```
