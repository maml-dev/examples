# 14373 - Dashboard Layout

Dashboard widget layout configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  title: "Greenfelder Group Dashboard"
  refresh_interval: 30 # seconds
  widgets: [
    {
      type: "chart"
      title: "Active Users"
      source: "/api/metrics/traffic"
      chart_type: "area"
      period: "90d"
    }

    {
      type: "stat"
      title: "Total Users"
      source: "/api/stats/users"
      format: "currency"
    }

    {
      type: "table"
      title: "Recent Orders"
      source: "/api/recent/orders"
      limit: 14
    }
  ]

  theme: "auto"
}
```
