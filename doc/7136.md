# 7136 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "gruesome-peony.com"
  inbound: {
    mx_records: [
      "mx1.gruesome-peony.com"
      "mx2.gruesome-peony.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.gruesome-peony.com"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 300
      per_hour: 7589
    }
  }
}
```
