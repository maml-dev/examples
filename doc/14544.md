# 14544 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "chilly-ethyl.biz"
  records: [
    {
      type: "TXT"
      name: "www"
      value: "baggy-millet.org"
      ttl: 3600
    }

    {
      type: "NS"
      name: "api"
      value: "57.13.252.252"
      ttl: 3600
    }

    {
      type: "NS"
      name: "@"
      value: "mammoth-monster.net"
      ttl: 3600
    }

    {
      type: "NS"
      name: "*"
      value: "v=spf1 include:_spf.grimy-reservation.biz ~all"
      ttl: 3600
    }

    {
      type: "TXT"
      name: "mail"
      value: "137.175.27.63"
      ttl: 3600
    }
  ]
}
```
