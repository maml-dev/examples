# 6742 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PATCH"
      path: "/posts"
      handler: "deletePosts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/users"
      handler: "updatePosts"
      auth: true
    }

    {
      method: "GET"
      path: "/users"
      handler: "deleteUsers"
      auth: false
    }

    {
      method: "GET"
      path: "/users/:id"
      handler: "updatePosts"
      auth: false
    }

    {
      method: "PUT"
      path: "/orders/:id"
      handler: "deleteProducts"
      auth: true
    }
  ]
}
```
