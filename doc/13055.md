# 13055 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "manage_users"
        "delete"
        "export_data"
        "read"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "read"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "delete"
        "export_data"
        "manage_billing"
      ]
      max_seats: null
    }
  ]
}
```
