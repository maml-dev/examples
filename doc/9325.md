# 9325 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "bouncy-singing.info"
  inbound: {
    mx_records: [
      "mx1.bouncy-singing.info"
      "mx2.bouncy-singing.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.bouncy-singing.info"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 112
      per_hour: 1934
    }
  }
}
```
