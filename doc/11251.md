# 11251 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "POST"
      path: "/posts/:id"
      handler: "updateUsers"
      auth: false
    }

    {
      method: "PUT"
      path: "/orders"
      handler: "updatePosts"
      auth: true
    }

    {
      method: "PUT"
      path: "/posts"
      handler: "updatePosts"
      auth: true
    }

    {
      method: "POST"
      path: "/orders/:id"
      handler: "getPosts"
      auth: false
    }

    {
      method: "POST"
      path: "/posts"
      handler: "updateOrders"
      auth: false
    }

    {
      method: "GET"
      path: "/products/:id"
      handler: "deletePosts"
      auth: true
    }
  ]
}
```
