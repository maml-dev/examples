# 11125 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.pricey-loaf.biz"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 9519
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://nutritious-shore.name"
      "https://app.cuddly-coast.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: true
    ttl: 3137
    store: "memory"
  }
}
```
