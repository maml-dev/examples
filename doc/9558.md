# 9558 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "read"
        "delete"
      ]
      max_seats: 18
    }

    {
      name: "admin"
      permissions: [
        "manage_users"
        "write"
      ]
      max_seats: 37
    }

    {
      name: "admin"
      permissions: [
        "manage_billing"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "manage_users"
        "export_data"
        "manage_billing"
      ]
      max_seats: 2
    }
  ]
}
```
