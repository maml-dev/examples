# 15037 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "primary-pearl.com"
  inbound: {
    mx_records: [
      "mx1.primary-pearl.com"
      "mx2.primary-pearl.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.primary-pearl.com"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 144
      per_hour: 2017
    }
  }
}
```
