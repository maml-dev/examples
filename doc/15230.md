# 15230 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "lazy-reasoning.biz"
  inbound: {
    mx_records: [
      "mx1.lazy-reasoning.biz"
      "mx2.lazy-reasoning.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.lazy-reasoning.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 468
      per_hour: 4967
    }
  }
}
```
