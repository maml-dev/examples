# 4936 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "carefree-ice-cream.name"
  inbound: {
    mx_records: [
      "mx1.carefree-ice-cream.name"
      "mx2.carefree-ice-cream.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.carefree-ice-cream.name"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 208
      per_hour: 5093
    }
  }
}
```
