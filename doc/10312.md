# 10312 - Linter Config

Code linter rule configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  parser: "espree"
  env: "browser"
  indent: 4
  semicolons: false
  quotes: "single"

  # Formatting
  max_line_length: 80
  trailing_comma: "es5"
  no_unused_vars: true # error
  no_console: false # warn
}
```
