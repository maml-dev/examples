# 16746 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "manage_billing"
        "write"
        "delete"
        "manage_users"
      ]
      max_seats: 35
    }

    {
      name: "viewer"
      permissions: [
        "view_analytics"
        "manage_users"
        "manage_billing"
        "read"
      ]
      max_seats: 16
    }

    {
      name: "moderator"
      permissions: [
        "export_data"
        "delete"
        "manage_billing"
      ]
      max_seats: 27
    }

    {
      name: "editor"
      permissions: [
        "delete"
        "view_analytics"
        "export_data"
      ]
      max_seats: 8
    }
  ]
}
```
