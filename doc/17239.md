# 17239 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "sad-velocity.biz"
  inbound: {
    mx_records: [
      "mx1.sad-velocity.biz"
      "mx2.sad-velocity.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.sad-velocity.biz"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 125
      per_hour: 2403
    }
  }
}
```
