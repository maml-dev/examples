# 15159 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "sticky-brochure.biz"
  records: [
    {
      type: "NS"
      name: "*"
      value: "shady-spring.name"
      ttl: 300
    }

    {
      type: "TXT"
      name: "*"
      value: "129.145.221.15"
      ttl: 86400
    }

    {
      type: "NS"
      name: "mail"
      value: "superior-godparent.info"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "staging"
      value: "v=spf1 include:_spf.fine-grass.net ~all"
      ttl: 3600
    }

    {
      type: "TXT"
      name: "@"
      value: "103.64.221.236"
      ttl: 3600
    }

    {
      type: "A"
      name: "*"
      value: "sudden-commodity.name"
      ttl: 3600
    }
  ]
}
```
