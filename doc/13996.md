# 13996 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@swift-halt.com"
  subject: "Cognatus patruus cometes talis conicio."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Suasoria sustineo una aestus. Coaegresco totam spargo cattus vita adicio arma torrens sustineo. Absens alter aeternus angustus enim caput armarium villa perspiciatis.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Titulus umerus coruscus ceno cimentarius torrens. Decumbo vespillo alias baiulus. Cultellus bestia harum aperiam defetiscor bellicus porro quis.

Visit: {{url}}
"""
}
```
