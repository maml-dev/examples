# 4845 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "PUT"
      path: "/comments"
      handler: "getOrders"
      auth: true
    }

    {
      method: "POST"
      path: "/comments/:id"
      handler: "getUsers"
      auth: true
    }

    {
      method: "PUT"
      path: "/comments"
      handler: "deleteProducts"
      auth: true
    }

    {
      method: "POST"
      path: "/posts/:id"
      handler: "deletePosts"
      auth: false
    }
  ]
}
```
