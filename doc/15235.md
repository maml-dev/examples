# 15235 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.sparkling-tackle.net"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 9700
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://ultimate-cuckoo.com"
      "https://app.tepid-fen.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 2896
    store: "redis"
  }
}
```
