# 14245 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "POST"
      path: "/products"
      handler: "deleteOrders"
      auth: true
    }

    {
      method: "POST"
      path: "/orders"
      handler: "createUsers"
      auth: true
    }

    {
      method: "POST"
      path: "/posts/:id"
      handler: "listUsers"
      auth: true
    }

    {
      method: "GET"
      path: "/users"
      handler: "deletePosts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/products/:id"
      handler: "listOrders"
      auth: false
    }
  ]
}
```
