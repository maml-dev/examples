# 5952 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Ctrl+Shift+F"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Ctrl+`"
      action: "command_palette"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+P"
      action: "search_project"
      when: "global"
    }
  ]
}
```
