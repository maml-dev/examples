# 6137 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "questionable-thigh.name"
  inbound: {
    mx_records: [
      "mx1.questionable-thigh.name"
      "mx2.questionable-thigh.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.questionable-thigh.name"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 268
      per_hour: 5407
    }
  }
}
```
