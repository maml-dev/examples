# 12595 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "fda7ecd3-e7f3-40ce-bb51-c8e05b621819"
  Accept-Language: "fr-FR"
  Cache-Control: "max-age=3600"
  X-Powered-By: "Express"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "cui"
    "another one": "arma"
  }
}
```
