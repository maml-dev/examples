# 17148 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "F5"
      action: "select_all_occurrences"
      when: "global"
    }

    {
      key: "Ctrl+Shift+F"
      action: "format"
      when: "debug"
    }

    {
      key: "Ctrl+D"
      action: "search_project"
      when: "terminal"
    }

    {
      key: "Ctrl+B"
      action: "select_all_occurrences"
      when: "debug"
    }

    {
      key: "Ctrl+S"
      action: "save"
      when: "global"
    }

    {
      key: "Cmd+K"
      action: "toggle_terminal"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+P"
      action: "toggle_comment"
      when: "terminal"
    }
  ]
}
```
