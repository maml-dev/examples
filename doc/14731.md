# 14731 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "schemas"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 10 # seconds
    labels: {
      env: "prod"
      region: "ap-south"
      team: "automotive"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 74
    memory_threshold: 75
    latency_p99_ms: 826
    error_rate: 0.02
    notification: {
      channel: "#oncall"
      severity: "warning"
    }
  }
}
```
