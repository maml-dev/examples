# 11038 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "trench-worker"
    namespace: "staging"
    labels: {
      app: "granny"
      tier: "frontend"
    }
  }

  # Deployment spec
  spec: {
    replicas: 2
    container: {
      image: "chairperson:4.14.17"
      port: 8000
      resources: {
        cpu_limit: "500m"
        memory_limit: "512Mi"
      }
    }

    health_check: {
      path: "/ready"
      interval: 10
      timeout: 10
    }
  }
}
```
