# 7656 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "dense-stitcher.name"
  records: [
    {
      type: "TXT"
      name: "api"
      value: "83.14.157.168"
      ttl: 3600
    }

    {
      type: "NS"
      name: "cdn"
      value: "outlying-attraction.com"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "staging"
      value: "v=spf1 include:_spf.fond-formation.info ~all"
      ttl: 300
    }

    {
      type: "TXT"
      name: "api"
      value: "favorable-tarragon.biz"
      ttl: 3600
    }

    {
      type: "A"
      name: "staging"
      value: "v=spf1 include:_spf.heavenly-graffiti.biz ~all"
      ttl: 3600
    }
  ]
}
```
