# 12018 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "homely-porter.name"
  ttl: 86400 # seconds
  nameservers: [
    "ns1.infamous-stall.info"
    "ns2.firsthand-t-shirt.info"
  ]

  soa_email: "admin@insecure-publicity.info"
  refresh: 14400
  retry: 1800
  expire: 604800
}
```
