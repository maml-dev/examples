# 5488 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@honorable-equal.biz"
  subject: "Vulnero tergum benigne degenero sequi somniculosus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Certe strenuus stabilis adicio verecundia depopulo capio vomito tepesco degero. Tantillus textor turpis carus minus. Tergeo supellex assumenda.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Sui triduana nisi statim dignissimos benigne tenuis nobis eaque. Calcar decumbo iusto audentia cedo explicabo advenio. Sub caterva derelinquo paulatim thermae coniecto advenio adulescens tam.

Visit: {{url}}
"""
}
```
