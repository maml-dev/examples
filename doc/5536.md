# 5536 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "needy-forager.name"
  inbound: {
    mx_records: [
      "mx1.needy-forager.name"
      "mx2.needy-forager.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.needy-forager.name"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 430
      per_hour: 6359
    }
  }
}
```
