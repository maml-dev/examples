# 15257 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "view_analytics"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "delete"
        "view_analytics"
        "export_data"
        "write"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "manage_users"
        "delete"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "view_analytics"
        "manage_users"
        "write"
        "read"
      ]
      max_seats: 24
    }
  ]
}
```
