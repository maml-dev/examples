# 14528 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "rubbery-bathhouse.org"
  inbound: {
    mx_records: [
      "mx1.rubbery-bathhouse.org"
      "mx2.rubbery-bathhouse.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.rubbery-bathhouse.org"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 472
      per_hour: 8350
    }
  }
}
```
