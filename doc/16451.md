# 16451 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Alt+Up"
      action: "select_all_occurrences"
      when: "editor"
    }

    {
      key: "Ctrl+`"
      action: "toggle_comment"
      when: "global"
    }

    {
      key: "Cmd+K"
      action: "find_references"
      when: "debug"
    }

    {
      key: "Cmd+Shift+L"
      action: "toggle_comment"
      when: "global"
    }

    {
      key: "Cmd+K"
      action: "format"
      when: "terminal"
    }

    {
      key: "Alt+F7"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Alt+F7"
      action: "search_project"
      when: "global"
    }
  ]
}
```
