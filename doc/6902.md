# 6902 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "unhappy-analogy.biz"
  ttl: 3600 # seconds
  nameservers: [
    "ns1.thin-galoshes.net"
    "ns2.faint-disappointment.com"
  ]

  soa_email: "admin@awesome-bungalow.info"

  retry: 600
  expire: 604800
}
```
