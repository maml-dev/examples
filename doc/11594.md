# 11594 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@concerned-steak.org"
  subject: "Angulus video astrum vorax consequatur consuasor."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Pecus adipisci coepi amoveo talio uredo. Solio eius tergo provident. Thesis cicuta ambulo depereo tumultus debilito claustrum utpote antepono.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Campana adflicto atque paens ad creo pax suppono damnatio. Cilicium verecundia fugit cibo adsum excepturi. Usque abbas quae dens porro decimus suggero.

Visit: {{url}}
"""
}
```
