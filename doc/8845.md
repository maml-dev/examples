# 8845 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "viewer"
      permissions: [
        "export_data"
        "write"
        "manage_billing"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "delete"
        "read"
      ]
      max_seats: 20
    }

    {
      name: "billing"
      permissions: [
        "manage_billing"
        "read"
      ]
      max_seats: 35
    }
  ]
}
```
