# 14453 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "view_analytics"
        "export_data"
        "manage_users"
      ]
      max_seats: 1
    }

    {
      name: "admin"
      permissions: [
        "manage_users"
        "export_data"
      ]
      max_seats: 42
    }

    {
      name: "moderator"
      permissions: [
        "manage_billing"
        "write"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "export_data"
        "read"
      ]
      max_seats: null
    }
  ]
}
```
