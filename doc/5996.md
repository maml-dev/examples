# 5996 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@filthy-alb.info"
  subject: "Administratio necessitatibus saepe blandior."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Demitto delicate vulgivagus aeger cogito substantia. Contra atque vitium antea viduo atqui adnuo. Tabula arguo unus somniculosus velit cena decet.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Capillus voluptatum amplexus paulatim causa vestigium tametsi. Appello amiculum soleo desolo depraedor unde spoliatio confido tepidus. Cuppedia voluntarius suscipit sunt viriliter cunctatio adfero.

Visit: {{url}}
"""
}
```
