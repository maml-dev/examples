# 7765 - Dashboard Layout

Dashboard widget layout configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  title: "Denesik, Daniel and Schultz Dashboard"
  refresh_interval: 30 # seconds
  widgets: [
    {
      type: "chart"
      title: "Active Users"
      source: "/api/metrics/traffic"
      chart_type: "bar"
      period: "90d"
    }

    {
      type: "stat"
      title: "Uptime"
      source: "/api/stats/users"
      format: "currency"
    }

    {
      type: "table"
      title: "Top Pages"
      source: "/api/recent/signups"
      limit: 23
    }
  ]

  theme: "auto"
}
```
