# 17200 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "fe5b906b-3eb2-40d5-8c28-cafd3daafbf4"
  Accept-Language: "ja-JP"
  Cache-Control: "public, max-age=86400"
  X-Powered-By: "Express"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "quaerat"
    "another one": "assentator"
  }
}
```
