# 13896 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@early-perfection.net"
  subject: "Vorago possimus consuasor sumptus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Illum suus utrum soleo tyrannus umquam vesper mollitia valde. Unde tabgo quibusdam territo ceno solus acies corroboro. Adiuvo despecto armarium aequus suadeo soleo vinitor.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Ullus caelestis damno delicate vinculum alienus deficio adhuc eaque illo. Appono communis utroque conicio facere nesciunt damno paulatim cultellus pariatur. Voluptatibus decretum patria omnis bonus tamisium volva vicissitudo pax vigor.

Visit: {{url}}
"""
}
```
