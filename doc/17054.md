# 17054 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "manage_users"
        "view_analytics"
        "write"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "manage_users"
        "manage_billing"
      ]
      max_seats: 19
    }

    {
      name: "admin"
      permissions: [
        "manage_billing"
        "read"
        "delete"
        "export_data"
        "write"
      ]
      max_seats: null
    }
  ]
}
```
