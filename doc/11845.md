# 11845 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "manage_billing"
        "view_analytics"
      ]
      max_seats: 35
    }

    {
      name: "billing"
      permissions: [
        "write"
        "manage_users"
      ]
      max_seats: 1
    }

    {
      name: "moderator"
      permissions: [
        "view_analytics"
        "read"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "delete"
        "read"
      ]
      max_seats: 48
    }
  ]
}
```
