# 12424 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "e-commerce"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 60 # seconds
    labels: {
      env: "staging"
      region: "ap-south"
      team: "electronics"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 73
    memory_threshold: 75
    latency_p99_ms: 179
    error_rate: 0.05
    notification: {
      channel: "#oncall"
      severity: "critical"
    }
  }
}
```
