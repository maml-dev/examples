# 14756 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Ctrl+/"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Cmd+K"
      action: "find_references"
      when: "global"
    }

    {
      key: "Ctrl+Shift+F"
      action: "format"
      when: "editor"
    }

    {
      key: "Ctrl+D"
      action: "toggle_comment"
      when: "global"
    }

    {
      key: "Alt+Up"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "Ctrl+D"
      action: "format"
      when: "global"
    }
  ]
}
```
