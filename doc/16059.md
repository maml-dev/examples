# 16059 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "PUT"
      path: "/products/:id"
      handler: "listProducts"
      auth: true
    }

    {
      method: "GET"
      path: "/users"
      handler: "listPosts"
      auth: true
    }

    {
      method: "PUT"
      path: "/comments/:id"
      handler: "listUsers"
      auth: false
    }

    {
      method: "PUT"
      path: "/comments"
      handler: "updateProducts"
      auth: false
    }

    {
      method: "GET"
      path: "/posts/:id"
      handler: "createPosts"
      auth: true
    }
  ]
}
```
