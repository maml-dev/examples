# 12560 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PUT"
      path: "/posts"
      handler: "deletePosts"
      auth: true
    }

    {
      method: "POST"
      path: "/orders"
      handler: "deleteUsers"
      auth: false
    }

    {
      method: "PUT"
      path: "/users"
      handler: "getPosts"
      auth: false
    }

    {
      method: "PUT"
      path: "/orders"
      handler: "createProducts"
      auth: false
    }
  ]
}
```
