# 5758 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Ctrl+D"
      action: "format"
      when: "global"
    }

    {
      key: "Cmd+Shift+L"
      action: "toggle_terminal"
      when: "editor"
    }

    {
      key: "F5"
      action: "find_references"
      when: "editor"
    }

    {
      key: "Alt+Up"
      action: "format"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+P"
      action: "find_references"
      when: "debug"
    }
  ]
}
```
