# 8841 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "write"
        "manage_users"
        "view_analytics"
      ]
      max_seats: 13
    }

    {
      name: "viewer"
      permissions: [
        "manage_billing"
        "view_analytics"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "delete"
        "manage_users"
      ]
      max_seats: 12
    }
  ]
}
```
