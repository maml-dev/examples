# 4425 - Theme Config

Design system theme configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  name: "dirty Theme"
  # Color palette
  colors: {
    primary: "#e3e5c2"
    secondary: "#e1ddba"
    accent: "#5150ac"
    background: "#ffffff"
    text: "#e6edf3"

    error: "#dc3545"
    warning: "#ffc107"
    success: "#28a745"
  }

  # Typography
  typography: {
    font_family: "system-ui, sans-serif"
    base_size: 16
    line_height: 1.6
    headings: {
      font_family: "Inter, sans-serif"
      weight: 800
    }
  }

  spacing: {
    unit: 4
    scale: [
      0
      4
      8
      16
      24
      32
      48
    ]
  }
  border_radius: 6
}
```
