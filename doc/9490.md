# 9490 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@sour-designation.biz"
  subject: "Vestigium cuius fugit."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Deripio aptus cultellus. Clamo adeptio teres accommodo cura debilito tripudio curso spargo. Valens excepturi convoco casus theologus xiphias verecundia illo doloribus caries.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Trucido arceo damnatio voluptatem constans. A veritas turpis curatio cognatus tubineus volutabrum administratio vulpes. Beatus vero peior aurum abduco caries trucido carmen ascit.

Visit: {{url}}
"""
}
```
