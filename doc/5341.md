# 5341 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+Shift+P"
      action: "toggle_sidebar"
      when: "global"
    }

    {
      key: "Alt+F7"
      action: "find_references"
      when: "editor"
    }

    {
      key: "Ctrl+S"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Cmd+Shift+L"
      action: "debug_run"
      when: "terminal"
    }
  ]
}
```
