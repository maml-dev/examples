# 15034 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "monstrous-schedule.biz"
  inbound: {
    mx_records: [
      "mx1.monstrous-schedule.biz"
      "mx2.monstrous-schedule.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.monstrous-schedule.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 493
      per_hour: 4590
    }
  }
}
```
