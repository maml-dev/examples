# 16251 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "obvious-freckle.org"
  records: [
    {
      type: "CNAME"
      name: "mail"
      value: "v=spf1 include:_spf.legal-electronics.name ~all"
      ttl: 3600
    }

    {
      type: "TXT"
      name: "*"
      value: "thin-maintainer.org"
      ttl: 86400
    }

    {
      type: "A"
      name: "*"
      value: "happy-farm.biz"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "@"
      value: "35.251.83.86"
      ttl: 3600
    }
  ]
}
```
