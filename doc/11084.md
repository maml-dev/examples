# 11084 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "221a960b-6fdd-4110-bf52-3aaad13fc847"
  Accept-Language: "en-US"
  Cache-Control: "max-age=3600"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "sonitus"
    "another one": "utique"
  }
}
```
