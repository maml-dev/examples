# 14118 - SSH Config

SSH client host configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  host: "bastion"
  hostname: "34.48.109.29"
  user: "esteban.bauch34"
  port: 2222
  identity_file: "~/.ssh/id_rsa"

  forward_agent: false
  server_alive_interval: 30
  compression: true
}
```
