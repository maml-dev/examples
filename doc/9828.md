# 9828 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "bad-scratch.name"
  inbound: {
    mx_records: [
      "mx1.bad-scratch.name"
      "mx2.bad-scratch.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.bad-scratch.name"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 466
      per_hour: 8382
    }
  }
}
```
