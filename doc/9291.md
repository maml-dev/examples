# 9291 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@dapper-silk.name"
  subject: "Sponte asporto cultellus tracto."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Consectetur qui ceno utpote abstergo studio. Vergo canis cresco viridis cras sonitus artificiose demergo. Quidem illo toties varius comprehendo ocer sursum voluptatem sortitus deserunt.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Desolo sodalitas argumentum valens administratio considero thermae aliqua vulnero tabesco. Arbitro sodalitas vos blanditiis. Derelinquo clibanus statim patruus.

Visit: {{url}}
"""
}
```
