# 4540 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "fantastic-teriyaki.com"
  inbound: {
    mx_records: [
      "mx1.fantastic-teriyaki.com"
      "mx2.fantastic-teriyaki.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.fantastic-teriyaki.com"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 152
      per_hour: 2280
    }
  }
}
```
