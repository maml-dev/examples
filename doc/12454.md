# 12454 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "read"
        "write"
        "manage_billing"
        "delete"
      ]
      max_seats: 19
    }

    {
      name: "support"
      permissions: [
        "manage_users"
        "manage_billing"
        "export_data"
      ]
      max_seats: 44
    }

    {
      name: "editor"
      permissions: [
        "write"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "view_analytics"
        "read"
      ]
      max_seats: null
    }
  ]
}
```
