# 11843 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Ctrl+S"
      action: "format"
      when: "editor"
    }

    {
      key: "Cmd+K"
      action: "debug_run"
      when: "editor"
    }

    {
      key: "Cmd+K"
      action: "search_project"
      when: "editor"
    }

    {
      key: "Ctrl+/"
      action: "format"
      when: "debug"
    }

    {
      key: "Cmd+Shift+L"
      action: "select_all_occurrences"
      when: "debug"
    }
  ]
}
```
