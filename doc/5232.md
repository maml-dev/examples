# 5232 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.proper-relative.biz"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 8731
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://favorable-freezing.com"
      "https://app.valuable-scorn.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 1078
    store: "memory"
  }
}
```
