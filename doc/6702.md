# 6702 - Email Config

SMTP email service settings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  smtp_host: "smtp.grim-request.name"
  smtp_port: 25
  use_tls: true
  from_name: "Adams and Sons"
  from_email: "noreply@grim-request.name"

  # Rate limiting
  max_batch_size: 192
  retry_interval: 254
}
```
