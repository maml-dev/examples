# 7981 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@enlightened-dream.org"
  subject: "Aegre conventus tergeo ago."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Condico tener degero deinde cohibeo truculenter. Deduco curia abscido. Calco averto laboriosam eaque atrocitas deludo caelestis ciminatio administratio vita.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Repudiandae via virtus alias claro abundans tollo. Deludo somnus thalassinus facilis attero degero fugit defungo acer. Socius canto tardus certus cupio bis accendo adimpleo voro.

Visit: {{url}}
"""
}
```
