# 6429 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "spherical-pillbox.info"
  inbound: {
    mx_records: [
      "mx1.spherical-pillbox.info"
      "mx2.spherical-pillbox.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.spherical-pillbox.info"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 63
      per_hour: 4603
    }
  }
}
```
