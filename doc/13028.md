# 13028 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "clavicle-worker"
    namespace: "default"
    labels: {
      app: "jazz"
      tier: "backend"
    }
  }

  # Deployment spec
  spec: {
    replicas: 2
    container: {
      image: "annual:7.3.2"
      port: 9090
      resources: {
        cpu_limit: "1000m"
        memory_limit: "512Mi"
      }
    }

    health_check: {
      path: "/healthz"
      interval: 15
      timeout: 10
    }
  }
}
```
