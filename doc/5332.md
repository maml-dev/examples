# 5332 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "pitiful-pantyhose.info"
  inbound: {
    mx_records: [
      "mx1.pitiful-pantyhose.info"
      "mx2.pitiful-pantyhose.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.pitiful-pantyhose.info"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 413
      per_hour: 5923
    }
  }
}
```
