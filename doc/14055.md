# 14055 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+D"
      action: "debug_run"
      when: "editor"
    }

    {
      key: "Ctrl+B"
      action: "toggle_terminal"
      when: "debug"
    }

    {
      key: "Alt+Up"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Alt+F7"
      action: "toggle_sidebar"
      when: "global"
    }

    {
      key: "Alt+F7"
      action: "command_palette"
      when: "editor"
    }
  ]
}
```
