# 6681 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@ecstatic-zebra.com"
  subject: "Viriliter casus vesco cras universe vaco."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Cohibeo abstergo bos decretum catena cui considero tabella bos. Suffoco deficio cauda crastinus. Uberrime carus aurum copiose cuppedia decretum caste sumptus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Defluo denuncio possimus debitis adulatio vinum articulus. Conor aliquid dolor bellicus audacia tonsor crebro. Autem virtus suppellex.

Visit: {{url}}
"""
}
```
