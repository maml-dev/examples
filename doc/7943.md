# 7943 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PATCH"
      path: "/posts/:id"
      handler: "getOrders"
      auth: true
    }

    {
      method: "DELETE"
      path: "/comments/:id"
      handler: "listProducts"
      auth: false
    }

    {
      method: "PUT"
      path: "/products"
      handler: "updatePosts"
      auth: false
    }
  ]
}
```
