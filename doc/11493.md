# 11493 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@good-natured-doubter.name"
  subject: "Solutio succedo substantia averto eveniet conforto."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Abscido vilicus alii aurum. Turpis demulceo tametsi traho complectus. Numquam compono velut aduro summa.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Pecto veritatis chirographum decretum pecus. Depulso cubicularis vir celer maiores carus. Crebro tenuis surgo arto voluptatibus comminor amo ratione.

Visit: {{url}}
"""
}
```
