# 13596 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@tinted-someplace.info"
  subject: "Summa vapulus vulgaris."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Atrocitas deleniti auditor laboriosam valens pauper cubitum. Quas articulus aduro ter natus volaticus animus. Cui damno victoria quam acer.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Pauci minus cedo ater celo currus cuius ducimus. Defessus deputo arca adfectus constans incidunt vomica adsuesco victus ultra. Patrocinor adstringo synagoga adinventitias aedificium consectetur timidus.

Visit: {{url}}
"""
}
```
