# 10552 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "joyful-puritan.info"
  records: [
    {
      type: "A"
      name: "*"
      value: "difficult-nougat.com"
      ttl: 300
    }

    {
      type: "A"
      name: "www"
      value: "noted-corral.org"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "api"
      value: "average-hydrolyze.info"
      ttl: 300
    }

    {
      type: "A"
      name: "cdn"
      value: "stormy-spear.biz"
      ttl: 3600
    }
  ]
}
```
