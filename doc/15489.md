# 15489 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@colorless-jogging.net"
  subject: "Commodo alias vulticulus mollitia."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Vulnero articulus audentia caelum veniam aeger molestiae calculus crustulum. Vicinus vita sub agnosco benevolentia excepturi calcar iure tabesco aestas. Sit demo aufero ustilo repudiandae decumbo thymum.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Vespillo templum sumptus ara talus canis. Voluptatum comminor conventus cruentus ascisco angelus carmen earum dolor. Acidus cognomen adeptio aspernatur tricesimus.

Visit: {{url}}
"""
}
```
