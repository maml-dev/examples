# 15750 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Cmd+K"
      action: "toggle_comment"
      when: "editor"
    }

    {
      key: "Alt+F7"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Alt+F7"
      action: "toggle_sidebar"
      when: "global"
    }

    {
      key: "Cmd+Shift+L"
      action: "command_palette"
      when: "global"
    }

    {
      key: "Ctrl+D"
      action: "select_all_occurrences"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+P"
      action: "select_all_occurrences"
      when: "global"
    }
  ]
}
```
