# 7045 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "manage_billing"
        "delete"
        "write"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "read"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "write"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "view_analytics"
        "export_data"
      ]
      max_seats: 13
    }
  ]
}
```
