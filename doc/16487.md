# 16487 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@free-linseed.org"
  subject: "Odit acervus quos verbera."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Aliquid tyrannus veritatis ait. Sursum amplitudo adiuvo curiositas thesaurus. Facere cursim depono comptus caterva supellex.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Centum damnatio subnecto defleo vix stella. Vestigium sponte cruciamentum advoco magni curis clarus totam pecto campana. Arx sperno suadeo adamo abbas comptus.

Visit: {{url}}
"""
}
```
