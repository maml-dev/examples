# 12016 - Email Config

SMTP email service settings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  smtp_host: "smtp.ornery-creature.net"
  smtp_port: 465
  use_tls: true
  from_name: "Feeney, Schowalter and Lubowitz"
  from_email: "noreply@ornery-creature.net"

  # Rate limiting
  max_batch_size: 171
  retry_interval: 148
}
```
