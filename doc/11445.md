# 11445 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "view_analytics"
        "manage_billing"
        "delete"
        "read"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "write"
        "read"
      ]
      max_seats: 41
    }

    {
      name: "admin"
      permissions: [
        "delete"
        "export_data"
        "manage_billing"
      ]
      max_seats: 31
    }
  ]
}
```
