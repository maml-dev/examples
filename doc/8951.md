# 8951 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "PUT"
      path: "/products"
      handler: "getOrders"
      auth: false
    }

    {
      method: "GET"
      path: "/products/:id"
      handler: "getUsers"
      auth: false
    }

    {
      method: "POST"
      path: "/products"
      handler: "updatePosts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/posts"
      handler: "getPosts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/posts"
      handler: "listOrders"
      auth: false
    }

    {
      method: "POST"
      path: "/posts/:id"
      handler: "getProducts"
      auth: true
    }

    {
      method: "PUT"
      path: "/comments"
      handler: "listOrders"
      auth: true
    }
  ]
}
```
