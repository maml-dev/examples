# 11941 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PUT"
      path: "/comments"
      handler: "updatePosts"
      auth: true
    }

    {
      method: "PUT"
      path: "/users"
      handler: "updatePosts"
      auth: true
    }

    {
      method: "POST"
      path: "/posts/:id"
      handler: "deleteOrders"
      auth: true
    }

    {
      method: "PATCH"
      path: "/comments"
      handler: "createUsers"
      auth: false
    }

    {
      method: "DELETE"
      path: "/comments"
      handler: "deleteProducts"
      auth: true
    }

    {
      method: "PUT"
      path: "/orders/:id"
      handler: "createOrders"
      auth: true
    }

    {
      method: "DELETE"
      path: "/comments/:id"
      handler: "updatePosts"
      auth: true
    }
  ]
}
```
