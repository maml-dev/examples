# 6445 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "devoted-going.name"
  records: [
    {
      type: "A"
      name: "staging"
      value: "merry-topsail.info"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "*"
      value: "vivacious-help.biz"
      ttl: 300
    }

    {
      type: "A"
      name: "*"
      value: "v=spf1 include:_spf.brilliant-disconnection.info ~all"
      ttl: 86400
    }

    {
      type: "A"
      name: "staging"
      value: "108.169.174.95"
      ttl: 3600
    }

    {
      type: "TXT"
      name: "*"
      value: "20.105.80.231"
      ttl: 300
    }
  ]
}
```
