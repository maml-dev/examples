# 6528 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "impolite-case.org"
  inbound: {
    mx_records: [
      "mx1.impolite-case.org"
      "mx2.impolite-case.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.impolite-case.org"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 488
      per_hour: 4955
    }
  }
}
```
