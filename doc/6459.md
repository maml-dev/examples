# 6459 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "DELETE"
      path: "/comments/:id"
      handler: "updateProducts"
      auth: true
    }

    {
      method: "PUT"
      path: "/comments/:id"
      handler: "updateUsers"
      auth: false
    }

    {
      method: "GET"
      path: "/comments"
      handler: "getPosts"
      auth: false
    }

    {
      method: "POST"
      path: "/comments"
      handler: "createPosts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/comments"
      handler: "createProducts"
      auth: false
    }

    {
      method: "POST"
      path: "/posts"
      handler: "getOrders"
      auth: true
    }

    {
      method: "GET"
      path: "/orders"
      handler: "deleteOrders"
      auth: true
    }
  ]
}
```
