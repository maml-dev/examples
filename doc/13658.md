# 13658 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "carefree-window.biz"
  records: [
    {
      type: "TXT"
      name: "mail"
      value: "webbed-guidance.org"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "cdn"
      value: "upset-importance.name"
      ttl: 300
    }

    {
      type: "MX"
      name: "api"
      value: "shimmering-dead.biz"
      ttl: 86400
    }

    {
      type: "A"
      name: "api"
      value: "v=spf1 include:_spf.well-groomed-deployment.info ~all"
      ttl: 3600
    }
  ]
}
```
