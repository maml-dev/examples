# 10826 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "courageous-dead.com"
  inbound: {
    mx_records: [
      "mx1.courageous-dead.com"
      "mx2.courageous-dead.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.courageous-dead.com"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 270
      per_hour: 3180
    }
  }
}
```
