# 16443 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Cmd+Shift+L"
      action: "select_all_occurrences"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+F"
      action: "toggle_sidebar"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+P"
      action: "find_references"
      when: "global"
    }

    {
      key: "Ctrl+`"
      action: "select_all_occurrences"
      when: "editor"
    }

    {
      key: "Ctrl+/"
      action: "save"
      when: "terminal"
    }

    {
      key: "Alt+F7"
      action: "command_palette"
      when: "editor"
    }
  ]
}
```
