# 13258 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "ugly-interior.org"
  records: [
    {
      type: "MX"
      name: "mail"
      value: "245.152.155.96"
      ttl: 3600
    }

    {
      type: "A"
      name: "*"
      value: "neighboring-pendant.info"
      ttl: 300
    }

    {
      type: "A"
      name: "@"
      value: "clear-cut-hygienic.net"
      ttl: 3600
    }

    {
      type: "NS"
      name: "mail"
      value: "207.84.229.221"
      ttl: 86400
    }

    {
      type: "MX"
      name: "@"
      value: "quiet-defendant.info"
      ttl: 3600
    }

    {
      type: "NS"
      name: "cdn"
      value: "v=spf1 include:_spf.downright-mom.name ~all"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "www"
      value: "v=spf1 include:_spf.partial-interviewer.com ~all"
      ttl: 86400
    }
  ]
}
```
