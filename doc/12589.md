# 12589 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "d66b335c-1887-49f3-995f-afc36014bd04"
  Accept-Language: "de-DE"
  Cache-Control: "no-cache"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "eaque"
    "another one": "adflicto"
  }
}
```
