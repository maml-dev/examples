# 7542 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "manage_billing"
        "read"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "view_analytics"
        "delete"
        "manage_billing"
        "read"
      ]
      max_seats: 46
    }

    {
      name: "viewer"
      permissions: [
        "view_analytics"
        "delete"
      ]
      max_seats: 28
    }

    {
      name: "moderator"
      permissions: [
        "write"
        "manage_billing"
        "read"
        "export_data"
      ]
      max_seats: null
    }
  ]
}
```
