# 14488 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@spotless-offset.org"
  subject: "Bestia absens consuasor supellex."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Delicate vesica ullam vulnero eligendi benigne corrigo communis. Unus valens minus verecundia considero. Officia uter stella adopto tergeo magnam tergo arto.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Terebro tum bene artificiose saepe perspiciatis depereo. Cumque ulterius odit. Communis sequi ut tolero itaque abduco conculco sono vereor caritas.

Visit: {{url}}
"""
}
```
