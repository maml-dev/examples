# 16339 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "unused-invite.org"
  inbound: {
    mx_records: [
      "mx1.unused-invite.org"
      "mx2.unused-invite.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.unused-invite.org"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 328
      per_hour: 7360
    }
  }
}
```
