# 5957 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PATCH"
      path: "/posts"
      handler: "updateUsers"
      auth: false
    }

    {
      method: "GET"
      path: "/products"
      handler: "getProducts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/orders/:id"
      handler: "getUsers"
      auth: false
    }

    {
      method: "PUT"
      path: "/posts/:id"
      handler: "createOrders"
      auth: true
    }

    {
      method: "DELETE"
      path: "/posts/:id"
      handler: "listPosts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/comments"
      handler: "getProducts"
      auth: false
    }
  ]
}
```
