# 13714 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "bare-desk.info"
  ttl: 600 # seconds
  nameservers: [
    "ns1.stingy-casket.org"
    "ns2.those-cleaner.org"
  ]

  soa_email: "admin@another-digit.name"
  refresh: 7200
  retry: 1800
  expire: 604800
}
```
