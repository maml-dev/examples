# 15850 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "delete"
        "manage_billing"
        "manage_users"
        "write"
      ]
      max_seats: 36
    }

    {
      name: "admin"
      permissions: [
        "delete"
        "manage_billing"
        "manage_users"
      ]
      max_seats: 28
    }

    {
      name: "moderator"
      permissions: [
        "manage_users"
        "manage_billing"
        "view_analytics"
        "read"
      ]
      max_seats: 42
    }

    {
      name: "support"
      permissions: [
        "view_analytics"
        "manage_billing"
        "manage_users"
        "export_data"
        "delete"
      ]
      max_seats: 11
    }
  ]
}
```
