# 11826 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "unrealistic-minister.org"
  inbound: {
    mx_records: [
      "mx1.unrealistic-minister.org"
      "mx2.unrealistic-minister.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.unrealistic-minister.org"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 128
      per_hour: 8047
    }
  }
}
```
