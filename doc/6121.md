# 6121 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "legal-underneath.net"
  inbound: {
    mx_records: [
      "mx1.legal-underneath.net"
      "mx2.legal-underneath.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.legal-underneath.net"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 289
      per_hour: 4673
    }
  }
}
```
