# 14428 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.impeccable-contrail.org"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 6466
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://outrageous-tenant.com"
      "https://app.tragic-eternity.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: true
    ttl: 1948
    store: "redis"
  }
}
```
