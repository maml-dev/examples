# 6134 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "lumpy-knitting.biz"
  inbound: {
    mx_records: [
      "mx1.lumpy-knitting.biz"
      "mx2.lumpy-knitting.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.lumpy-knitting.biz"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 387
      per_hour: 8396
    }
  }
}
```
