# 8829 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "bossy-charm.biz"
  inbound: {
    mx_records: [
      "mx1.bossy-charm.biz"
      "mx2.bossy-charm.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.bossy-charm.biz"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 229
      per_hour: 6219
    }
  }
}
```
