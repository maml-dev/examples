# 14296 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@inferior-adult.name"
  subject: "Vorax desino degenero."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Tracto bestia circumvenio voluptatum delectatio coerceo cohibeo. Calcar vulgus decens demergo occaecati currus tego blandior. Carmen cilicium dolores.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Depopulo canto uredo adopto adeo. Deorsum acervus tunc cernuus adipiscor amet odit taedium colo. Conculco molestias capio tantum coaegresco turpis sum.

Visit: {{url}}
"""
}
```
