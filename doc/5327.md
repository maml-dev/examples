# 5327 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "critical-grandson.biz"
  inbound: {
    mx_records: [
      "mx1.critical-grandson.biz"
      "mx2.critical-grandson.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.critical-grandson.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 458
      per_hour: 9368
    }
  }
}
```
