# 15555 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "read"
        "view_analytics"
        "write"
        "export_data"
      ]
      max_seats: 25
    }

    {
      name: "editor"
      permissions: [
        "manage_billing"
        "write"
      ]
      max_seats: 27
    }

    {
      name: "support"
      permissions: [
        "manage_billing"
        "export_data"
        "read"
        "delete"
      ]
      max_seats: 9
    }
  ]
}
```
