# 12751 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "serpentine-masterpiece.org"
  records: [
    {
      type: "NS"
      name: "staging"
      value: "intent-eternity.name"
      ttl: 86400
    }

    {
      type: "A"
      name: "staging"
      value: "v=spf1 include:_spf.nice-formula.com ~all"
      ttl: 86400
    }

    {
      type: "CNAME"
      name: "staging"
      value: "v=spf1 include:_spf.incomplete-cop-out.net ~all"
      ttl: 300
    }

    {
      type: "CNAME"
      name: "staging"
      value: "ornery-cleaner.name"
      ttl: 300
    }
  ]
}
```
