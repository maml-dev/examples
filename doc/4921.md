# 4921 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "communities"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 10 # seconds
    labels: {
      env: "prod"
      region: "us-east"
      team: "shoes"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 76
    memory_threshold: 86
    latency_p99_ms: 1033
    error_rate: 0.01
    notification: {
      channel: "#ops-alerts"
      severity: "critical"
    }
  }
}
```
