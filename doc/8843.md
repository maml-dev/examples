# 8843 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "F5"
      action: "format"
      when: "global"
    }

    {
      key: "F5"
      action: "save"
      when: "terminal"
    }

    {
      key: "Cmd+K"
      action: "command_palette"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+P"
      action: "toggle_terminal"
      when: "debug"
    }
  ]
}
```
