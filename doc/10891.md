# 10891 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@cluttered-godparent.net"
  subject: "Aptus vomer adduco virgo rem."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Aliquam deorsum certe utroque admitto sonitus aggredior. Tricesimus tergo venustas vulgus. Maxime alias alioqui alveus atrox torrens vita tollo statim basium.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Corrigo aureus derelinquo quas cultura chirographum tabesco ver. Tres vivo solum possimus delego tertius. Laboriosam amita degusto turbo vos dolore cilicium tamen unde.

Visit: {{url}}
"""
}
```
