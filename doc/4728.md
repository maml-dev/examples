# 4728 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "ornery-video.name"
  inbound: {
    mx_records: [
      "mx1.ornery-video.name"
      "mx2.ornery-video.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.ornery-video.name"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 452
      per_hour: 7492
    }
  }
}
```
