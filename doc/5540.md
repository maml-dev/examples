# 5540 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.distinct-couch.org"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 8938
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://weary-lotion.name"
      "https://app.agile-e-mail.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 579
    store: "redis"
  }
}
```
