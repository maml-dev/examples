# 6133 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "careless-coordination.net"
  inbound: {
    mx_records: [
      "mx1.careless-coordination.net"
      "mx2.careless-coordination.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.careless-coordination.net"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 444
      per_hour: 3425
    }
  }
}
```
