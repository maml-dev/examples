# 13157 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PUT"
      path: "/orders/:id"
      handler: "getProducts"
      auth: true
    }

    {
      method: "POST"
      path: "/orders"
      handler: "getOrders"
      auth: false
    }

    {
      method: "GET"
      path: "/products/:id"
      handler: "listOrders"
      auth: false
    }

    {
      method: "PUT"
      path: "/comments/:id"
      handler: "updatePosts"
      auth: true
    }
  ]
}
```
