# 15935 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.robust-vista.biz"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 3709
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://finished-reservation.org"
      "https://app.striking-thyme.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 2711
    store: "redis"
  }
}
```
