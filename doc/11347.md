# 11347 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "reckless-adviser.net"
  records: [

      type: "NS"
      name: "staging"
      value: "tangible-issue.name"
      ttl: 3600

      name: "api"

      ttl: 86400
    }

      name: "api"

      ttl: 86400

      type: "AAAA"
      name: "@"

    }
  ]
}
```
