# 14841 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "manage_billing"
        "export_data"
        "read"
        "view_analytics"
      ]
      max_seats: 40
    }

    {
      name: "viewer"
      permissions: [
        "manage_billing"
        "manage_users"
        "delete"
        "export_data"
        "write"
      ]
      max_seats: 2
    }

    {
      name: "viewer"
      permissions: [
        "delete"
        "write"
      ]
      max_seats: 5
    }

    {
      name: "viewer"
      permissions: [
        "manage_users"
        "delete"
        "write"
      ]
      max_seats: 50
    }
  ]
}
```
