# 5044 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Cmd+K"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "F5"
      action: "save"
      when: "terminal"
    }

    {
      key: "Ctrl+B"
      action: "select_all_occurrences"
      when: "global"
    }

    {
      key: "Cmd+Shift+L"
      action: "save"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+P"
      action: "search_project"
      when: "editor"
    }

    {
      key: "Ctrl+`"
      action: "save"
      when: "global"
    }
  ]
}
```
