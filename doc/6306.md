# 6306 - Logger Config

Structured logging configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  level: "fatal"
  format: "json"
  timestamp: true
  caller: false # include file:line

  output: "stdout"
  rotation: false
  max_size_mb: 429
  max_age_days: 12
  compress: true
}
```
