# 11897 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@fatherly-godparent.com"
  subject: "Quae sunt ultra."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Desolo comburo neque virgo. Iste numquam usus vulticulus brevis deputo sufficio admoneo vereor trans. Aer aveho alius aperio surculus aperte consuasor defungo statim.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Valde derelinquo utor laboriosam apparatus suffragium. Voluptatum contra temptatio spiculum eveniet cupio absens denique. Commodi anser tantum conscendo vereor angulus.

Visit: {{url}}
"""
}
```
