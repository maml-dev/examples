# 7482 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@regular-corral.org"
  subject: "Deduco combibo fugit strenuus arca."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Conor talis acquiro tersus taedium caterva quam calculus balbus tantum. Decretum dicta degenero. Conitor alveus appello altus trans sortitus color verbum auxilium abundans.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Cursim vomer timidus crux deserunt commodo depopulo. Cognatus aestus audio iusto strenuus tubineus calamitas canonicus bene. Subvenio delinquo sustineo subvenio sono appello ambitus degero totam.

Visit: {{url}}
"""
}
```
