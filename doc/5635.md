# 5635 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "small-dash.com"
  inbound: {
    mx_records: [
      "mx1.small-dash.com"
      "mx2.small-dash.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.small-dash.com"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 285
      per_hour: 5510
    }
  }
}
```
