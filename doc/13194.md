# 13194 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@pointless-roadway.biz"
  subject: "Aqua utrimque cavus curto."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Coma eos auctor odio temeritas nesciunt calamitas attollo delectatio celer. Aequitas cibus ager sum copiose tersus decimus. Clementia caritas spargo.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Arto cinis vomica vir doloremque ipsam tamdiu. Deprimo crinis natus velit sustineo aedificium adduco taedium versus. Depulso cohibeo caput.

Visit: {{url}}
"""
}
```
