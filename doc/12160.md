# 12160 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "PATCH"
      path: "/comments"
      handler: "updateProducts"
      auth: false
    }

    {
      method: "PUT"
      path: "/posts"
      handler: "deletePosts"
      auth: true
    }

    {
      method: "GET"
      path: "/users/:id"
      handler: "createProducts"
      auth: false
    }

    {
      method: "GET"
      path: "/users"
      handler: "getUsers"
      auth: false
    }
  ]
}
```
