# 14457 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "unwelcome-pliers.net"
  records: [
    {
      type: "TXT"
      name: "*"
      value: "95.2.77.102"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "staging"
      value: "6.225.34.108"
      ttl: 86400
    }

    {
      type: "MX"
      name: "@"
      value: "16.105.196.176"
      ttl: 3600
    }

    {
      type: "MX"
      name: "staging"
      value: "unusual-cosset.net"
      ttl: 86400
    }

    {
      type: "TXT"
      name: "*"
      value: "6.119.5.235"
      ttl: 3600
    }

    {
      type: "MX"
      name: "@"
      value: "v=spf1 include:_spf.which-tributary.biz ~all"
      ttl: 86400
    }

    {
      type: "TXT"
      name: "staging"
      value: "v=spf1 include:_spf.palatable-bookend.biz ~all"
      ttl: 300
    }
  ]
}
```
