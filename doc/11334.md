# 11334 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "synergies"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 15 # seconds
    labels: {
      env: "staging"
      region: "ap-south"
      team: "outdoors"

  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 73
    memory_threshold: 88
    latency_p99_ms: 1597
    error_rate: 0.05

      channel: "#oncall"
      severity: "critical"
    }
  }
}
```
