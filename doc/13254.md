# 13254 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PATCH"
      path: "/comments"
      handler: "createProducts"
      auth: false
    }

    {
      method: "GET"
      path: "/products"
      handler: "createUsers"
      auth: false
    }

    {
      method: "PUT"
      path: "/orders"
      handler: "createPosts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/products"
      handler: "createPosts"
      auth: false
    }
  ]
}
```
