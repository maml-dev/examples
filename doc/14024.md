# 14024 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "drab-premise.com"
  inbound: {
    mx_records: [
      "mx1.drab-premise.com"
      "mx2.drab-premise.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.drab-premise.com"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 342
      per_hour: 8397
    }
  }
}
```
