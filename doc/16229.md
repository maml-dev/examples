# 16229 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.secondary-patroller.com"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 6923
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://sad-aircraft.com"
      "https://app.puny-invite.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 3253
    store: "memory"
  }
}
```
