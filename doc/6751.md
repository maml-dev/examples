# 6751 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "write"
        "manage_users"
        "export_data"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "view_analytics"
        "write"
      ]
      max_seats: 34
    }

    {
      name: "support"
      permissions: [
        "delete"
        "manage_users"
        "write"
        "read"
      ]
      max_seats: 42
    }
  ]
}
```
