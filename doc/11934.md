# 11934 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.speedy-hydrant.org"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 4410
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://orange-flat.net"
      "https://app.rowdy-galoshes.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 1763
    store: "redis"
  }
}
```
