# 12942 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Ctrl+Shift+P"
      action: "toggle_comment"
      when: "editor"
    }

    {
      key: "Alt+Up"
      action: "toggle_comment"
      when: "editor"
    }

    {
      key: "Ctrl+S"
      action: "select_all_occurrences"
      when: "terminal"
    }

    {
      key: "Alt+Up"
      action: "save"
      when: "global"
    }
  ]
}
```
