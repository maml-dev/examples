# 7094 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@cloudy-recovery.name"
  subject: "Amicitia vinum perspiciatis correptius cito."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Tamdiu trado necessitatibus. Ventus tristis numquam tamdiu. Aranea tamdiu vis tamquam commodi admoveo.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Utilis bibo tamen concedo recusandae veritatis in bis absum. Civis ullam strenuus vel. Vesica ambulo certus.

Visit: {{url}}
"""
}
```
