# 8598 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "448451c9-6224-4c17-b621-2f5bb748cc43"
  Accept-Language: "fr-FR"
  Cache-Control: "public, max-age=86400"
  X-Powered-By: "Koa"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "adulatio"
    "another one": "vivo"
  }
}
```
