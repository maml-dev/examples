# 8310 - Locale Config

Regional and locale settings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  language: "en"
  country: "WF"
  timezone: "Pacific/Honolulu"
  currency: "MOP"

  date_format: "MM/DD/YYYY"
  time_format: "12h"
  first_day_of_week: "sunday"
  decimal_separator: "."
}
```
