# 14338 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.exhausted-forgery.name"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 2874
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://short-term-sightseeing.net"
      "https://app.irresponsible-puppet.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 3076
    store: "redis"
  }
}
```
