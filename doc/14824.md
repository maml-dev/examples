# 14824 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.ironclad-pulse.biz"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 1856
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://apt-decision.name"
      "https://app.orange-omelet.info"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 111
    store: "redis"
  }
}
```
