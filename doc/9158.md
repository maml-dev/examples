# 9158 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "crazy-sideboard.org"
  records: [
    {
      type: "TXT"
      name: "www"
      value: "v=spf1 include:_spf.prickly-mantua.org ~all"
      ttl: 3600
    }

    {
      type: "A"
      name: "mail"
      value: "129.122.130.232"
      ttl: 300
    }

    {
      type: "TXT"
      name: "*"
      value: "snappy-polarisation.com"
      ttl: 86400
    }

    {
      type: "A"
      name: "@"
      value: "pointed-nucleotidase.com"
      ttl: 3600
    }

    {
      type: "MX"
      name: "www"
      value: "v=spf1 include:_spf.urban-saloon.net ~all"
      ttl: 300
    }
  ]
}
```
