# 15758 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Ctrl+`"
      action: "command_palette"
      when: "terminal"
    }

    {
      key: "F5"
      action: "search_project"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+P"
      action: "debug_run"
      when: "global"
    }

    {
      key: "Alt+Up"
      action: "toggle_terminal"
      when: "global"
    }

    {
      key: "Ctrl+S"
      action: "toggle_sidebar"
      when: "debug"
    }

    {
      key: "Cmd+K"
      action: "toggle_comment"
      when: "debug"
    }
  ]
}
```
