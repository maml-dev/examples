# 11935 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "experiences"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 60 # seconds
    labels: {
      env: "prod"
      region: "eu-west"
      team: "sports"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 72
    memory_threshold: 91
    latency_p99_ms: 404
    error_rate: 0.02
    notification: {
      channel: "#ops-alerts"
      severity: "warning"
    }
  }
}
```
