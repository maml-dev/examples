# 6043 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Cmd+Shift+L"
      action: "debug_run"
      when: "global"
    }

    {
      key: "Ctrl+B"
      action: "save"
      when: "editor"
    }

    {
      key: "Ctrl+/"
      action: "save"
      when: "global"
    }
  ]
}
```
