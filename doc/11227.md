# 11227 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "sudden-complication.com"
  inbound: {
    mx_records: [
      "mx1.sudden-complication.com"
      "mx2.sudden-complication.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.sudden-complication.com"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 98
      per_hour: 9117
    }
  }
}
```
