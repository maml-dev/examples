# 14721 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.square-cash.info"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 6548
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://humiliating-doing.info"
      "https://app.grubby-roundabout.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 433
    store: "redis"
  }
}
```
