# 13626 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "new-cheetah.net"
  inbound: {
    mx_records: [
      "mx1.new-cheetah.net"
      "mx2.new-cheetah.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.new-cheetah.net"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 258
      per_hour: 2211
    }
  }
}
```
