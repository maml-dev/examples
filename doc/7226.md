# 7226 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.remarkable-promise.info"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 6885
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://sick-bar.info"
      "https://app.infinite-newsstand.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 2465
    store: "redis"
  }
}
```
