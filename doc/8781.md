# 8781 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@cavernous-nudge.info"
  subject: "Talus iste corpus avarus aedificium."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Animadverto timor depraedor ambitus amplus corrigo spargo distinctio cariosus vinco. Tum debeo cursus cilicium amet. Admiratio tardus virgo tempus concedo aveho sed cilicium.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Suasoria conforto communis nesciunt. Vilis votum subito. Bonus voluptatem vivo basium benigne.

Visit: {{url}}
"""
}
```
