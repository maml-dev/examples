SMTP email service settings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  smtp_host: "smtp.educated-hierarchy.net"
  smtp_port: 465
  use_tls: true
  from_name: "Howe, Rodriguez and Lowe"
  from_email: "noreply@educated-hierarchy.net"

  # Rate limiting
  max_batch_size: 366

}
```
