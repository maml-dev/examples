# 8860 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "PUT"
      path: "/products"
      handler: "deleteUsers"
      auth: false
    }

    {
      method: "PUT"
      path: "/posts/:id"
      handler: "getUsers"
      auth: false
    }

    {
      method: "POST"
      path: "/users/:id"
      handler: "deleteProducts"
      auth: false
    }
  ]
}
```
