# 11585 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@cavernous-cinema.org"
  subject: "Vomer viridis carus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Vomer correptius subito perferendis. Doloremque tribuo consectetur curvo torrens aro voveo cubicularis apostolus asperiores. Magni advoco arbitro.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Vulnus numquam tergum alter. Sui capitulus ocer verbum via. Combibo degero angulus cenaculum causa universe arceo termes.

Visit: {{url}}
"""
}
```
