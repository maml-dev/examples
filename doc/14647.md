# 14647 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "known-climb.name"
  records: [
    {
      type: "MX"
      name: "cdn"
      value: "30.169.95.197"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "mail"
      value: "146.185.131.202"
      ttl: 86400
    }

    {
      type: "A"
      name: "api"
      value: "whirlwind-cassava.org"
      ttl: 300
    }

    {
      type: "NS"
      name: "*"
      value: "grumpy-nightlife.biz"
      ttl: 86400
    }

    {
      type: "MX"
      name: "*"
      value: "91.193.31.195"
      ttl: 86400
    }

    {
      type: "TXT"
      name: "www"
      value: "heartfelt-coordination.net"
      ttl: 300
    }

    {
      type: "MX"
      name: "staging"
      value: "roasted-obligation.name"
      ttl: 86400
    }
  ]
}
```
