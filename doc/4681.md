# 4681 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@dirty-kit.net"
  subject: "Conforto vero corrigo accendo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Patruus trans quos talis autem sublime. Subseco textilis terga sulum beatus certus cruentus tametsi. Civis vallum coadunatio cupiditate culpo alienus taedium aliquid textus pectus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Volo vociferor suppono animi volup virga coruscus compono autem. Civis terebro cernuus vulgivagus torrens pauci vestrum vinum. Delicate arcus id textor sollicito terreo tamquam spargo.

Visit: {{url}}
"""
}
```
