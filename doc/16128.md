# 16128 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "icy-recommendation.info"
  inbound: {
    mx_records: [
      "mx1.icy-recommendation.info"
      "mx2.icy-recommendation.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.icy-recommendation.info"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 244
      per_hour: 8557
    }
  }
}
```
