# 13859 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Ctrl+D"
      action: "toggle_terminal"
      when: "debug"
    }

    {
      key: "Ctrl+`"
      action: "format"
      when: "editor"
    }

    {
      key: "Ctrl+D"
      action: "search_project"
      when: "terminal"
    }

    {
      key: "Ctrl+B"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "Ctrl+/"
      action: "save"
      when: "global"
    }
  ]
}
```
