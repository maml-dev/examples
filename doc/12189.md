# 12189 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@accurate-conservation.biz"
  subject: "Crur sursum adficio taceo contabesco."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Carmen defleo exercitationem stillicidium tempus tamisium accendo sophismata arbustum. Surculus quibusdam tutamen explicabo. Tumultus perferendis denuo sui cupiditate est vaco.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Subiungo suus temperantia. Curatio ad pectus cetera tonsor suspendo corrumpo. Adipisci adamo pax ceno tantum delinquo aestas.

Visit: {{url}}
"""
}
```
