# 7025 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.juvenile-dash.org"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 5615
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://radiant-sesame.info"
      "https://app.happy-go-lucky-optimal.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: true
    ttl: 1545
    store: "memory"
  }
}
```
