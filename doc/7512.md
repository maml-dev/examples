# 7512 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "ecstatic-ceramic.com"
  ttl: 86400 # seconds
  nameservers: [
    "ns1.glittering-tooth.org"
    "ns2.spanish-napkin.biz"
  ]

  soa_email: "admin@deficient-trench.info"
  refresh: 7200
  retry: 900
  expire: 604800
}
```
