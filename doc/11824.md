# 11824 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "channels"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 15 # seconds
    labels: {
      env: "prod"
      region: "us-east"
      team: "home"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 72
    memory_threshold: 76
    latency_p99_ms: 1926
    error_rate: 0.02
    notification: {
      channel: "#oncall"
      severity: "critical"
    }
  }
}
```
