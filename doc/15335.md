# 15335 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "hairy-accelerator.com"
  inbound: {
    mx_records: [
      "mx1.hairy-accelerator.com"
      "mx2.hairy-accelerator.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.hairy-accelerator.com"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 346
      per_hour: 6046
    }
  }
}
```
