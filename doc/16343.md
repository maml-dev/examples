# 16343 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Alt+Up"
      action: "search_project"
      when: "global"
    }

    {
      key: "Cmd+Shift+L"
      action: "save"
      when: "editor"
    }

    {
      key: "F5"
      action: "toggle_comment"
      when: "editor"
    }

    {
      key: "F5"
      action: "find_references"
      when: "editor"
    }

    {
      key: "Ctrl+`"
      action: "find_references"
      when: "editor"
    }

    {
      key: "F5"
      action: "save"
      when: "debug"
    }
  ]
}
```
