# 16152 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "delete"
        "export_data"
        "view_analytics"
        "manage_billing"
        "read"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "manage_billing"
        "read"
        "export_data"
        "write"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "read"
        "export_data"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "export_data"
        "manage_users"
        "manage_billing"
        "write"
        "read"
      ]
      max_seats: 49
    }
  ]
}
```
