# 8848 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Alt+Up"
      action: "toggle_sidebar"
      when: "terminal"
    }

    {
      key: "Alt+Up"
      action: "toggle_sidebar"
      when: "editor"
    }

    {
      key: "Ctrl+`"
      action: "search_project"
      when: "editor"
    }

    {
      key: "F5"
      action: "format"
      when: "debug"
    }

    {
      key: "Ctrl+S"
      action: "toggle_terminal"
      when: "terminal"
    }

    {
      key: "Alt+Up"
      action: "toggle_terminal"
      when: "debug"
    }
  ]
}
```
