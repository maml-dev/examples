# 12935 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.enlightened-season.org"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 3219
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://same-dish.org"
      "https://app.vengeful-digestive.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: true
    ttl: 1843
    store: "memory"
  }
}
```
