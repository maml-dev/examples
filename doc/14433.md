# 14433 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "networks"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 10 # seconds
    labels: {
      env: "prod"
      region: "eu-west"
      team: "industrial"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 70
    memory_threshold: 90
    latency_p99_ms: 1565
    error_rate: 0.01
    notification: {
      channel: "#incidents"
      severity: "warning"
    }
  }
}
```
