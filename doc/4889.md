# 4889 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "22934ece-4285-4748-ac6b-bd8839b49e0d"
  Accept-Language: "ja-JP"
  Cache-Control: "public, max-age=86400"
  X-Powered-By: "Fastify"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "sufficio"
    "another one": "sufficio"
  }
}
```
