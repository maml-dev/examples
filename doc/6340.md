# 6340 - Theme Config

Design system theme configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  name: "bony Theme"
  # Color palette
  colors: {
    primary: "#df3ee6"
    secondary: "#bfc32b"
    accent: "#2c2cf5"
    background: "#ffffff"
    text: "#e6edf3"

    error: "#dc3545"
    warning: "#ffc107"
    success: "#28a745"
  }

  # Typography
  typography: {
    font_family: "system-ui, sans-serif"
    base_size: 14
    line_height: 1.5
    headings: {
      font_family: "Inter, sans-serif"
      weight: 800
    }
  }

  spacing: {
    unit: 8
    scale: [
      0
      4
      8
      16
      24
      32
      48
    ]
  }
  border_radius: 12
}
```
