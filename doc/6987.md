# 6987 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@far-off-cellar.biz"
  subject: "Officiis tabesco tredecim suppono."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Utrum brevis colligo speciosus. Clarus bellum suadeo vito aeternus ullus excepturi carpo advoco. Deprimo acquiro veritas nesciunt vado cohors adimpleo possimus auxilium adflicto.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Adstringo minus laborum creator subito patria velit tyrannus. Substantia amplitudo terra delinquo temperantia utrum deripio. Comprehendo velociter autem.

Visit: {{url}}
"""
}
```
