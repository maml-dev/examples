# 16721 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.colorless-bidet.com"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 7275
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://esteemed-decryption.net"
      "https://app.complicated-saw.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 1766
    store: "memory"
  }
}
```
