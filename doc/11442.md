# 11442 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+/"
      action: "toggle_terminal"
      when: "global"
    }

    {
      key: "Ctrl+/"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+F"
      action: "toggle_comment"
      when: "terminal"
    }

    {
      key: "F5"
      action: "toggle_sidebar"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+F"
      action: "select_all_occurrences"
      when: "global"
    }
  ]
}
```
