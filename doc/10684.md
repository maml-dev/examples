# 10684 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@noxious-archaeology.com"
  subject: "Charisma provident uredo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Laudantium rem terra aequus vergo crepusculum vobis aegre abeo crebro. Contego triduana cupiditas derideo artificiose adfero turba tutamen thesaurus asperiores. Accedo pectus terra cruciamentum quasi facere fugiat.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Capillus audentia explicabo vindico libero nemo. Vorago teneo et desparatus aequitas. Comes deinde earum conscendo vere defungo.

Visit: {{url}}
"""
}
```
