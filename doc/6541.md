# 6541 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "GET"
      path: "/posts"
      handler: "getPosts"
      auth: false
    }

    {
      method: "GET"
      path: "/products/:id"
      handler: "createUsers"
      auth: false
    }

    {
      method: "GET"
      path: "/comments"
      handler: "getOrders"
      auth: false
    }
  ]
}
```
