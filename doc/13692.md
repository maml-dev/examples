# 13692 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@shameful-cauliflower.net"
  subject: "Cubo administratio vulgus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Contego ver auxilium degusto consequatur. Tabula deprimo timor derideo adstringo sum tergum vivo viscus commodo. Demum verus capillus crebro unus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Abduco accedo arbitro nobis curvo consectetur tredecim aetas crustulum angulus. Degusto fugiat patruus perferendis expedita trucido suspendo crebro casso. Iste umquam cogo adnuo uter supplanto tertius delinquo.

Visit: {{url}}
"""
}
```
