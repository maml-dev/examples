# 6138 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "brisk-scale.biz"
  inbound: {
    mx_records: [
      "mx1.brisk-scale.biz"
      "mx2.brisk-scale.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.brisk-scale.biz"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 347
      per_hour: 1510
    }
  }
}
```
