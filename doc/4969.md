# 4969 - Dashboard Layout

Dashboard widget layout configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  title: "Bernhard and Sons Dashboard"
  refresh_interval: 300 # seconds
  widgets: [
    {
      type: "chart"
      title: "Traffic"
      source: "/api/metrics/traffic"
      chart_type: "area"
      period: "30d"
    }

    {
      type: "stat"
      title: "Uptime"
      source: "/api/stats/revenue"
      format: "currency"
    }

    {
      type: "table"
      title: "Latest Signups"
      source: "/api/recent/orders"
      limit: 22
    }
  ]

  theme: "dark"
}
```
