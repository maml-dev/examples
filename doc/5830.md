# 5830 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "functionalities"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "prod"
      region: "ap-south"
      team: "automotive"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 88
    memory_threshold: 95
    latency_p99_ms: 387
    error_rate: 0.05
    notification: {
      channel: "#incidents"
      severity: "info"
    }
  }
}
```
