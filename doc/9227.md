# 9227 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.unsung-railway.com"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 9785
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://violent-unblinking.net"
      "https://app.polite-dandelion.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 2679
    store: "memory"
  }
}
```
