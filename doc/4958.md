# 4958 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PUT"
      path: "/orders"
      handler: "deleteProducts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/products/:id"
      handler: "getProducts"
      auth: true
    }

    {
      method: "PUT"
      path: "/orders/:id"
      handler: "deleteProducts"
      auth: true
    }
  ]
}
```
