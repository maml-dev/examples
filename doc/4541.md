# 4541 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{

  records: [

      type: "A"
      name: "@"
      value: "authorized-amnesty.com"
      ttl: 3600

      type: "A"
      name: "*"
      value: "v=spf1 include:_spf.happy-go-lucky-cinema.name ~all"
      ttl: 86400
    }

      type: "TXT"

      type: "NS"
      name: "@"
      value: "227.38.214.87"

      type: "CNAME"
      name: "*"
      value: "smart-typeface.info"
```
