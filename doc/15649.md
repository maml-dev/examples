# 15649 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+/"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "F5"
      action: "save"
      when: "global"
    }

    {
      key: "F5"
      action: "command_palette"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+P"
      action: "find_references"
      when: "terminal"
    }

    {
      key: "Ctrl+`"
      action: "find_references"
      when: "debug"
    }

    {
      key: "Ctrl+B"
      action: "toggle_comment"
      when: "global"
    }
  ]
}
```
