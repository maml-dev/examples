# 12637 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "smooth-tusk.org"
  inbound: {
    mx_records: [
      "mx1.smooth-tusk.org"
      "mx2.smooth-tusk.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.smooth-tusk.org"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 169
      per_hour: 2728
    }
  }
}
```
