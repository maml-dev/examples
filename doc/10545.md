# 10545 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "GET"
      path: "/comments/:id"
      handler: "getProducts"
      auth: false
    }

    {
      method: "GET"
      path: "/orders/:id"
      handler: "listOrders"
      auth: false
    }

    {
      method: "DELETE"
      path: "/products"
      handler: "createProducts"
      auth: true
    }
  ]
}
```
