# 9334 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "limping-violin.net"
  inbound: {
    mx_records: [
      "mx1.limping-violin.net"
      "mx2.limping-violin.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.limping-violin.net"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 89
      per_hour: 5917
    }
  }
}
```
