# 10352 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "tedious-halt.name"
  records: [
    {
      type: "MX"
      name: "@"
      value: "v=spf1 include:_spf.smooth-academics.org ~all"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "cdn"
      value: "v=spf1 include:_spf.official-newsletter.org ~all"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "www"
      value: "182.154.50.146"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "staging"
      value: "unkempt-siege.info"
      ttl: 3600
    }
  ]
}
```
