# 7823 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "content"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "staging"
      region: "us-east"
      team: "automotive"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 85
    memory_threshold: 80
    latency_p99_ms: 1328
    error_rate: 0.02
    notification: {
      channel: "#oncall"
      severity: "warning"
    }
  }
}
```
