# 10442 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "hasty-emergent.org"
  records: [
    {
      type: "MX"
      name: "www"
      value: "v=spf1 include:_spf.long-term-amnesty.info ~all"
      ttl: 300
    }

    {
      type: "NS"
      name: "staging"
      value: "v=spf1 include:_spf.insecure-opera.com ~all"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "@"
      value: "poor-range.org"
      ttl: 300
    }

    {
      type: "TXT"
      name: "@"
      value: "v=spf1 include:_spf.enlightened-omelet.biz ~all"
      ttl: 300
    }
  ]
}
```
