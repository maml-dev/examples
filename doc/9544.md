# 9544 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Ctrl+D"
      action: "find_references"
      when: "editor"
    }

    {
      key: "Ctrl+S"
      action: "search_project"
      when: "debug"
    }

    {
      key: "Alt+Up"
      action: "save"
      when: "terminal"
    }

    {
      key: "Ctrl+S"
      action: "select_all_occurrences"
      when: "global"
    }

    {
      key: "Ctrl+`"
      action: "select_all_occurrences"
      when: "debug"
    }

    {
      key: "Ctrl+D"
      action: "command_palette"
      when: "debug"
    }
  ]
}
```
