# 13742 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "manage_users"
        "manage_billing"
        "view_analytics"
        "delete"
      ]
      max_seats: 28
    }

    {
      name: "editor"
      permissions: [
        "manage_users"
        "delete"
        "read"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "export_data"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "view_analytics"
        "export_data"
        "delete"
        "manage_billing"
        "read"
      ]
      max_seats: 3
    }
  ]
}
```
