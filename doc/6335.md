# 6335 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.educated-citizen.org"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 5926
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://impish-gerbil.net"
      "https://app.self-reliant-backbone.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 2181
    store: "redis"
  }
}
```
