# 16483 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/xml"
  X-Request-ID: "b05103bd-0a46-4b8b-b435-2bd44f754b95"
  Accept-Language: "de-DE"
  Cache-Control: "no-cache"
  X-Powered-By: "Fastify"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "ventus"
    "another one": "chirographum"
  }
}
```
