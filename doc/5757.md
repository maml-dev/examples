# 5757 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Cmd+Shift+L"
      action: "command_palette"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+P"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+P"
      action: "debug_run"
      when: "global"
    }

    {
      key: "F5"
      action: "format"
      when: "terminal"
    }
  ]
}
```
