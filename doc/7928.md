# 7928 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "these-responsibility.org"
  inbound: {
    mx_records: [
      "mx1.these-responsibility.org"
      "mx2.these-responsibility.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.these-responsibility.org"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 84
      per_hour: 7158
    }
  }
}
```
