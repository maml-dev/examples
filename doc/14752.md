# 14752 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "delete"
        "manage_users"
      ]
      max_seats: 1
    }

    {
      name: "support"
      permissions: [
        "read"
        "export_data"
        "manage_billing"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "view_analytics"
        "delete"
        "export_data"
      ]
      max_seats: 9
    }

    {
      name: "moderator"
      permissions: [
        "write"
        "manage_billing"
        "manage_users"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "write"
        "manage_billing"
        "manage_users"
      ]
      max_seats: null
    }
  ]
}
```
