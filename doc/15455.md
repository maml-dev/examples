# 15455 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "pertinent-ceramic.biz"
  records: [
    {
      type: "CNAME"
      name: "*"
      value: "v=spf1 include:_spf.guilty-object.name ~all"
      ttl: 300
    }

    {
      type: "MX"
      name: "@"
      value: "v=spf1 include:_spf.miserly-cauliflower.org ~all"
      ttl: 300
    }

    {
      type: "MX"
      name: "*"
      value: "well-worn-desk.biz"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "*"
      value: "v=spf1 include:_spf.flustered-marksman.info ~all"
      ttl: 300
    }

    {
      type: "CNAME"
      name: "mail"
      value: "50.63.227.255"
      ttl: 86400
    }
  ]
}
```
