# 11190 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@well-groomed-translation.name"
  subject: "Acquiro accommodo advoco alveus decor."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Beatae perferendis clibanus suggero sodalitas subnecto iste depulso vinculum. Vomer baiulus denique labore itaque coadunatio solitudo tracto voco. Desino adhuc cultura.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Calcar cubitum asperiores perspiciatis inventore beneficium perspiciatis absorbeo comes. Annus virtus ascisco usitas caste depromo addo vere constans abstergo. Conor vado vere maiores terror.

Visit: {{url}}
"""
}
```
