# 12134 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "architectures"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 10 # seconds
    labels: {
      env: "staging"
      region: "us-east"
      team: "books"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 86
    memory_threshold: 80
    latency_p99_ms: 1706
    error_rate: 0.02
    notification: {
      channel: "#incidents"
      severity: "info"
    }
  }
}
```
