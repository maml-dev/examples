# 16649 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "present-translation.com"
  records: [
    {
      type: "A"
      name: "@"
      value: "merry-gymnast.name"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "cdn"
      value: "167.182.1.178"
      ttl: 3600
    }

    {
      type: "MX"
      name: "api"
      value: "red-gloom.org"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "cdn"
      value: "44.249.62.212"
      ttl: 3600
    }
  ]
}
```
