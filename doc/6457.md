# 6457 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "DELETE"
      path: "/orders/:id"
      handler: "deleteOrders"
      auth: false
    }

    {
      method: "PATCH"
      path: "/products"
      handler: "updatePosts"
      auth: false
    }

    {
      method: "PUT"
      path: "/users"
      handler: "deleteOrders"
      auth: true
    }
  ]
}
```
