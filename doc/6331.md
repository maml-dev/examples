# 6331 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "ai"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 10 # seconds
    labels: {
      env: "prod"
      region: "eu-west"
      team: "health"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 72
    memory_threshold: 89
    latency_p99_ms: 1307
    error_rate: 0.02
    notification: {
      channel: "#oncall"
      severity: "warning"
    }
  }
}
```
