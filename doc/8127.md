# 8127 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "monumental-decryption.com"
  inbound: {
    mx_records: [
      "mx1.monumental-decryption.com"
      "mx2.monumental-decryption.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.monumental-decryption.com"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 253
      per_hour: 7358
    }
  }
}
```
