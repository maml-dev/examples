# 9089 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "95a41701-1901-4c10-b6bd-aa50655bd957"
  Accept-Language: "de-DE"
  Cache-Control: "public, max-age=86400"
  X-Powered-By: "Express"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "absum"
    "another one": "socius"
  }
}
```
