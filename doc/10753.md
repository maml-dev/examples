# 10753 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Ctrl+`"
      action: "find_references"
      when: "editor"
    }

    {
      key: "Alt+Up"
      action: "toggle_terminal"
      when: "terminal"
    }

    {
      key: "Ctrl+`"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Ctrl+D"
      action: "format"
      when: "global"
    }

    {
      key: "Ctrl+B"
      action: "find_references"
      when: "debug"
    }

    {
      key: "Alt+F7"
      action: "save"
      when: "global"
    }
  ]
}
```
