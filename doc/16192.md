# 16192 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "f7c3b9b8-1a0a-492e-b2d3-34efbc9e5f67"
  Accept-Language: "ja-JP"
  Cache-Control: "no-cache"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "decerno"
    "another one": "dedico"
  }
}
```
