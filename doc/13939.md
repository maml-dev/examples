# 13939 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "architectures"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 10 # seconds
    labels: {
      env: "staging"
      region: "ap-south"
      team: "music"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 94
    memory_threshold: 93
    latency_p99_ms: 1540
    error_rate: 0.05
    notification: {
      channel: "#ops-alerts"
      severity: "warning"
    }
  }
}
```
