# 9250 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "viewer"
      permissions: [
        "manage_users"
        "export_data"
        "delete"
        "read"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "manage_users"
        "delete"
        "manage_billing"
        "write"
      ]
      max_seats: 38
    }

    {
      name: "moderator"
      permissions: [
        "manage_billing"
        "export_data"
        "view_analytics"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "delete"
        "read"
        "write"
        "export_data"
        "manage_billing"
      ]
      max_seats: 27
    }
  ]
}
```
