# 16852 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "POST"
      path: "/orders/:id"
      handler: "updatePosts"
      auth: false
    }

    {
      method: "GET"
      path: "/posts/:id"
      handler: "createOrders"
      auth: false
    }

    {
      method: "PUT"
      path: "/comments/:id"
      handler: "createOrders"
      auth: true
    }

    {
      method: "DELETE"
      path: "/products/:id"
      handler: "createOrders"
      auth: true
    }

    {
      method: "DELETE"
      path: "/comments"
      handler: "listOrders"
      auth: true
    }

    {
      method: "DELETE"
      path: "/products/:id"
      handler: "deleteUsers"
      auth: false
    }
  ]
}
```
