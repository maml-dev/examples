# 6449 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "sophisticated-illusion.biz"
  records: [
    {
      type: "MX"
      name: "@"
      value: "v=spf1 include:_spf.tempting-postbox.name ~all"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "*"
      value: "antique-replacement.biz"
      ttl: 300
    }

    {
      type: "TXT"
      name: "@"
      value: "45.52.169.128"
      ttl: 86400
    }

    {
      type: "NS"
      name: "staging"
      value: "194.122.124.111"
      ttl: 86400
    }

    {
      type: "A"
      name: "api"
      value: "v=spf1 include:_spf.elderly-skyline.info ~all"
      ttl: 300
    }
  ]
}
```
