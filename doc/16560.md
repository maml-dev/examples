# 16560 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "viewer"
      permissions: [
        "read"
        "manage_billing"
        "write"
        "manage_users"
        "view_analytics"
      ]
      max_seats: 3
    }

    {
      name: "support"
      permissions: [
        "manage_billing"
        "export_data"
        "delete"
        "view_analytics"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "manage_billing"
        "view_analytics"
        "delete"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "manage_users"
        "export_data"
        "read"
      ]
      max_seats: 17
    }
  ]
}
```
