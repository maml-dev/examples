# 16456 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "GET"
      path: "/users"
      handler: "updateOrders"
      auth: false
    }

    {
      method: "POST"
      path: "/comments"
      handler: "createOrders"
      auth: true
    }

    {
      method: "PUT"
      path: "/users/:id"
      handler: "updateOrders"
      auth: false
    }
  ]
}
```
