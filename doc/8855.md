# 8855 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "write"
        "delete"
      ]
      max_seats: 19
    }

    {
      name: "editor"
      permissions: [
        "delete"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "write"
        "export_data"
        "manage_users"
        "view_analytics"
        "delete"
      ]
      max_seats: 24
    }

    {
      name: "viewer"
      permissions: [
        "delete"
        "export_data"
        "view_analytics"
        "write"
      ]
      max_seats: 26
    }

    {
      name: "billing"
      permissions: [
        "delete"
        "write"
        "export_data"
        "manage_billing"
      ]
      max_seats: 38
    }
  ]
}
```
