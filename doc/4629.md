# 4629 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.obedient-coal.info"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 3539
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://precious-marimba.com"
      "https://app.glaring-joy.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 521
    store: "redis"
  }
}
```
