# 8344 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "read"
        "export_data"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "write"
        "view_analytics"
        "export_data"
        "manage_billing"
      ]
      max_seats: 12
    }

    {
      name: "admin"
      permissions: [
        "manage_users"
        "view_analytics"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "manage_billing"
        "delete"
      ]
      max_seats: 22
    }
  ]
}
```
