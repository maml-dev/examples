# 15006 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "steep-sightseeing.name"
  ttl: 600 # seconds
  nameservers: [
    "ns1.some-subexpression.info"
    "ns2.moral-representation.com"
  ]

  soa_email: "admin@imaginative-doorpost.org"
  refresh: 3600
  retry: 600
  expire: 604800
}
```
