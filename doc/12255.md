# 12255 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "manage_users"
        "export_data"
        "delete"
      ]
      max_seats: 21
    }

    {
      name: "editor"
      permissions: [
        "view_analytics"
        "write"
        "export_data"
      ]
      max_seats: 25
    }

    {
      name: "viewer"
      permissions: [
        "delete"
        "write"
        "manage_users"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "read"
        "export_data"
        "view_analytics"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "delete"
        "manage_billing"
        "manage_users"
      ]
      max_seats: 8
    }
  ]
}
```
