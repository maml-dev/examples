# 8015 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "direct-brush.net"
  ttl: 600 # seconds
  nameservers: [
    "ns1.early-section.com"
    "ns2.short-pigpen.org"
  ]

  soa_email: "admin@moral-tuber.biz"
  refresh: 3600
  retry: 1800
  expire: 1209600
}
```
