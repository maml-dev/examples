# 6128 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.improbable-saw.org"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 7301
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://rotating-fen.com"
      "https://app.boiling-guacamole.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 2426
    store: "memory"
  }
}
```
