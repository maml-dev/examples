# 10322 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "parched-summary.org"
  inbound: {
    mx_records: [
      "mx1.parched-summary.org"
      "mx2.parched-summary.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.parched-summary.org"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 190
      per_hour: 8221
    }
  }
}
```
