# 9160 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "sleepy-graffiti.info"
  records: [
    {
      type: "NS"
      name: "api"
      value: "blushing-follower.biz"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "@"
      value: "174.216.162.118"
      ttl: 300
    }

    {
      type: "CNAME"
      name: "api"
      value: "246.140.196.8"
      ttl: 300
    }

    {
      type: "A"
      name: "*"
      value: "gruesome-lawmaker.name"
      ttl: 86400
    }

    {
      type: "CNAME"
      name: "*"
      value: "128.180.255.236"
      ttl: 86400
    }

    {
      type: "TXT"
      name: "api"
      value: "v=spf1 include:_spf.medium-gown.biz ~all"
      ttl: 300
    }
  ]
}
```
