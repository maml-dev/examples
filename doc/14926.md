# 14926 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "pointed-beret.org"
  inbound: {
    mx_records: [
      "mx1.pointed-beret.org"
      "mx2.pointed-beret.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.pointed-beret.org"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 324
      per_hour: 4927
    }
  }
}
```
