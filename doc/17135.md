# 17135 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "insidious-eggplant.name"
  inbound: {
    mx_records: [
      "mx1.insidious-eggplant.name"
      "mx2.insidious-eggplant.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.insidious-eggplant.name"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 484
      per_hour: 6063
    }
  }
}
```
