# 14628 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.thorough-cycle.name"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 319
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://doting-forage.biz"
      "https://app.corny-brief.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 1388
    store: "redis"
  }
}
```
