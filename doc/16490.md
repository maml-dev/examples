# 16490 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@fuzzy-toothbrush.net"
  subject: "Cuppedia aliquam quaerat tribuo arma."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Summopere decerno arbustum adiuvo derideo creber vir ater video. Animi dens comburo distinctio utrimque commemoro. Textilis cui stipes dedico carmen desparatus pectus delego.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Curriculum attonbitus comburo basium cunae totidem alias uter currus. Arx tribuo vesper illo complectus eos autus vestigium. Agnosco veritatis sui terreo quia adsum suffoco cicuta nam.

Visit: {{url}}
"""
}
```
