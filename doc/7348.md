# 7348 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "PATCH"
      path: "/posts"
      handler: "createProducts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/comments/:id"
      handler: "createPosts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/comments"
      handler: "deletePosts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/comments"
      handler: "getPosts"
      auth: false
    }

    {
      method: "POST"
      path: "/orders/:id"
      handler: "deleteOrders"
      auth: true
    }

    {
      method: "PUT"
      path: "/users"
      handler: "listPosts"
      auth: false
    }
  ]
}
```
