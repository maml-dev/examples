# 13321 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "poor-tomb.info"
  inbound: {
    mx_records: [
      "mx1.poor-tomb.info"
      "mx2.poor-tomb.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.poor-tomb.info"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 227
      per_hour: 9373
    }
  }
}
```
