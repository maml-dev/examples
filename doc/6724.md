# 6724 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "metrics"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 15 # seconds
    labels: {
      env: "prod"
      region: "ap-south"
      team: "electronics"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 86
    memory_threshold: 92
    latency_p99_ms: 1079
    error_rate: 0.01
    notification: {
      channel: "#oncall"
      severity: "critical"
    }
  }
}
```
