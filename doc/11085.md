# 11085 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@soupy-request.org"
  subject: "Abstergo vallum ars causa."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Ante varius trans accusator balbus amiculum. Debeo architecto aperiam comitatus ipsam. Tametsi charisma ara nostrum sophismata est.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Absque antiquus tandem circumvenio pax vos terga cruciamentum curso aeneus. Sequi speciosus succurro. Dedecor provident totam benevolentia iure vulnero supellex amoveo.

Visit: {{url}}
"""
}
```
