# 9383 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@coarse-inspection.com"
  subject: "Toties carbo taedium deficio antepono perferendis."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Stabilis vel surculus beatus. Dignissimos vomica delectatio vereor cohaero subito aspernatur. Tumultus apud ancilla adamo patior condico tondeo urbanus acerbitas.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Alioqui aveho creptio xiphias. Caste cupiditas curia. Ipsam baiulus totidem dolorem amitto.

Visit: {{url}}
"""
}
```
