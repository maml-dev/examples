# 6285 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@uncommon-fireplace.name"
  subject: "Cuppedia ascit subvenio culpo aliqua."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Vinitor conqueror aeger sequi absens accedo adversus. Calculus cinis aggero thesis exercitationem animus. Sollicito timidus voluntarius artificiose.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Tabula earum ter et cur viridis aggero cunabula abundans repudiandae. Caveo strenuus degero magni et vestrum. Ager vix tandem delego altus deinde conventus confero.

Visit: {{url}}
"""
}
```
