# 14144 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+/"
      action: "save"
      when: "terminal"
    }

    {
      key: "Ctrl+S"
      action: "debug_run"

    }

      key: "Alt+Up"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Ctrl+B"
      action: "debug_run"
      when: "global"
    }
  ]
}
```
