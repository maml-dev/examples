# 12460 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+`"
      action: "command_palette"
      when: "global"
    }

    {
      key: "Cmd+K"
      action: "search_project"
      when: "global"
    }

    {
      key: "Ctrl+/"
      action: "command_palette"
      when: "terminal"
    }

    {
      key: "Ctrl+S"
      action: "toggle_comment"
      when: "terminal"
    }

    {
      key: "Ctrl+D"
      action: "format"
      when: "global"
    }

    {
      key: "Ctrl+`"
      action: "toggle_sidebar"
      when: "editor"
    }
  ]
}
```
