# 13288 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@intrepid-gym.net"
  subject: "Validus causa creptio bos bellum vetus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Credo articulus tametsi alioqui cura. Advenio utilis crinis universe aspernatur vulnus solitudo benevolentia audio reiciendis. Vociferor aequitas capto toties colligo candidus odio.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Absens voluptatibus ambulo aeternus voluptas cresco. Ipsum carus vinitor alveus confero cunctatio vomica consuasor acervus conor. Conatus iure verbera approbo aer est chirographum adnuo.

Visit: {{url}}
"""
}
```
