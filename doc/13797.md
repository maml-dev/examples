# 13797 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@live-curl.info"
  subject: "Adflicto armarium ustilo urbanus nemo supplanto."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Succedo valeo calcar debilito celebrer. Nostrum alii delinquo. Coma ubi vallum tam copia.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Fugiat voveo ipsum neque angulus amplitudo coerceo concedo. Aranea adhuc vae atrox labore aveho desidero. Tribuo deprecator desipio eius adfero thesaurus color contigo vesper.

Visit: {{url}}
"""
}
```
