# 16788 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@lasting-siege.net"
  subject: "Demergo vicinus conturbo deludo demitto alius."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Adhaero speciosus tristis deludo studio adulatio tergo summopere. Assumenda ab tabella hic demulceo. Crustulum peccatus turba fugit.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Summopere curiositas defleo venustas aureus textilis nostrum adsum. Acervus inventore calculus in colo aufero appositus. Occaecati spargo dens iure.

Visit: {{url}}
"""
}
```
