# 10846 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "read"
        "write"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "view_analytics"
        "write"
      ]
      max_seats: 9
    }

    {
      name: "billing"
      permissions: [
        "delete"
        "manage_billing"
        "write"
      ]
      max_seats: 39
    }
  ]
}
```
