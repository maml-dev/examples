# 11928 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "pick-web"
    namespace: "staging"
    labels: {
      app: "tentacle"
      tier: "frontend"
    }
  }

  # Deployment spec
  spec: {
    replicas: 1
    container: {
      image: "farm:1.11.15"
      port: 8080
      resources: {
        cpu_limit: "500m"
        memory_limit: "1Gi"
      }
    }

    health_check: {
      path: "/healthz"
      interval: 10
      timeout: 3
    }
  }
}
```
