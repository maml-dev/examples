# 4656 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "GET"
      path: "/posts/:id"
      handler: "deleteOrders"
      auth: false
    }

    {
      method: "GET"
      path: "/comments"
      handler: "getOrders"
      auth: true
    }

    {
      method: "PUT"
      path: "/orders"
      handler: "deletePosts"
      auth: false
    }
  ]
}
```
