# 16293 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@immaculate-climb.org"
  subject: "Occaecati veritatis suus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Acquiro vero volo cibus beatus timor. Iste maxime adhuc subnecto cilicium. Tabgo defaeco balbus animus turpis reprehenderit.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Tersus cervus vitae magni. Aggredior demulceo vilicus architecto degenero. Cupiditate cruentus aegre.

Visit: {{url}}
"""
}
```
