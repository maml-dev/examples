# 12201 - Feature Flags

Application feature toggle configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  enable_dark_mode: true
  enable_notifications: false
  enable_analytics: false # requires consent
  enable_beta_features: false

  maintenance_mode: false
  max_upload_mb: 87
  session_timeout: 6397 # seconds
}
```
