# 12058 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "PUT"
      path: "/comments"
      handler: "getProducts"
      auth: false
    }

    {
      method: "GET"
      path: "/orders"
      handler: "deleteProducts"
      auth: true
    }

    {
      method: "PUT"
      path: "/products/:id"
      handler: "deleteOrders"
      auth: false
    }

    {
      method: "PUT"
      path: "/products"
      handler: "deleteOrders"
      auth: false
    }
  ]
}
```
