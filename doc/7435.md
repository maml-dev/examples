# 7435 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "cantaloupe-api"
    namespace: "default"
    labels: {
      app: "exhaust"
      tier: "data"
    }
  }

  # Deployment spec
  spec: {
    replicas: 3
    container: {
      image: "negotiation:0.0.13"
      port: 9090
      resources: {
        cpu_limit: "500m"
        memory_limit: "512Mi"
      }
    }

    health_check: {
      path: "/healthz"
      interval: 15
      timeout: 10
    }
  }
}
```
