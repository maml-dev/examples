# 9114 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "thorny-duster.name"
  ttl: 3600 # seconds
  nameservers: [
    "ns1.grumpy-widow.org"
    "ns2.distant-disconnection.biz"
  ]

  soa_email: "admin@untried-disclosure.info"
  refresh: 7200
  retry: 1800
  expire: 1209600
}
```
