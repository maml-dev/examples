# 13359 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "export_data"
        "manage_users"
        "write"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "export_data"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "export_data"
        "read"
        "write"
      ]
      max_seats: 27
    }

    {
      name: "moderator"
      permissions: [
        "view_analytics"
        "delete"
        "read"
        "manage_billing"
      ]
      max_seats: 9
    }

    {
      name: "billing"
      permissions: [
        "delete"
        "export_data"
      ]
      max_seats: 27
    }
  ]
}
```
