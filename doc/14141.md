# 14141 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "viewer"
      permissions: [
        "read"
        "view_analytics"
        "manage_billing"
        "manage_users"
      ]
      max_seats: 27
    }

    {
      name: "billing"
      permissions: [
        "export_data"
        "read"
      ]
      max_seats: 22
    }

    {
      name: "billing"
      permissions: [
        "manage_users"
        "export_data"
        "view_analytics"
        "manage_billing"
        "write"
      ]
      max_seats: 24
    }

    {
      name: "admin"
      permissions: [
        "read"
        "export_data"
        "manage_billing"
        "manage_users"
        "write"
      ]
      max_seats: 25
    }

    {
      name: "support"
      permissions: [
        "export_data"
        "view_analytics"
      ]
      max_seats: 12
    }
  ]
}
```
