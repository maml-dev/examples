# 9656 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Ctrl+S"
      action: "format"
      when: "debug"
    }

    {
      key: "Ctrl+`"
      action: "search_project"
      when: "debug"
    }

    {
      key: "Ctrl+/"
      action: "toggle_terminal"
      when: "global"
    }

    {
      key: "Ctrl+S"
      action: "format"
      when: "global"
    }

    {
      key: "Ctrl+B"
      action: "find_references"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+P"
      action: "toggle_terminal"
      when: "global"
    }
  ]
}
```
