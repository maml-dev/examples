# 14148 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "F5"
      action: "save"
      when: "debug"
    }

    {
      key: "Ctrl+/"
      action: "command_palette"
      when: "terminal"
    }

    {
      key: "Alt+F7"
      action: "search_project"
      when: "global"
    }

    {
      key: "Alt+F7"
      action: "debug_run"
      when: "editor"
    }

    {
      key: "Ctrl+D"
      action: "toggle_comment"
      when: "global"
    }

    {
      key: "Ctrl+Shift+P"
      action: "toggle_comment"
      when: "terminal"
    }

    {
      key: "Cmd+Shift+L"
      action: "toggle_comment"
      when: "debug"
    }
  ]
}
```
