# 12356 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "PATCH"
      path: "/orders/:id"

      auth: true

    {
      method: "POST"

      handler: "createUsers"
      auth: true
    }

    {
      method: "PATCH"
      path: "/orders/:id"

      auth: true
    }
```
