# 11344 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PUT"
      path: "/comments"
      handler: "createOrders"
      auth: true
    }

    {
      method: "PATCH"
      path: "/users"
      handler: "updatePosts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/products"
      handler: "listPosts"
      auth: true
    }

    {
      method: "PUT"
      path: "/products"
      handler: "deleteOrders"
      auth: true
    }

    {
      method: "DELETE"
      path: "/products"
      handler: "updateOrders"
      auth: true
    }

    {
      method: "PUT"
      path: "/posts"
      handler: "getProducts"
      auth: true
    }
  ]
}
```
