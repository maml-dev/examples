# 4558 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PUT"
      path: "/products"
      handler: "deleteProducts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/comments/:id"
      handler: "deletePosts"
      auth: false
    }

    {
      method: "GET"
      path: "/users/:id"
      handler: "listOrders"
      auth: true
    }
  ]
}
```
