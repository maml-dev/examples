# 15125 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.good-rule.net"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 4352
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://firsthand-march.net"
      "https://app.babyish-footrest.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 2619
    store: "memory"
  }
}
```
