# 14990 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@selfish-simple.info"
  subject: "Deripio dolores turba pecus amitto convoco."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Comedo audax congregatio. Cupressus tamquam amicitia angulus vivo non varietas. Volup acervus usitas.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Amitto adinventitias subseco ambitus commemoro timor repudiandae. Totam tantillus tam cibus repudiandae carpo. Sumo celebrer curtus impedit cogo dolorum tristis alienus cupio laudantium.

Visit: {{url}}
"""
}
```
