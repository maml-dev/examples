# 14334 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "tragic-bug.info"
  inbound: {
    mx_records: [
      "mx1.tragic-bug.info"
      "mx2.tragic-bug.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.tragic-bug.info"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 404
      per_hour: 6234
    }
  }
}
```
