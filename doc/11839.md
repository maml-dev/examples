# 11839 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "mundane-guacamole.name"
  inbound: {
    mx_records: [
      "mx1.mundane-guacamole.name"
      "mx2.mundane-guacamole.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.mundane-guacamole.name"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 468
      per_hour: 7666
    }
  }
}
```
