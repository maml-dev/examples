# 13689 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@brisk-quart.net"
  subject: "Vesper theologus claro."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Tristis coruscus tergeo creptio excepturi temeritas debeo accommodo abstergo. Concido suscipit supplanto. Tibi somniculosus teres adsuesco cursus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Adficio caveo harum vulnus. Sursum derelinquo caelum ustulo. Umquam cunabula pecus taedium velut vehemens comprehendo amicitia cometes.

Visit: {{url}}
"""
}
```
