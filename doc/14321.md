# 14321 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.precious-captain.org"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 3270
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://everlasting-tinderbox.info"
      "https://app.giving-sailor.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: true
    ttl: 2959
    store: "redis"
  }
}
```
