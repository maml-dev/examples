# 10586 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "f22e40dd-2a0e-4ea3-9c74-fffe1a1f3be0"
  Accept-Language: "ja-JP"
  Cache-Control: "no-cache"
  X-Powered-By: "Express"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "rem"
    "another one": "adsum"
  }
}
```
