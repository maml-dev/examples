# 4554 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "shoddy-encouragement.biz"
  records: [
    {
      type: "NS"
      name: "cdn"
      value: "v=spf1 include:_spf.squeaky-cheese.org ~all"
      ttl: 86400
    }

    {
      type: "MX"
      name: "api"
      value: "international-contractor.com"
      ttl: 3600
    }

    {
      type: "A"
      name: "staging"
      value: "v=spf1 include:_spf.nocturnal-widow.biz ~all"
      ttl: 300
    }

    {
      type: "MX"
      name: "cdn"
      value: "smooth-cash.net"
      ttl: 3600
    }
  ]
}
```
