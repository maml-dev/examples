# 13735 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "blushing-essence.com"
  inbound: {
    mx_records: [
      "mx1.blushing-essence.com"
      "mx2.blushing-essence.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.blushing-essence.com"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 194
      per_hour: 8841
    }
  }
}
```
