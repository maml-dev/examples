# 13725 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "deliverables"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "staging"
      region: "ap-south"
      team: "toys"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 71
    memory_threshold: 83
    latency_p99_ms: 1809
    error_rate: 0.01
    notification: {
      channel: "#oncall"
      severity: "critical"
    }
  }
}
```
