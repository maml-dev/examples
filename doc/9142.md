# 9142 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "export_data"
        "delete"
        "manage_users"
      ]
      max_seats: 31
    }

    {
      name: "moderator"
      permissions: [
        "manage_users"
        "delete"
        "view_analytics"
      ]
      max_seats: 39
    }

    {
      name: "admin"
      permissions: [
        "manage_billing"
        "export_data"
        "read"
      ]
      max_seats: 34
    }

    {
      name: "editor"
      permissions: [
        "delete"
        "view_analytics"
      ]
      max_seats: 33
    }

    {
      name: "editor"
      permissions: [
        "read"
        "manage_users"
        "export_data"
      ]
      max_seats: null
    }
  ]
}
```
