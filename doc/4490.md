# 4490 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@rough-transom.biz"
  subject: "Agnosco explicabo ocer."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Quasi ara convoco claro quo. Defungo vergo adstringo thesis audeo creptio altus sono. Confugo textor tenus tricesimus debilito blandior creator censura.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Omnis cunae considero thesaurus accusator. Vulgus sollers vado barba corrumpo alii adhuc paulatim. Basium caecus vicinus sperno nesciunt concido denuo.

Visit: {{url}}
"""
}
```
