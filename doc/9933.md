# 9933 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.gifted-numeracy.com"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 9397
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://jagged-promise.net"
      "https://app.slow-retention.info"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 2272
    store: "memory"
  }
}
```
