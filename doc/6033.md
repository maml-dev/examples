# 6033 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "shabby-beret.com"
  inbound: {
    mx_records: [
      "mx1.shabby-beret.com"
      "mx2.shabby-beret.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.shabby-beret.com"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 229
      per_hour: 5255
    }
  }
}
```
