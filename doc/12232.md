# 12232 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "austere-baritone.org"
  inbound: {
    mx_records: [
      "mx1.austere-baritone.org"
      "mx2.austere-baritone.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.austere-baritone.org"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 146
      per_hour: 9325
    }
  }
}
```
