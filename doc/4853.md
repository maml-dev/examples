# 4853 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "delete"
        "manage_users"
        "write"
        "manage_billing"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "export_data"
        "delete"
        "manage_billing"
        "write"
        "read"
      ]
      max_seats: 29
    }

    {
      name: "support"
      permissions: [
        "view_analytics"
        "read"
        "delete"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "write"
        "read"
        "delete"
        "manage_billing"
      ]
      max_seats: 23
    }
  ]
}
```
