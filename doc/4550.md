# 4550 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "early-premise.info"
  records: [
    {
      type: "CNAME"
      name: "staging"
      value: "254.93.243.248"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "@"
      value: "hasty-marksman.net"
      ttl: 3600
    }

    {
      type: "MX"
      name: "@"
      value: "11.117.237.178"
      ttl: 86400
    }

    {
      type: "MX"
      name: "@"
      value: "180.205.56.179"
      ttl: 3600
    }

    {
      type: "A"
      name: "@"
      value: "182.135.65.157"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "staging"
      value: "gigantic-hydrolyze.com"
      ttl: 300
    }

    {
      type: "NS"
      name: "www"
      value: "alienated-trash.org"
      ttl: 300
    }

    {
      type: "NS"
      name: "www"
      value: "v=spf1 include:_spf.indolent-iridescence.net ~all"
      ttl: 86400
    }
  ]
}
```
