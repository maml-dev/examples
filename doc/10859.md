# 10859 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "viewer"
      permissions: [
        "manage_users"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "manage_billing"
        "write"
      ]
      max_seats: 49
    }

    {
      name: "billing"
      permissions: [
        "manage_billing"
        "export_data"
      ]
      max_seats: 20
    }

    {
      name: "billing"
      permissions: [
        "read"
        "write"
      ]
      max_seats: 40
    }
  ]
}
```
