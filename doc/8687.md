# 8687 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@gripping-plastic.biz"
  subject: "Cupiditas utrum dolorem terga casso."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Pecco cohibeo aggredior defungo aggero conicio coniecto adaugeo laudantium ago. Videlicet tantillus speculum voluptate ars repellat. Creator curiositas pecto deprimo cibus censura amplitudo conservo depereo.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Caecus volubilis succedo consequatur. Dolorem corroboro acsi. Tamisium tempus virgo textus.

Visit: {{url}}
"""
}
```
