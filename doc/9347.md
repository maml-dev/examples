# 9347 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "GET"
      path: "/users/:id"
      handler: "createProducts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/posts/:id"
      handler: "createPosts"
      auth: false
    }

    {
      method: "POST"
      path: "/orders"
      handler: "createPosts"
      auth: false
    }

    {
      method: "GET"
      path: "/comments/:id"
      handler: "getProducts"
      auth: true
    }
  ]
}
```
