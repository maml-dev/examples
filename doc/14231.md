# 14231 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.regal-synergy.biz"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 3971
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://educated-accountability.com"
      "https://app.grizzled-typewriter.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 649
    store: "memory"
  }
}
```
