# 16624 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.understated-iridescence.com"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 8534
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://early-pigpen.com"
      "https://app.snappy-cutlet.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 2477
    store: "memory"
  }
}
```
