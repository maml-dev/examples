# 5531 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "plain-designation.com"
  inbound: {
    mx_records: [
      "mx1.plain-designation.com"
      "mx2.plain-designation.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.plain-designation.com"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 86
      per_hour: 1209
    }
  }
}
```
