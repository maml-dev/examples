# 8557 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "PATCH"
      path: "/comments/:id"
      handler: "createProducts"
      auth: true
    }

    {
      method: "POST"
      path: "/users"
      handler: "getProducts"
      auth: true
    }

    {
      method: "POST"
      path: "/products"
      handler: "getOrders"
      auth: true
    }

    {
      method: "PUT"
      path: "/orders/:id"
      handler: "deletePosts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/products"
      handler: "deleteUsers"
      auth: false
    }

    {
      method: "DELETE"
      path: "/orders"
      handler: "createOrders"
      auth: false
    }
  ]
}
```
