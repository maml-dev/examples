# 10928 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "difficult-suspension.name"
  inbound: {
    mx_records: [
      "mx1.difficult-suspension.name"
      "mx2.difficult-suspension.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.difficult-suspension.name"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 217
      per_hour: 5666
    }
  }
}
```
