# 11430 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.antique-solution.info"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 6282
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://enchanted-peony.com"
      "https://app.aggravating-seafood.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: true
    ttl: 2639
    store: "memory"
  }
}
```
