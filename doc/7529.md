# 7529 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "accurate-morbidity.info"
  inbound: {
    mx_records: [
      "mx1.accurate-morbidity.info"
      "mx2.accurate-morbidity.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.accurate-morbidity.info"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 254
      per_hour: 7340
    }
  }
}
```
