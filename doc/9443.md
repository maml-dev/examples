# 9443 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "cloudy-smoke.name"
  records: [
    {
      type: "MX"
      name: "staging"
      value: "50.55.38.184"
      ttl: 300
    }

    {
      type: "TXT"
      name: "staging"
      value: "v=spf1 include:_spf.petty-designation.name ~all"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "cdn"
      value: "v=spf1 include:_spf.straight-championship.name ~all"
      ttl: 3600
    }

    {
      type: "MX"
      name: "staging"
      value: "83.84.31.30"
      ttl: 3600
    }
  ]
}
```
