# 16046 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "PUT"
      path: "/orders/:id"
      handler: "listUsers"
      auth: false
    }

    {
      method: "PUT"
      path: "/orders"
      handler: "deletePosts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/posts/:id"
      handler: "deleteOrders"
      auth: true
    }

    {
      method: "PATCH"
      path: "/posts/:id"
      handler: "updateUsers"
      auth: true
    }

    {
      method: "PATCH"
      path: "/posts"
      handler: "createOrders"
      auth: true
    }

    {
      method: "PUT"
      path: "/orders"
      handler: "getPosts"
      auth: true
    }
  ]
}
```
