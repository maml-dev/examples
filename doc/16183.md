# 16183 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/xml"
  X-Request-ID: "c674d98b-b302-41dd-a7d4-27a5774057e3"
  Accept-Language: "en-US"
  Cache-Control: "no-cache"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "vespillo"
    "another one": "arbitro"
  }
}
```
