# 12860 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "read"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "manage_billing"
        "read"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "view_analytics"
        "manage_users"
        "write"
        "read"
      ]
      max_seats: 31
    }

    {
      name: "admin"
      permissions: [
        "manage_billing"
        "delete"
        "read"
        "write"
      ]
      max_seats: null
    }
  ]
}
```
