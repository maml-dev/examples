# 12956 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "delete"
        "manage_billing"
        "view_analytics"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "manage_users"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "manage_billing"
        "read"
      ]
      max_seats: null
    }
  ]
}
```
