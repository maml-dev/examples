# 10627 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "models"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "staging"
      region: "ap-south"
      team: "sports"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 94
    memory_threshold: 87
    latency_p99_ms: 962
    error_rate: 0.05
    notification: {
      channel: "#ops-alerts"
      severity: "warning"
    }
  }
}
```
