# 10744 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "manage_billing"
        "manage_users"
      ]
      max_seats: 13
    }

    {
      name: "viewer"
      permissions: [
        "export_data"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "manage_billing"
        "read"
        "delete"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "manage_users"
        "export_data"
      ]
      max_seats: 32
    }

    {
      name: "support"
      permissions: [
        "export_data"
        "read"
      ]
      max_seats: null
    }
  ]
}
```
