# 17116 - Logger Config

Structured logging configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
  level: "error"
  format: "logfmt"
  timestamp: true
  caller: true # include file:line

  output: "stdout"
  rotation: false
  max_size_mb: 53
  max_age_days: 16
  compress: true
}
```
