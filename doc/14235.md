# 14235 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.downright-pocket-watch.org"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 3545
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://perfumed-populist.name"
      "https://app.key-pension.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 2168
    store: "memory"
  }
}
```
