# 12854 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "whispered-promise.org"
  records: [
    {
      type: "MX"
      name: "*"
      value: "emotional-cop-out.biz"
      ttl: 300
    }

    {
      type: "TXT"
      name: "staging"
      value: "130.173.50.160"
      ttl: 3600
    }

    {
      type: "A"
      name: "cdn"
      value: "v=spf1 include:_spf.noteworthy-kick.info ~all"
      ttl: 300
    }

    {
      type: "CNAME"
      name: "cdn"
      value: "111.28.166.36"
      ttl: 86400
    }

    {
      type: "TXT"
      name: "*"
      value: "cuddly-hyena.org"
      ttl: 300
    }
  ]
}
```
