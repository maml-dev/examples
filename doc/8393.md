# 8393 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "51c58b16-ceea-4269-aec3-f47681adfe06"
  Accept-Language: "fr-FR"
  Cache-Control: "no-cache"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "ex"
    "another one": "solium"
  }
}
```
