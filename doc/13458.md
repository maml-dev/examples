# 13458 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "DELETE"
      path: "/comments/:id"
      handler: "deleteProducts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/posts/:id"
      handler: "deletePosts"
      auth: false
    }

    {
      method: "GET"
      path: "/orders/:id"
      handler: "deleteOrders"
      auth: true
    }
  ]
}
```
