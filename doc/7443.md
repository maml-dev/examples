# 7443 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "POST"
      path: "/comments/:id"
      handler: "createPosts"
      auth: false
    }

    {
      method: "PUT"
      path: "/posts/:id"
      handler: "listProducts"
      auth: true
    }

    {
      method: "PUT"
      path: "/posts"
      handler: "deleteProducts"
      auth: false
    }

    {
      method: "GET"
      path: "/posts/:id"
      handler: "updateOrders"
      auth: false
    }

    {
      method: "PUT"
      path: "/posts"
      handler: "listProducts"
      auth: false
    }

    {
      method: "PUT"
      path: "/orders"
      handler: "updatePosts"
      auth: false
    }
  ]
}
```
