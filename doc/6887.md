# 6887 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@spherical-brook.biz"
  subject: "Defaeco nam color canto deleo alienus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Defleo ulterius deserunt suscipio tepidus volo valeo. Abutor commodo vita suppono alii communis corpus suscipio valeo. Vestigium denuncio deputo contra commodi cohors.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Aufero copia vereor. Tutis cometes uterque derideo substantia. Vita usque vulnus absum delibero sponte valetudo.

Visit: {{url}}
"""
}
```
