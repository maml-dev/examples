# 10428 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "unusual-spork.biz"
  inbound: {
    mx_records: [
      "mx1.unusual-spork.biz"
      "mx2.unusual-spork.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.unusual-spork.biz"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 310
      per_hour: 3781
    }
  }
}
```
