# 15739 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "metrics"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 60 # seconds
    labels: {
      env: "prod"
      region: "ap-south"
      team: "shoes"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 79
    memory_threshold: 88
    latency_p99_ms: 1834
    error_rate: 0.05
    notification: {
      channel: "#oncall"
      severity: "critical"
    }
  }
}
```
