# 6744 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "export_data"
        "write"
      ]
      max_seats: 23
    }

    {
      name: "moderator"
      permissions: [
        "read"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "manage_users"
        "manage_billing"
        "delete"
        "export_data"
      ]
      max_seats: 15
    }
  ]
}
```
