# 6352 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "PATCH"
      path: "/users"
      handler: "deletePosts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/comments/:id"
      handler: "deletePosts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/comments/:id"
      handler: "updatePosts"
      auth: false
    }
  ]
}
```
