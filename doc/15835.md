# 15835 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "qualified-wafer.name"
  inbound: {
    mx_records: [
      "mx1.qualified-wafer.name"
      "mx2.qualified-wafer.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.qualified-wafer.name"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 228
      per_hour: 4734
    }
  }
}
```
