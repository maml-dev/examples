# 12845 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "tender-decision.org"
  records: [
    {
      type: "A"
      name: "*"
      value: "brave-bourgeoisie.com"
      ttl: 86400
    }

    {
      type: "NS"
      name: "www"
      value: "12.223.110.139"
      ttl: 300
    }

    {
      type: "NS"
      name: "www"
      value: "68.187.40.58"
      ttl: 300
    }

    {
      type: "A"
      name: "*"
      value: "v=spf1 include:_spf.present-yak.org ~all"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "cdn"
      value: "v=spf1 include:_spf.unfinished-pliers.info ~all"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "*"

      ttl: 86400
    }

    {
      type: "CNAME"
      name: "api"
      value: "grandiose-larva.name"
      ttl: 86400
    }
  ]
}
```
