# 16536 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "different-battle.org"
  inbound: {
    mx_records: [
      "mx1.different-battle.org"
      "mx2.different-battle.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.different-battle.org"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 283
      per_hour: 1721
    }
  }
}
```
