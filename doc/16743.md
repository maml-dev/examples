# 16743 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "POST"
      path: "/comments/:id"
      handler: "updateOrders"
      auth: true
    }

    {
      method: "GET"
      path: "/orders"
      handler: "listPosts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/comments"
      handler: "updatePosts"
      auth: true
    }

    {
      method: "PUT"
      path: "/orders"
      handler: "getUsers"
      auth: true
    }

    {
      method: "GET"
      path: "/products"
      handler: "updatePosts"
      auth: false
    }

    {
      method: "GET"
      path: "/comments"
      handler: "createPosts"
      auth: false
    }
  ]
}
```
