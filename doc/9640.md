# 9640 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.direct-partridge.com"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 6555
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://handsome-fireplace.net"
      "https://app.alert-thongs.info"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: true
    ttl: 2164
    store: "memory"
  }
}
```
