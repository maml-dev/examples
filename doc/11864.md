# 11864 - Dashboard Layout

Dashboard widget layout configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  title: "O'Keefe Group Dashboard"
  refresh_interval: 30 # seconds
  widgets: [
    {
      type: "chart"
      title: "Signups"
      source: "/api/metrics/traffic"
      chart_type: "bar"
      period: "7d"
    }

    {
      type: "stat"
      title: "Total Users"
      source: "/api/stats/users"
      format: "percent"
    }

    {
      type: "table"
      title: "Latest Signups"
      source: "/api/recent/signups"
      limit: 17
    }
  ]

  theme: "light"
}
```
