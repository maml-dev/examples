# 11049 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "PATCH"
      path: "/products"
      handler: "getUsers"
      auth: false
    }

    {
      method: "PUT"
      path: "/products/:id"
      handler: "getOrders"
      auth: false
    }

    {
      method: "DELETE"
      path: "/products/:id"
      handler: "getUsers"
      auth: false
    }
  ]
}
```
