# 15922 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "nimble-allocation.com"
  inbound: {
    mx_records: [
      "mx1.nimble-allocation.com"
      "mx2.nimble-allocation.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.nimble-allocation.com"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 245
      per_hour: 8502
    }
  }
}
```
