# 14140 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "normal-extension.net"
  inbound: {
    mx_records: [
      "mx1.normal-extension.net"
      "mx2.normal-extension.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.normal-extension.net"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 97
      per_hour: 8151
    }
  }
}
```
