# 12727 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.sugary-stitcher.org"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 4728
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://yellowish-cassava.com"
      "https://app.phony-mainstream.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: true
    ttl: 645
    store: "redis"
  }
}
```
