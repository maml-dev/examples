# 16340 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.purple-reconsideration.net"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 7340
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://orange-patroller.info"
      "https://app.sandy-laughter.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 3408
    store: "redis"
  }
}
```
