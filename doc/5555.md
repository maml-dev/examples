# 5555 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Ctrl+Shift+P"
      action: "toggle_sidebar"
      when: "editor"
    }

    {
      key: "Alt+F7"
      action: "search_project"
      when: "global"
    }

    {
      key: "Ctrl+D"
      action: "command_palette"
      when: "terminal"
    }

    {
      key: "F5"
      action: "command_palette"
      when: "editor"
    }

    {
      key: "F5"
      action: "find_references"
      when: "terminal"
    }

    {
      key: "Alt+Up"
      action: "find_references"
      when: "terminal"
    }
  ]
}
```
