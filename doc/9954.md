# 9954 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "manage_billing"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "manage_users"
        "view_analytics"
      ]
      max_seats: 27
    }

    {
      name: "editor"
      permissions: [
        "manage_users"
        "export_data"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "write"
        "export_data"
        "manage_billing"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "manage_users"
        "export_data"
      ]
      max_seats: 39
    }
  ]
}
```
