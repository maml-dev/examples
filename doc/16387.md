# 16387 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@muddy-cricket.net"
  subject: "Atrocitas acerbitas aliqua adopto cicuta crux."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Decens calco virga tardus textor audeo cometes. Tredecim tabesco clibanus aut dolor. Comitatus calamitas aestivus alveus illo dicta chirographum coruscus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Deprimo valde atavus conforto taceo umbra. Summisse omnis vulariter. Audacia arceo conor alias neque sequi vix.

Visit: {{url}}
"""
}
```
