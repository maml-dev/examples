# 5854 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "view_analytics"
        "read"
        "delete"
        "export_data"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "manage_billing"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "view_analytics"
        "manage_users"
        "read"
        "manage_billing"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "write"
        "view_analytics"
        "manage_users"
        "delete"
        "export_data"
      ]
      max_seats: null
    }
  ]
}
```
