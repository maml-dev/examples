# 16949 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "DELETE"
      path: "/orders/:id"
      handler: "deletePosts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/users"
      handler: "createProducts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/posts/:id"
      handler: "createOrders"
      auth: true
    }

    {
      method: "PATCH"
      path: "/comments/:id"
      handler: "createOrders"
      auth: false
    }

    {
      method: "DELETE"
      path: "/orders"
      handler: "updatePosts"
      auth: true
    }
  ]
}
```
