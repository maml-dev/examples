# 10139 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "blockchains"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 15 # seconds
    labels: {
      env: "prod"
      region: "us-east"
      team: "movies"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 90
    memory_threshold: 95
    latency_p99_ms: 1066
    error_rate: 0.01
    notification: {
      channel: "#ops-alerts"
      severity: "critical"
    }
  }
}
```
