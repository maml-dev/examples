# 9736 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.cumbersome-scrap.com"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 5045
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://nutritious-toaster.org"
      "https://app.ornate-duffel.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: true
    ttl: 3486
    store: "memory"
  }
}
```
