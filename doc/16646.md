# 16646 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "legal-apparatus.org"
  records: [
    {
      type: "MX"
      name: "staging"
      value: "spirited-statue.info"
      ttl: 300
    }

    {
      type: "CNAME"
      name: "cdn"
      value: "imaginative-boulevard.name"
      ttl: 3600
    }

    {
      type: "TXT"
      name: "staging"
      value: "189.237.236.3"
      ttl: 300
    }

    {
      type: "TXT"
      name: "cdn"
      value: "17.97.33.130"
      ttl: 3600
    }
  ]
}
```
