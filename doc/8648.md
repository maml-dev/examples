# 8648 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "read"
        "view_analytics"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "manage_users"
        "export_data"
        "read"
        "manage_billing"
        "write"
      ]
      max_seats: 18
    }

    {
      name: "billing"
      permissions: [
        "manage_billing"
        "write"
        "delete"
        "view_analytics"
      ]
      max_seats: 8
    }
  ]
}
```
