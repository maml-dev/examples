# 17039 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.untimely-granny.info"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 9334
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://jubilant-redesign.org"
      "https://app.weighty-hyena.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: true
    ttl: 1797
    store: "redis"
  }
}
```
