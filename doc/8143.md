# 8143 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Alt+F7"
      action: "save"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+F"
      action: "toggle_sidebar"
      when: "terminal"
    }

    {
      key: "Alt+Up"
      action: "save"
      when: "debug"
    }

    {
      key: "Ctrl+B"
      action: "search_project"
      when: "debug"
    }

    {
      key: "Cmd+Shift+L"
      action: "select_all_occurrences"
      when: "editor"
    }
  ]
}
```
