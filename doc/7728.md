# 7728 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.only-reservation.info"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 5423
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://excitable-citizen.com"
      "https://app.likable-cutover.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 3352
    store: "redis"
  }
}
```
