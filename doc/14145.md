# 14145 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Alt+F7"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Alt+F7"
      action: "find_references"
      when: "debug"
    }

    {
      key: "Alt+Up"
      action: "save"
      when: "debug"
    }

    {
      key: "Cmd+Shift+L"
      action: "toggle_terminal"
      when: "terminal"
    }

    {
      key: "Ctrl+D"
      action: "toggle_sidebar"
      when: "editor"
    }

    {
      key: "Cmd+K"
      action: "search_project"
      when: "terminal"
    }
  ]
}
```
