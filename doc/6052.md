# 6052 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "export_data"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "view_analytics"
        "manage_users"
        "export_data"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "read"
        "export_data"
      ]
      max_seats: 43
    }

    {
      name: "viewer"
      permissions: [
        "manage_users"
        "export_data"
        "manage_billing"
        "read"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "read"
        "view_analytics"
      ]
      max_seats: null
    }
  ]
}
```
