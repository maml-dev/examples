# 7340 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "ai"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 10 # seconds
    labels: {
      env: "staging"
      region: "eu-west"
      team: "computers"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 73
    memory_threshold: 89
    latency_p99_ms: 996
    error_rate: 0.02
    notification: {
      channel: "#ops-alerts"
      severity: "info"
    }
  }
}
```
