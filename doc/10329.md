# 10329 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.ultimate-apricot.net"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 1539
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://unhealthy-smoke.org"
      "https://app.buzzing-retrospectivity.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: true
    ttl: 3404
    store: "memory"
  }
}
```
