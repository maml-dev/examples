# 13347 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "delete"
        "read"
        "view_analytics"
        "write"
      ]
      max_seats: 6
    }

    {
      name: "editor"
      permissions: [
        "export_data"
        "delete"
      ]
      max_seats: 41
    }

    {
      name: "billing"
      permissions: [
        "write"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "delete"
        "write"
        "view_analytics"
        "read"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "write"
        "delete"
        "read"
        "manage_billing"
        "export_data"
      ]
      max_seats: 46
    }
  ]
}
```
