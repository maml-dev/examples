# 9147 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+S"
      action: "search_project"
      when: "debug"
    }

    {
      key: "Ctrl+S"
      action: "command_palette"
      when: "terminal"
    }

    {
      key: "Cmd+K"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+F"
      action: "toggle_comment"
      when: "global"
    }
  ]
}
```
