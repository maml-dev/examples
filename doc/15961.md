# 15961 - Dashboard Layout

Dashboard widget layout configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  title: "Swift, Hagenes and Bogan Dashboard"
  refresh_interval: 30 # seconds
  widgets: [
    {
      type: "chart"
      title: "Signups"
      source: "/api/metrics/revenue"
      chart_type: "line"
      period: "7d"
    }

    {
      type: "stat"
      title: "MRR"
      source: "/api/stats/users"
      format: "percent"
    }

    {
      type: "table"
      title: "Top Pages"
      source: "/api/recent/signups"
      limit: 12
    }
  ]

  theme: "light"
}
```
