# 15027 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "vast-inspection.name"
  inbound: {
    mx_records: [
      "mx1.vast-inspection.name"
      "mx2.vast-inspection.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.vast-inspection.name"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 86
      per_hour: 6105
    }
  }
}
```
