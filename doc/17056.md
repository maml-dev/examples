# 17056 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "youthful-hydrocarbon.com"
  records: [
    {
      type: "AAAA"
      name: "@"
      value: "126.10.191.94"
      ttl: 86400
    }

    {
      type: "NS"
      name: "api"
      value: "129.213.200.18"
      ttl: 300
    }

    {
      type: "TXT"
      name: "mail"
      value: "brown-sustenance.name"
      ttl: 300
    }

    {
      type: "TXT"
      name: "www"
      value: "v=spf1 include:_spf.alive-glider.info ~all"
      ttl: 300
    }
  ]
}
```
