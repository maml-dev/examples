# 9956 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "manage_users"
        "write"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "export_data"
        "manage_billing"
        "view_analytics"
        "write"
      ]
      max_seats: 42
    }

    {
      name: "admin"
      permissions: [
        "read"
        "view_analytics"
        "write"
        "export_data"
      ]
      max_seats: 41
    }
  ]
}
```
