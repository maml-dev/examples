# 12199 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@trusty-bog.name"
  subject: "Ultra tego adiuvo vulticulus clarus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Coruscus spiculum via compello dolores vix amplitudo utrum impedit textor. Ea natus varietas ceno. Culpa alveus cognomen arbitro confugo concedo vetus considero cras blanditiis.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Super absque conventus modi at. Vesco explicabo quasi infit bibo facilis vel claudeo. Bestia ciminatio capillus cernuus praesentium convoco bos aiunt molestiae.

Visit: {{url}}
"""
}
```
