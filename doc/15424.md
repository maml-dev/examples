# 15424 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.baggy-tomography.biz"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 2129
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://entire-squid.info"
      "https://app.pleasant-mixture.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: true
    ttl: 413
    store: "redis"
  }
}
```
