# 4847 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "shameful-yarmulke.name"
  records: [
    {
      type: "CNAME"
      name: "mail"
      value: "44.3.119.124"
      ttl: 86400
    }

    {
      type: "NS"
      name: "staging"
      value: "0.224.57.159"
      ttl: 300
    }

    {
      type: "CNAME"
      name: "@"
      value: "13.82.190.163"
      ttl: 300
    }

    {
      type: "A"
      name: "*"
      value: "250.187.29.95"
      ttl: 86400
    }
  ]
}
```
