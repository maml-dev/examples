# 15626 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "afraid-academics.info"
  inbound: {
    mx_records: [
      "mx1.afraid-academics.info"
      "mx2.afraid-academics.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.afraid-academics.info"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 375
      per_hour: 5440
    }
  }
}
```
