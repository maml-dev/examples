# 15321 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.big-representation.com"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 764
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://svelte-impostor.net"
      "https://app.wicked-hippodrome.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: true
    ttl: 1522
    store: "memory"
  }
}
```
