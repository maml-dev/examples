# 12039 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "unfit-concentration.info"
  inbound: {
    mx_records: [
      "mx1.unfit-concentration.info"
      "mx2.unfit-concentration.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.unfit-concentration.info"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 233
      per_hour: 9872
    }
  }
}
```
