# 12784 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@impressive-optimal.net"
  subject: "Sumptus libero bellum conturbo recusandae aiunt."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Blanditiis conqueror fugiat commodo itaque contigo attonbitus. Pauper esse degenero tantum praesentium. Depulso tui tamisium facere crur expedita.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Tantum copia reiciendis corrupti mollitia. Torqueo ambulo solus careo thalassinus claudeo. Aeger vacuus vesica venustas.

Visit: {{url}}
"""
}
```
