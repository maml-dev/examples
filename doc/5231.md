# 5231 - Theme Config

Design system theme configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
  name: "shabby Theme"
  # Color palette
  colors: {
    primary: "#af8c3f"
    secondary: "#e0acfe"
    accent: "#aadca3"
    background: "#ffffff"

    error: "#dc3545"
    warning: "#ffc107"
    success: "#28a745"

  # Typography
  typography: {
    font_family: "Inter, sans-serif"

      font_family: "\"Space Grotesk\", sans-serif"

    unit: 8

      0
      4
      8
      16
      24
      32
      48
    ]
  }
  border_radius: 6
}
```
