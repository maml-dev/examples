# 7344 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "hateful-scrap.biz"
  records: [
    {
      type: "CNAME"
      name: "www"
      value: "closed-massage.com"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "www"
      value: "v=spf1 include:_spf.crowded-custody.com ~all"
      ttl: 86400
    }

    {
      type: "MX"
      name: "@"
      value: "variable-arcade.org"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "www"
      value: "v=spf1 include:_spf.mundane-napkin.com ~all"
      ttl: 3600
    }

    {
      type: "TXT"
      name: "api"
      value: "199.77.159.246"
      ttl: 300
    }

    {
      type: "AAAA"
      name: "mail"
      value: "v=spf1 include:_spf.interesting-department.net ~all"
      ttl: 3600
    }

    {
      type: "TXT"
      name: "api"
      value: "21.99.154.165"
      ttl: 3600
    }
  ]
}
```
