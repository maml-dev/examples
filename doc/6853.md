# 6853 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Ctrl+B"
      action: "format"
      when: "global"
    }

    {
      key: "Ctrl+S"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+F"
      action: "search_project"
      when: "editor"
    }

    {
      key: "Cmd+Shift+L"
      action: "save"
      when: "global"
    }

    {
      key: "Ctrl+Shift+P"
      action: "command_palette"
      when: "debug"
    }

    {
      key: "F5"
      action: "save"
      when: "editor"
    }
  ]
}
```
