# 13645 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "POST"
      path: "/orders"
      handler: "updateUsers"
      auth: false
    }

    {
      method: "PATCH"
      path: "/products/:id"
      handler: "getProducts"
      auth: true
    }

    {
      method: "DELETE"
      path: "/comments"
      handler: "updateProducts"
      auth: false
    }

    {
      method: "GET"
      path: "/users/:id"
      handler: "updatePosts"
      auth: true
    }

    {
      method: "PUT"
      path: "/comments"
      handler: "getUsers"
      auth: true
    }

    {
      method: "PATCH"
      path: "/posts/:id"
      handler: "createUsers"
      auth: true
    }

    {
      method: "PUT"
      path: "/posts"
      handler: "createPosts"
      auth: false
    }
  ]
}
```
