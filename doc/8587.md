# 8587 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@indelible-understanding.info"
  subject: "Volup subiungo conscendo brevis bonus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Pectus arma balbus attero dolore somniculosus. Repudiandae aliquam tum in. Ascisco laboriosam ancilla.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Defaeco commodo tardus comparo sustineo cilicium stultus articulus cunae alias. Subnecto usitas sortitus arceo aiunt laboriosam vado. Conor versus eligendi adicio abbas sequi denuncio vetus harum suscipit.

Visit: {{url}}
"""
}
```
