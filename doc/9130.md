# 9130 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "similar-plugin.biz"
  inbound: {
    mx_records: [
      "mx1.similar-plugin.biz"
      "mx2.similar-plugin.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.similar-plugin.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 275
      per_hour: 7715
    }
  }
}
```
