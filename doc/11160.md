# 11160 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "pitiful-sermon.biz"
  records: [
    {
      type: "A"
      name: "api"
      value: "210.251.133.155"
      ttl: 300
    }

    {
      type: "NS"
      name: "@"
      value: "crushing-minor.org"
      ttl: 300
    }

    {
      type: "TXT"
      name: "mail"
      value: "naughty-subexpression.net"
      ttl: 3600
    }

    {
      type: "MX"
      name: "www"
      value: "v=spf1 include:_spf.colorful-disposer.info ~all"
      ttl: 86400
    }

    {
      type: "NS"
      name: "@"
      value: "133.173.236.229"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "*"
      value: "v=spf1 include:_spf.fantastic-plain.net ~all"
      ttl: 3600
    }

    {
      type: "TXT"
      name: "cdn"
      value: "v=spf1 include:_spf.oddball-adrenalin.com ~all"

    {
```
