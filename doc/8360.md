# 8360 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "POST"
      path: "/orders/:id"
      handler: "updateUsers"
      auth: false
    }

    {
      method: "PATCH"
      path: "/posts"
      handler: "updateProducts"
      auth: false
    }

    {
      method: "POST"
      path: "/comments"
      handler: "getUsers"
      auth: false
    }

    {
      method: "PUT"
      path: "/orders/:id"
      handler: "getProducts"
      auth: false
    }

    {
      method: "PUT"
      path: "/users/:id"
      handler: "deleteOrders"
      auth: false
    }
  ]
}
```
