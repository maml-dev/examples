# 11449 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "write"
        "view_analytics"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "view_analytics"
        "delete"
        "read"
        "export_data"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "write"
        "delete"
        "manage_billing"
        "export_data"
        "manage_users"
      ]
      max_seats: 26
    }

    {
      name: "moderator"
      permissions: [
        "export_data"
        "read"
        "manage_billing"
      ]
      max_seats: null
    }
  ]
}
```
