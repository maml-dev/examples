# 11547 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+S"
      action: "find_references"
      when: "editor"
    }

    {
      key: "Ctrl+`"
      action: "format"
      when: "debug"
    }

    {
      key: "Ctrl+/"
      action: "toggle_comment"
      when: "global"
    }

    {
      key: "Ctrl+S"
      action: "search_project"
      when: "terminal"
    }

    {
      key: "Ctrl+S"
      action: "command_palette"
      when: "global"
    }

    {
      key: "Ctrl+Shift+F"
      action: "command_palette"
      when: "debug"
    }

    {
      key: "Alt+Up"
      action: "find_references"
      when: "editor"
    }
  ]
}
```
