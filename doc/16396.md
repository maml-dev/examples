# 16396 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "0d67217f-4963-4d24-ad37-b6eae793a6b5"
  Accept-Language: "en-US"
  Cache-Control: "max-age=3600"
  X-Powered-By: "Koa"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "attonbitus"
    "another one": "ante"
  }
}
```
