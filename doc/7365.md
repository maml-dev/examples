# 7365 - Dashboard Layout

Dashboard widget layout configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  title: "Bradtke - Rolfson Dashboard"
  refresh_interval: 30 # seconds
  widgets: [
    {
      type: "chart"
      title: "Active Users"
      source: "/api/metrics/revenue"
      chart_type: "area"
      period: "90d"
    }

    {
      type: "stat"
      title: "MRR"
      source: "/api/stats/users"
      format: "currency"
    }

    {
      type: "table"
      title: "Recent Orders"
      source: "/api/recent/orders"
      limit: 23
    }
  ]

  theme: "light"
}
```
