# 5495 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/xml"
  X-Request-ID: "51c4b698-60d7-4eb3-8f91-78a7631b7d6b"
  Accept-Language: "ja-JP"
  Cache-Control: "no-cache"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "triduana"
    "another one": "adopto"
  }
}
```
