# 7410 - Logger Config

Structured logging configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  level: "debug"
  format: "pretty"
  timestamp: true
  caller: false # include file:line

  output: "stdout"
  rotation: true
  max_size_mb: 384
  max_age_days: 9
  compress: true
}
```
