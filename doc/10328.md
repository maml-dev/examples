# 10328 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "roi"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 10 # seconds
    labels: {
      env: "prod"
      region: "us-east"
      team: "baby"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 91
    memory_threshold: 82
    latency_p99_ms: 1790
    error_rate: 0.05
    notification: {
      channel: "#oncall"
      severity: "warning"
    }
  }
}
```
