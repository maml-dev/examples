# 12083 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@humiliating-ownership.com"
  subject: "Cattus tempore vesco supra adhuc annus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Barba explicabo demoror atqui ullam adulatio qui libero venio curia. Minus cetera tendo utique abbas amor civitas arca. Vigor fugit correptius subvenio saepe denuo volva cribro ad.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Inventore laboriosam mollitia convoco volubilis coma surgo caveo assumenda nulla. Patrocinor trepide turbo tactus sonitus. Videlicet cur uredo canto aestivus nam tumultus.

Visit: {{url}}
"""
}
```
