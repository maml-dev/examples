# 15340 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "ironclad-pocket-watch.com"
  inbound: {
    mx_records: [
      "mx1.ironclad-pocket-watch.com"
      "mx2.ironclad-pocket-watch.com"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.ironclad-pocket-watch.com"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 429
      per_hour: 8700
    }
  }
}
```
