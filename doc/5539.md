# 5539 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "next-brief.info"
  inbound: {
    mx_records: [
      "mx1.next-brief.info"
      "mx2.next-brief.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.next-brief.info"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 243
      per_hour: 4430
    }
  }
}
```
