# 10443 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Cmd+Shift+L"
      action: "format"
      when: "terminal"
    }

    {
      key: "Cmd+Shift+L"
      action: "toggle_terminal"
      when: "editor"
    }

    {
      key: "Ctrl+D"
      action: "toggle_terminal"
      when: "global"
    }
  ]
}
```
