# 14733 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "drab-restaurant.name"
  inbound: {
    mx_records: [
      "mx1.drab-restaurant.name"
      "mx2.drab-restaurant.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.drab-restaurant.name"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 393
      per_hour: 1518
    }
  }
}
```
