# 9887 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@substantial-accelerator.name"
  subject: "Desipio amaritudo antepono tenetur varius considero."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Ait suscipio sub. Suffragium canto vesper arbustum truculenter delicate voluptatum. Explicabo voluptatibus sapiente aperte alii demergo calcar astrum.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Vomer nam confido abutor eaque sophismata trans curtus desipio ad. Tolero vivo sapiente aggredior averto vulnero sumptus ipsa vulariter aspicio. Tendo bonus umquam culpa cado decerno sumo.

Visit: {{url}}
"""
}
```
