# 10751 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "well-lit-shore.net"
  records: [
    {
      type: "CNAME"
      name: "www"
      value: "247.242.102.217"
      ttl: 300
    }

    {
      type: "NS"
      name: "mail"
      value: "6.126.17.59"
      ttl: 300
    }

    {
      type: "NS"
      name: "mail"
      value: "v=spf1 include:_spf.some-wallaby.net ~all"
      ttl: 86400
    }

    {
      type: "CNAME"
      name: "*"
      value: "v=spf1 include:_spf.cool-sauerkraut.com ~all"
      ttl: 300
    }
  ]
}
```
