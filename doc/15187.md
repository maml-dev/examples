# 15187 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "24589056-1651-46a1-aee0-9f40b13eabb6"
  Accept-Language: "en-US"
  Cache-Control: "no-cache"
  X-Powered-By: "Fastify"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "vox"
    "another one": "amo"
  }
}
```
