# 17050 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+D"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Cmd+K"
      action: "debug_run"
      when: "editor"
    }

    {
      key: "Ctrl+S"
      action: "save"
      when: "debug"
    }

    {
      key: "Ctrl+S"
      action: "toggle_sidebar"
      when: "global"
    }
  ]
}
```
