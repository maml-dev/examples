# 10650 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "manage_billing"
        "write"
        "export_data"
        "view_analytics"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "export_data"
        "manage_billing"
        "view_analytics"
        "read"
      ]
      max_seats: 35
    }

    {
      name: "viewer"
      permissions: [
        "read"
        "manage_billing"
      ]
      max_seats: 22
    }

    {
      name: "editor"
      permissions: [
        "delete"
        "view_analytics"
        "export_data"
        "manage_billing"
      ]
      max_seats: null
    }
  ]
}
```
