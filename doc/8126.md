# 8126 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "metrics"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "prod"
      region: "us-east"
      team: "shoes"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 87
    memory_threshold: 85
    latency_p99_ms: 305
    error_rate: 0.05
    notification: {
      channel: "#ops-alerts"
      severity: "critical"
    }
  }
}
```
