# 15124 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.humiliating-tusk.net"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 4208
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://sardonic-armoire.org"
      "https://app.chilly-valentine.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: false
    ttl: 3471
    store: "redis"
  }
}
```
