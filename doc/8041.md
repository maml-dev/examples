# 8041 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "DELETE"
      path: "/comments"
      handler: "deleteOrders"
      auth: true
    }

    {
      method: "DELETE"
      path: "/comments"
      handler: "listOrders"
      auth: false
    }

    {
      method: "GET"
      path: "/users"
      handler: "listProducts"
      auth: false
    }

    {
      method: "PATCH"
      path: "/products/:id"
      handler: "listProducts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/posts"
      handler: "createOrders"
      auth: true
    }
  ]
}
```
