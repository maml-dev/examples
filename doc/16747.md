# 16747 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Ctrl+Shift+F"
      action: "search_project"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+F"
      action: "toggle_terminal"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+F"
      action: "command_palette"
      when: "debug"
    }

    {
      key: "F5"
      action: "save"
      when: "terminal"
    }

    {
      key: "Ctrl+/"
      action: "search_project"
      when: "global"
    }

    {
      key: "Alt+Up"
      action: "select_all_occurrences"
      when: "editor"
    }

    {
      key: "Cmd+K"
      action: "toggle_comment"
      when: "global"
    }
  ]
}
```
