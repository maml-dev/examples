# 5730 - Theme Config

Design system theme configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  name: "wide Theme"
  # Color palette
  colors: {
    primary: "#4ccc07"
    secondary: "#f50f9b"
    accent: "#7c5b8e"
    background: "#0d1117"
    text: "#333333"

    error: "#dc3545"
    warning: "#ffc107"
    success: "#28a745"
  }

  # Typography
  typography: {
    font_family: "\"JetBrains Mono\", monospace"
    base_size: 14
    line_height: 1.6
    headings: {
      font_family: "\"Playfair Display\", serif"
      weight: 800
    }
  }

  spacing: {
    unit: 8
    scale: [
      0
      4
      8
      16
      24
      32
      48
    ]
  }
  border_radius: 4
}
```
