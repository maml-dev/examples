# 8323 - K8s Deployment

Kubernetes deployment specification. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  apiVersion: "apps/v1"
  kind: "Deployment"
  metadata: {
    name: "conversation-api"
    namespace: "staging"
    labels: {
      app: "bell"
      tier: "frontend"
    }
  }

  # Deployment spec
  spec: {
    replicas: 5
    container: {
      image: "cutlet:8.4.18"
      port: 3000
      resources: {
        cpu_limit: "500m"
        memory_limit: "256Mi"
      }
    }

    health_check: {
      path: "/healthz"
      interval: 15
      timeout: 3
    }
  }
}
```
