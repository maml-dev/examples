# 6439 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "indolent-pocket-watch.name"
  inbound: {
    mx_records: [
      "mx1.indolent-pocket-watch.name"
      "mx2.indolent-pocket-watch.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.indolent-pocket-watch.name"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 52
      per_hour: 9335
    }
  }
}
```
