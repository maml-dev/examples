# 9359 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "subdued-venom.name"
  records: [
    {
      type: "NS"
      name: "@"
      value: "v=spf1 include:_spf.sore-interviewer.name ~all"
      ttl: 300
    }

    {
      type: "TXT"
      name: "www"
      value: "massive-king.name"
      ttl: 86400
    }

    {
      type: "MX"
      name: "@"
      value: "v=spf1 include:_spf.physical-bend.com ~all"
      ttl: 3600
    }

    {
      type: "NS"
      name: "staging"
      value: "v=spf1 include:_spf.quixotic-median.name ~all"
      ttl: 86400
    }
  ]
}
```
