# 14549 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "POST"
      path: "/posts/:id"
      handler: "getProducts"
      auth: false
    }

    {
      method: "POST"
      path: "/comments"
      handler: "createOrders"
      auth: false
    }

    {
      method: "PATCH"
      path: "/orders"
      handler: "listUsers"
      auth: true
    }
  ]
}
```
