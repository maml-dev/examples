# 6001 - App Settings

Application environment configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  app_name: "Daniel LLC"
  environment: "production"
  debug: true
  port: 8575

  # Logging
  log_level: "debug"
  log_format: "text"
  api_version: "v5"
  max_request_size: "25mb"
}
```
