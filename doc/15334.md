# 15334 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "interfaces"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 15 # seconds
    labels: {
      env: "prod"
      region: "ap-south"
      team: "beauty"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 93
    memory_threshold: 92
    latency_p99_ms: 507
    error_rate: 0.05
    notification: {
      channel: "#incidents"
      severity: "critical"
    }
  }
}
```
