# 13920 - Proxy Config

```maml
{
  listen: 80
  server_name: "flimsy-wedding.name"
  upstream: "http://localhost:7633"

  # TLS settings
  ssl: false
  http2: true

  gzip: true
  gzip_min_length: 512

}
```
