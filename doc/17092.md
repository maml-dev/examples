# 17092 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@instructive-issue.name"
  subject: "Animadverto angustus decimus libero."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Denuo colo triumphus appono. Alioqui cogo ut sui. Utroque absorbeo nostrum deprecator calamitas videlicet commemoro curtus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Absque civitas comedo pauci terror barba vobis thermae ago subito. Terminatio vestrum curtus accusator aeneus debeo delibero. Iste ipsam quam vesica nostrum.

Visit: {{url}}
"""
}
```
