# 5632 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "stable-fellow.org"
  inbound: {
    mx_records: [
      "mx1.stable-fellow.org"
      "mx2.stable-fellow.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.stable-fellow.org"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 337
      per_hour: 2859
    }
  }
}
```
