# 8923 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.livid-metal.com"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 8086
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://stained-freckle.name"
      "https://app.cluttered-disclosure.org"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 336
    store: "redis"
  }
}
```
