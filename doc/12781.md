# 12781 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@trained-decryption.info"
  subject: "Acsi spero complectus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Ager toties accendo tantillus. Cito crebro velum sed argentum coniuratio vitae audacia defleo. Suspendo odit tui est eius voluntarius combibo tredecim vestrum.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Suasoria civis civis. Desparatus concedo delego ventito iste considero. Eveniet vetus caput enim artificiose congregatio.

Visit: {{url}}
"""
}
```
