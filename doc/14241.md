# 14241 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Alt+F7"
      action: "format"
      when: "debug"
    }

    {
      key: "Ctrl+/"
      action: "format"
      when: "debug"
    }

    {
      key: "Alt+F7"
      action: "toggle_sidebar"
      when: "editor"
    }

    {
      key: "Ctrl+D"
      action: "search_project"
      when: "terminal"
    }

    {
      key: "Ctrl+S"
      action: "toggle_terminal"
      when: "editor"
    }

    {
      key: "Cmd+Shift+L"
      action: "toggle_sidebar"
      when: "debug"
    }
  ]
}
```
