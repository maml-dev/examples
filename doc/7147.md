# 7147 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Ctrl+D"
      action: "select_all_occurrences"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+P"
      action: "select_all_occurrences"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+P"
      action: "format"
      when: "terminal"
    }
  ]
}
```
