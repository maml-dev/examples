# 6960 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "DELETE"
      path: "/users"
      handler: "getOrders"
      auth: true
    }

    {
      method: "POST"
      path: "/products"
      handler: "createOrders"
      auth: true
    }

    {
      method: "POST"
      path: "/products/:id"
      handler: "updatePosts"
      auth: false
    }

    {
      method: "POST"
      path: "/comments/:id"
      handler: "createPosts"
      auth: false
    }

    {
      method: "GET"
      path: "/products"
      handler: "updateProducts"
      auth: true
    }
  ]
}
```
