# 15323 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "handsome-plugin.biz"
  inbound: {
    mx_records: [
      "mx1.handsome-plugin.biz"
      "mx2.handsome-plugin.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.handsome-plugin.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 133
      per_hour: 5969
    }
  }
}
```
