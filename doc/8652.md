# 8652 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "POST"
      path: "/posts"
      handler: "deleteOrders"
      auth: true
    }

    {
      method: "PATCH"
      path: "/comments"
      handler: "getProducts"
      auth: true
    }

    {
      method: "PATCH"
      path: "/users"
      handler: "listPosts"
      auth: false
    }
  ]
}
```
