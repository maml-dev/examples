# 14741 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "viewer"
      permissions: [
        "delete"
        "manage_billing"
        "read"
        "write"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "write"
        "manage_users"
      ]
      max_seats: 6
    }

    {
      name: "viewer"
      permissions: [
        "manage_users"
        "write"
      ]
      max_seats: null
    }
  ]
}
```
