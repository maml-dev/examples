# 5842 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v3"
  routes: [
    {
      method: "DELETE"
      path: "/orders"
      handler: "createOrders"
      auth: true
    }

    {
      method: "PATCH"
      path: "/users/:id"
      handler: "getUsers"
      auth: true
    }

    {
      method: "DELETE"
      path: "/orders"
      handler: "deletePosts"
      auth: true
    }
  ]
}
```
