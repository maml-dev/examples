# 7148 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "write"
        "delete"
      ]
      max_seats: 35
    }

    {
      name: "viewer"
      permissions: [
        "read"
        "manage_billing"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "manage_users"
        "manage_billing"
        "read"
      ]
      max_seats: 2
    }

    {
      name: "support"
      permissions: [
        "read"
        "write"
        "view_analytics"
        "delete"
      ]
      max_seats: null
    }
  ]
}
```
