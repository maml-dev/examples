# 14008 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "short-term-fort.org"
  ttl: 86400 # seconds
  nameservers: [
    "ns1.sleepy-airport.name"
    "ns2.nifty-populist.biz"
  ]

  soa_email: "admin@french-wear.com"
  refresh: 3600
  retry: 1800
  expire: 604800
}
```
