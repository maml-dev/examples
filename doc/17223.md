# 17223 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "heartfelt-saloon.biz"
  inbound: {
    mx_records: [
      "mx1.heartfelt-saloon.biz"
      "mx2.heartfelt-saloon.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.heartfelt-saloon.biz"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 284
      per_hour: 2913
    }
  }
}
```
