# 16540 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.mediocre-pacemaker.com"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 6838
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://kosher-saw.net"
      "https://app.trivial-sarong.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: true
    ttl: 1515
    store: "memory"
  }
}
```
