# 8738 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "oily-extension.net"
  inbound: {
    mx_records: [
      "mx1.oily-extension.net"
      "mx2.oily-extension.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.oily-extension.net"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 323
      per_hour: 9160
    }
  }
}
```
