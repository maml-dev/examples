# 10151 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "F5"
      action: "debug_run"
      when: "debug"
    }

    {
      key: "Ctrl+D"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Cmd+Shift+L"
      action: "debug_run"
      when: "debug"
    }
  ]
}
```
