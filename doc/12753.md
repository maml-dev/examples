# 12753 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "view_analytics"
        "export_data"
        "write"
        "delete"
      ]
      max_seats: 5
    }

    {
      name: "viewer"
      permissions: [
        "read"
        "export_data"
        "view_analytics"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "write"
        "view_analytics"
      ]
      max_seats: 38
    }

    {
      name: "support"
      permissions: [
        "view_analytics"
        "delete"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "view_analytics"
        "manage_users"
        "read"
      ]
      max_seats: 23
    }
  ]
}
```
