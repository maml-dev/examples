# 14923 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "smooth-hope.net"
  inbound: {
    mx_records: [
      "mx1.smooth-hope.net"
      "mx2.smooth-hope.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.smooth-hope.net"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 478
      per_hour: 6691
    }
  }
}
```
