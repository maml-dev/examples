# 15350 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "insidious-pine.com"
  records: [
    {
      type: "CNAME"
      name: "api"
      value: "v=spf1 include:_spf.lively-hovel.net ~all"
      ttl: 300
    }

    {
      type: "NS"
      name: "api"
      value: "natural-cop-out.info"
      ttl: 3600
    }

    {
      type: "MX"
      name: "staging"
      value: "raw-king.info"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "@"
      value: "lanky-receptor.org"
      ttl: 3600
    }

    {
      type: "MX"
      name: "*"
      value: "171.16.217.105"
      ttl: 86400
    }
  ]
}
```
