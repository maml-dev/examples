# 13231 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "empty-incandescence.net"
  inbound: {
    mx_records: [
      "mx1.empty-incandescence.net"
      "mx2.empty-incandescence.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.empty-incandescence.net"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 427
      per_hour: 7777
    }
  }
}
```
