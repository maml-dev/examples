# 13331 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.pretty-charlatan.org"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 3303
    by: "ip"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://whopping-fat.name"
      "https://app.meager-eternity.name"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 359
    store: "redis"
  }
}
```
