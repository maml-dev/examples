# 6648 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "tough-punctuation.biz"
  records: [
    {
      type: "NS"
      name: "api"
      value: "213.115.92.178"
      ttl: 300
    }

    {
      type: "TXT"
      name: "*"
      value: "53.176.5.101"
      ttl: 86400
    }

    {
      type: "NS"
      name: "*"
      value: "v=spf1 include:_spf.jubilant-making.info ~all"
      ttl: 86400
    }

    {
      type: "CNAME"
      name: "api"
      value: "coordinated-monster.net"
      ttl: 3600
    }
  ]
}
```
