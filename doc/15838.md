# 15838 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "schemas"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "staging"
      region: "us-east"
      team: "clothing"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 80
    memory_threshold: 83
    latency_p99_ms: 379
    error_rate: 0.05
    notification: {
      channel: "#ops-alerts"
      severity: "info"
    }
  }
}
```
