# 4944 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v2"
  routes: [
    {
      method: "DELETE"
      path: "/products"
      handler: "getProducts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/posts"
      handler: "deletePosts"
      auth: false
    }

    {
      method: "POST"
      path: "/orders/:id"
      handler: "getUsers"
      auth: true
    }

    {
      method: "PATCH"
      path: "/products"
      handler: "listOrders"
      auth: false
    }
  ]
}
```
