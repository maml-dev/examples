# 4725 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "physical-folklore.info"
  inbound: {
    mx_records: [
      "mx1.physical-folklore.info"
      "mx2.physical-folklore.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.physical-folklore.info"
    port: 587
    tls: true
    rate_limit: {
      per_minute: 142
      per_hour: 7133
    }
  }
}
```
