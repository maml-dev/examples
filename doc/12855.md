# 12855 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vim"
  shortcuts: [
    {
      key: "Ctrl+Shift+F"
      action: "format"
      when: "global"
    }

    {
      key: "Alt+Up"
      action: "select_all_occurrences"
      when: "editor"
    }

    {
      key: "Ctrl+Shift+P"
      action: "debug_run"
      when: "global"
    }

    {
      key: "Alt+Up"
      action: "command_palette"
      when: "terminal"
    }

    {
      key: "Ctrl+B"
      action: "toggle_sidebar"
      when: "editor"
    }
  ]
}
```
