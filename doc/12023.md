# 12023 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "blockchains"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "prod"
      region: "eu-west"
      team: "books"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 91
    memory_threshold: 75
    latency_p99_ms: 1060
    error_rate: 0.01
    notification: {
      channel: "#incidents"
      severity: "warning"
    }
  }
}
```
