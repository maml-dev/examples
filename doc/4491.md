# 4491 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@excitable-circumference.com"
  subject: "Uredo unde compello civitas admitto comburo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Tredecim suffoco est conatus demonstro. Aureus suffragium spiculum bellum decens titulus. Tempore apostolus vilicus deserunt totam defessus quas consuasor necessitatibus.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Curtus apud teneo sint. Patruus cursus laborum minima cibo. Timor taedium corpus.

Visit: {{url}}
"""
}
```
