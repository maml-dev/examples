# 5845 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "admin"
      permissions: [
        "read"
        "view_analytics"
        "manage_billing"
      ]
      max_seats: 31
    }

    {
      name: "viewer"
      permissions: [
        "write"
        "manage_billing"
        "manage_users"
      ]
      max_seats: 46
    }

    {
      name: "viewer"
      permissions: [
        "manage_billing"
        "delete"
      ]
      max_seats: 6
    }

    {
      name: "moderator"
      permissions: [
        "export_data"
        "manage_billing"
      ]
      max_seats: 4
    }

    {
      name: "support"
      permissions: [
        "export_data"
        "manage_billing"
        "manage_users"
        "delete"
        "write"
      ]
      max_seats: 31
    }
  ]
}
```
