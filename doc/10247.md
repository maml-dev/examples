# 10247 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "export_data"
        "read"
        "write"
        "delete"
      ]
      max_seats: 22
    }

    {
      name: "billing"
      permissions: [
        "view_analytics"
        "export_data"
        "read"
        "write"
      ]
      max_seats: 2
    }

    {
      name: "support"
      permissions: [
        "read"
        "export_data"
        "manage_billing"
        "view_analytics"
        "manage_users"
      ]
      max_seats: 38
    }

    {
      name: "viewer"
      permissions: [
        "delete"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "delete"
        "export_data"
        "write"
        "read"
      ]
      max_seats: null
    }
  ]
}
```
