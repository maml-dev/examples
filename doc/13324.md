# 13324 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "models"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "prod"
      region: "eu-west"
      team: "electronics"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 87
    memory_threshold: 82
    latency_p99_ms: 1845
    error_rate: 0.05
    notification: {
      channel: "#incidents"
      severity: "info"
    }
  }
}
```
