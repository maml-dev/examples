# 12456 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "viewer"
      permissions: [
        "delete"
        "read"
        "export_data"
      ]
      max_seats: 47
    }

    {
      name: "support"
      permissions: [
        "write"
        "delete"
        "read"
        "view_analytics"
        "manage_users"
      ]
      max_seats: 35
    }

    {
      name: "admin"
      permissions: [
        "manage_billing"
        "manage_users"
        "read"
        "view_analytics"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "moderator"
      permissions: [
        "write"
        "read"
        "delete"
        "manage_billing"
        "export_data"
      ]
      max_seats: 20
    }
  ]
}
```
