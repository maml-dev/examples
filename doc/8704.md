# 8704 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "muddy-birth.com"
  ttl: 86400 # seconds
  nameservers: [
    "ns1.deep-fisherman.com"
    "ns2.upright-sonnet.org"
  ]

  soa_email: "admin@peaceful-cantaloupe.org"
  refresh: 14400
  retry: 1800
  expire: 1209600
}
```
