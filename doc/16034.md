# 16034 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "blond-freight.org"
  inbound: {
    mx_records: [
      "mx1.blond-freight.org"
      "mx2.blond-freight.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.blond-freight.org"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 306
      per_hour: 7366
    }
  }
}
```
