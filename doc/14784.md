# 14784 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "application/xml"
  X-Request-ID: "f999397b-0dee-4923-ba00-0875735bc234"
  Accept-Language: "fr-FR"
  Cache-Control: "no-cache"
  X-Powered-By: "Koa"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "crustulum"
    "another one": "magnam"
  }
}
```
