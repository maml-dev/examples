# 5348 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "delete"
        "read"
        "manage_billing"
        "view_analytics"
        "write"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "read"
        "write"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "admin"
      permissions: [
        "read"
        "write"
      ]
      max_seats: null
    }

    {
      name: "editor"
      permissions: [
        "write"
        "export_data"
        "manage_users"
        "delete"
      ]
      max_seats: 35
    }
  ]
}
```
