# 17055 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "moderator"
      permissions: [
        "read"
        "export_data"
        "delete"
        "manage_users"
      ]
      max_seats: null
    }

    {
      name: "support"
      permissions: [
        "delete"
        "view_analytics"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "export_data"
        "view_analytics"
        "delete"
        "read"
      ]
      max_seats: null
    }
  ]
}
```
