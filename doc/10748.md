# 10748 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "editor"
      permissions: [
        "write"
        "read"
        "manage_users"
      ]
      max_seats: 25
    }

    {
      name: "moderator"
      permissions: [
        "write"
        "delete"
      ]
      max_seats: 31
    }

    {
      name: "viewer"
      permissions: [
        "write"
        "delete"
        "view_analytics"
        "read"
      ]
      max_seats: 27
    }

    {
      name: "support"
      permissions: [
        "manage_users"
        "read"
        "delete"
      ]
      max_seats: null
    }
  ]
}
```
