# 5833 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "corrupt-cricket.org"
  inbound: {
    mx_records: [
      "mx1.corrupt-cricket.org"
      "mx2.corrupt-cricket.org"
    ]
    spam_filter: {
      enabled: true
      threshold: 7
      action: "reject"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.corrupt-cricket.org"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 77
      per_hour: 4100
    }
  }
}
```
