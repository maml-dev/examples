# 4625 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "far-off-custom.biz"
  inbound: {
    mx_records: [
      "mx1.far-off-custom.biz"
      "mx2.far-off-custom.biz"
    ]
    spam_filter: {
      enabled: true
      threshold: 5
      action: "tag"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.far-off-custom.biz"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 182
      per_hour: 7733
    }
  }
}
```
