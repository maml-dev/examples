# 7428 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.wee-intervention.org"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 975
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://any-tributary.com"
      "https://app.sore-march.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 119
    store: "redis"
  }
}
```
