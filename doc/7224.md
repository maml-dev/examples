# 7224 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "mealy-legislature.name"
  inbound: {
    mx_records: [
      "mx1.mealy-legislature.name"
      "mx2.mealy-legislature.name"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.mealy-legislature.name"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 118
      per_hour: 2965
    }
  }
}
```
