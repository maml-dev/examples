# 12524 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "unruly-e-mail.net"
  inbound: {
    mx_records: [
      "mx1.unruly-e-mail.net"
      "mx2.unruly-e-mail.net"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 1024
    }
  }

  outbound: {
    relay: "smtp.unruly-e-mail.net"
    port: 465
    tls: true
    rate_limit: {
      per_minute: 175
      per_hour: 7959
    }
  }
}
```
