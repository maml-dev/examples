# 8828 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "applications"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 60 # seconds
    labels: {
      env: "prod"
      region: "eu-west"
      team: "baby"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 94
    memory_threshold: 87
    latency_p99_ms: 837
    error_rate: 0.05
    notification: {
      channel: "#ops-alerts"
      severity: "info"
    }
  }
}
```
