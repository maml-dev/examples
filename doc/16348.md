# 16348 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "support"
      permissions: [
        "view_analytics"
        "delete"
      ]
      max_seats: 37
    }

    {
      name: "billing"
      permissions: [
        "write"
        "view_analytics"
      ]
      max_seats: 26
    }

    {
      name: "editor"
      permissions: [
        "view_analytics"
        "read"
        "manage_users"
        "delete"
        "manage_billing"
      ]
      max_seats: 49
    }

    {
      name: "editor"
      permissions: [
        "write"
        "view_analytics"
        "delete"
      ]
      max_seats: 32
    }

    {
      name: "editor"
      permissions: [
        "delete"
        "manage_users"
        "write"
        "manage_billing"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "export_data"
        "manage_billing"
      ]
      max_seats: 37
    }
  ]
}
```
