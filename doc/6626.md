# 6626 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.noxious-commercial.net"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "15m"
    max_requests: 3601
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://sentimental-dependency.com"
      "https://app.pastel-innovation.net"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 2952
    store: "memory"
  }
}
```
