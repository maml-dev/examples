# 7432 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.quintessential-metal.org"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 8106
    by: "user"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://scaly-testing.org"
      "https://app.tricky-ribbon.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 3600
  }

  cache: {
    enabled: false
    ttl: 733
    store: "redis"
  }
}
```
