# 11758 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Cmd+Shift+L"
      action: "find_references"
      when: "editor"
    }

    {
      key: "Alt+Up"
      action: "format"
      when: "debug"
    }

    {
      key: "Cmd+K"
      action: "format"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+P"
      action: "search_project"
      when: "global"
    }

    {
      key: "Alt+Up"
      action: "toggle_terminal"
      when: "debug"
    }

    {
      key: "Ctrl+D"
      action: "select_all_occurrences"
      when: "debug"
    }

    {
      key: "Alt+Up"
      action: "command_palette"
      when: "debug"
    }
  ]
}
```
