# 13329 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.other-wheel.org"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 7971
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://joyous-hammock.info"
      "https://app.boiling-vision.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 576
    store: "redis"
  }
}
```
