# 14798 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@impure-hepatitis.com"
  subject: "Adflicto vociferor custodia candidus adamo cogito."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Antepono sub tantum. Crapula torqueo pel decimus sustineo abduco vicinus ustulo. Cunae damno talus admiratio amplus collum nihil vorax amplitudo colo.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Ulciscor praesentium clarus bellicus capillus defleo tamdiu atqui causa. Occaecati creptio territo cultura confugo qui. Credo ventito vicinus catena conor.

Visit: {{url}}
"""
}
```
