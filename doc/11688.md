# 11688 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@long-curl.biz"
  subject: "Victus aggero aperte nulla articulus tepidus."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Cimentarius vacuus creber caterva suppellex. Verecundia carpo amo arguo. Damnatio nisi corpus quia minima auxilium.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Tracto neque caelestis alii ipsum. Sordeo ultra censura. Tremo comedo cum natus.

Visit: {{url}}
"""
}
```
