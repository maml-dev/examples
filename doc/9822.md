# 9822 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.some-printer.org"
    port: 443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "5m"
    max_requests: 2004
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://unruly-gerbil.biz"
      "https://app.winding-reorganisation.com"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 86400
  }

  cache: {
    enabled: false
    ttl: 2616
    store: "memory"
  }
}
```
