# 12087 - Quoted Keys

Configuration using special characters in keys. This is an example of a [MAML](https://maml.dev) document.

```maml
# HTTP Headers
{
  Content-Type: "text/html"
  X-Request-ID: "241670a0-d70a-4907-abc4-a9e0f1b56fb2"
  Accept-Language: "ja-JP"
  Cache-Control: "no-cache"
  X-Powered-By: "Koa"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "cunabula"
    "another one": "ratione"
  }
}
```
