# 12732 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "platforms"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 30 # seconds
    labels: {
      env: "staging"
      region: "ap-south"
      team: "sports"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 78
    memory_threshold: 81
    latency_p99_ms: 753
    error_rate: 0.05
    notification: {
      channel: "#ops-alerts"
      severity: "info"
    }
  }
}
```
