# 14591 - HTML Templates

Email HTML templates with raw string content. This is an example of a [MAML](https://maml.dev) document.

```maml
# Email template configuration
{
  from: "noreply@worthy-populist.com"
  subject: "Voluntarius caterva soleo."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Cogito cariosus arbustum sortitus capio tempore sed dedico porro. Sonitus textus conspergo perferendis adversus censura. Corpus uter umerus arto cunabula trepide curia.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Quam consuasor alienus capitulus angustus vulnus cultura copia antiquus delinquo. Cattus ratione tubineus summa demergo curo copiose illum defessus autem. Delectus velum adficio tres terminatio trans votum.

Visit: {{url}}
"""
}
```
