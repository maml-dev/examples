# 5851 - Roles & Permissions

Role-based access control definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  roles: [
    {
      name: "billing"
      permissions: [
        "read"
        "delete"
        "export_data"
        "write"
      ]
      max_seats: null
    }

    {
      name: "viewer"
      permissions: [
        "manage_users"
        "manage_billing"
        "write"
        "export_data"
      ]
      max_seats: null
    }

    {
      name: "billing"
      permissions: [
        "manage_users"
        "write"
        "delete"
        "manage_billing"
        "read"
      ]
      max_seats: 34
    }

    {
      name: "editor"
      permissions: [
        "view_analytics"
        "read"
      ]
      max_seats: 34
    }

    {
      name: "support"
      permissions: [
        "read"
        "write"
        "manage_users"
        "view_analytics"
      ]
      max_seats: 49
    }
  ]
}
```
