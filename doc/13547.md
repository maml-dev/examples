# 13547 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Cmd+K"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "F5"
      action: "toggle_sidebar"
      when: "editor"
    }

    {
      key: "F5"
      action: "format"
      when: "editor"
    }

    {
      key: "Ctrl+D"
      action: "format"
      when: "global"
    }

    {
      key: "Alt+F7"
      action: "toggle_sidebar"
      when: "debug"
    }
  ]
}
```
