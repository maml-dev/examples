# 10657 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "sublime"
  shortcuts: [
    {
      key: "Ctrl+/"
      action: "command_palette"
      when: "editor"
    }

    {
      key: "Ctrl+B"
      action: "save"
      when: "global"
    }

    {
      key: "Ctrl+Shift+P"
      action: "debug_run"
      when: "global"
    }

    {
      key: "Alt+Up"
      action: "format"
      when: "editor"
    }
  ]
}
```
