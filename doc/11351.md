# 11351 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Ctrl+B"
      action: "format"
      when: "editor"
    }

    {
      key: "Ctrl+`"
      action: "search_project"
      when: "debug"
    }

    {
      key: "Ctrl+Shift+F"
      action: "toggle_terminal"
      when: "terminal"
    }

    {
      key: "Cmd+K"
      action: "find_references"
      when: "editor"
    }

    {
      key: "Alt+F7"
      action: "toggle_comment"
      when: "debug"
    }

    {
      key: "Ctrl+S"
      action: "toggle_terminal"
      when: "debug"
    }
  ]
}
```
