# 12129 - API Gateway

API gateway routing and middleware configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  gateway: {
    host: "api.murky-devastation.biz"
    port: 8443
    protocol: "https"
  }

  # Rate limiting
  rate_limit: {
    enabled: true
    window: "1m"
    max_requests: 4756
    by: "api_key"
  }

  # CORS policy
  cors: {
    enabled: true
    origins: [
      "https://puny-repeat.name"
      "https://app.fragrant-mentor.biz"
    ]
    methods: [
      "GET"
      "POST"
      "PUT"
      "DELETE"
    ]
    max_age: 7200
  }

  cache: {
    enabled: true
    ttl: 2365
    store: "redis"
  }
}
```
