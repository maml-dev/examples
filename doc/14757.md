# 14757 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "vscode"
  shortcuts: [
    {
      key: "Ctrl+S"
      action: "toggle_comment"
      when: "editor"
    }

    {
      key: "Cmd+Shift+L"
      action: "find_references"
      when: "global"
    }

    {
      key: "Ctrl+S"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "Alt+Up"
      action: "find_references"
      when: "editor"
    }

    {
      key: "Ctrl+`"
      action: "toggle_terminal"
      when: "terminal"
    }

    {
      key: "Cmd+Shift+L"
      action: "toggle_sidebar"
      when: "debug"
    }
  ]
}
```
