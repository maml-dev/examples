# 12650 - Keyboard Shortcuts

Editor keyboard shortcut bindings. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  editor: "emacs"
  shortcuts: [
    {
      key: "Cmd+K"
      action: "find_references"
      when: "global"
    }

    {
      key: "Alt+F7"
      action: "command_palette"
      when: "global"
    }

    {
      key: "Cmd+K"
      action: "debug_run"
      when: "terminal"
    }

    {
      key: "Ctrl+Shift+F"
      action: "search_project"
      when: "terminal"
    }
  ]
}
```
