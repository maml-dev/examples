# 6016 - DNS Config

DNS zone configuration. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "wealthy-ribbon.net"
  ttl: 300 # seconds
  nameservers: [
    "ns1.international-bend.info"
    "ns2.dependable-dash.net"
  ]

  soa_email: "admin@competent-gerbil.name"
  refresh: 3600
  retry: 900
  expire: 1209600
}
```
