# 5249 - API Routes

REST API route definitions. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  base_url: "/api/v1"
  routes: [
    {
      method: "PATCH"
      path: "/products"
      handler: "deleteOrders"
      auth: false
    }

    {
      method: "PATCH"
      path: "/users"
      handler: "updateOrders"
      auth: false
    }

    {
      method: "GET"
      path: "/users/:id"
      handler: "updateProducts"
      auth: false
    }

    {
      method: "DELETE"
      path: "/orders"
      handler: "createUsers"
      auth: true
    }

    {
      method: "POST"
      path: "/orders"
      handler: "getPosts"
      auth: true
    }
  ]
}
```
