# 12547 - DNS Records

DNS zone record entries. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  zone: "darling-impact.net"
  records: [
    {
      type: "CNAME"
      name: "staging"
      value: "wise-fisherman.name"
      ttl: 3600
    }

    {
      type: "NS"
      name: "www"
      value: "hollow-fold.net"
      ttl: 3600
    }

    {
      type: "CNAME"
      name: "@"
      value: "v=spf1 include:_spf.scary-comparison.org ~all"
      ttl: 3600
    }

    {
      type: "AAAA"
      name: "@"
      value: "genuine-coliseum.info"
      ttl: 86400
    }

    {
      type: "AAAA"
      name: "@"
      value: "scary-bran.com"
      ttl: 86400
    }

    {
      type: "CNAME"
      name: "www"
      value: "89.109.101.53"
      ttl: 86400
    }

    {
      type: "TXT"
      name: "www"
      value: "109.1.108.236"
      ttl: 300
    }
  ]
}
```
