# 16024 - Monitoring Config

Application monitoring and alerting setup. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  service: "niches"
  # Prometheus metrics
  metrics: {
    endpoint: "/metrics"
    interval: 10 # seconds
    labels: {
      env: "staging"
      region: "ap-south"
      team: "tools"
    }
  }

  # Alert thresholds
  alerts: {
    cpu_threshold: 83
    memory_threshold: 77
    latency_p99_ms: 151
    error_rate: 0.05
    notification: {
      channel: "#ops-alerts"
      severity: "info"
    }
  }
}
```
