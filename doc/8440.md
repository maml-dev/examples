# 8440 - Email Routing

Email routing and filtering rules. This is an example of a [MAML](https://maml.dev) document.

```maml
{
  domain: "dim-coordination.info"
  inbound: {
    mx_records: [
      "mx1.dim-coordination.info"
      "mx2.dim-coordination.info"
    ]
    spam_filter: {
      enabled: true
      threshold: 8.5
      action: "quarantine"
    }

    dkim: {
      enabled: true
      selector: "default"
      key_size: 2048
    }
  }

  outbound: {
    relay: "smtp.dim-coordination.info"
    port: 25
    tls: true
    rate_limit: {
      per_minute: 280
      per_hour: 2158
    }
  }
}
```
