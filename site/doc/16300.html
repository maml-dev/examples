Example 16300

HTML Templates

Email HTML templates with raw string content.

# Email template configuration
{
  from: "noreply@artistic-hunger.net"
  subject: "Celebrer esse antea aranea."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Adeptio cilicium nulla. Adamo caput aegre iure quidem pecto usitas temporibus. Occaecati talio attero.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Teres deporto barba arguo delicate denego caput adipisci vestrum. Ipsum adulatio aperte caute aequitas nihil angulus thalassinus audentia vinum. Acerbitas depulso valde compono somniculosus deripio cito.

Visit: {{url}}
"""
}
