Example 13789

Quoted Keys

Configuration using special characters in keys.

# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "f3a174e0-bd24-4ca6-a1a4-9c55070baccb"
  Accept-Language: "de-DE"
  Cache-Control: "no-cache"
  X-Powered-By: "Hono"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "ea"
    "another one": "delibero"
  }
}
