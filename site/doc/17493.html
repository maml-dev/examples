Example 17493

Quoted Keys

Configuration using special characters in keys.

# HTTP Headers
{
  Content-Type: "application/xml"
  X-Request-ID: "bae9ded1-6f7a-4df8-bcf1-7236e757b8bc"
  Accept-Language: "ja-JP"
  Cache-Control: "no-cache"
  X-Powered-By: "Koa"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "apparatus"
    "another one": "conqueror"
  }
}
