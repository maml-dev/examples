Quoted Keys

Configuration using special characters in keys.

  Content-Type: "text/html"

  Accept-Language: "ja-JP"
  Cache-Control: "no-cache"
  X-Powered-By: "Fastify"

  # Keys with spaces get quoted

    "custom header": "urbanus"
    "another one": "nihil"
  }
}
