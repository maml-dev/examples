Example 12889

HTML Templates

Email HTML templates with raw string content.

# Email template configuration
{
  from: "noreply@unsung-steeple.biz"
  subject: "Antiquus pecto autus truculenter dedico."
  # HTML email body
  template: """
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Welcome</title>
</head>
<body>
  <h1>Hello, {{name}}!</h1>
  <p>Volubilis consequatur concedo comburo bestia. Deripio quae ventosus armarium stillicidium tabella atqui. Abscido sufficio arbustum explicabo decerno creo.</p>
  <a href="{{url}}">Get Started</a>
</body>
</html>
"""

  # Plain text fallback
  plain_text: """
Hello, {{name}}!

Carcer aiunt acsi sperno sumptus. Vulticulus laborum solitudo admitto aeger toties amet cenaculum aliqua. Odio spectaculum pauci degusto tutamen ustulo velut voluptatibus clarus accusantium.

Visit: {{url}}
"""
}
