Example 8989

Quoted Keys

Configuration using special characters in keys.

# HTTP Headers
{
  Content-Type: "application/json"
  X-Request-ID: "f9e941a5-682c-4d64-b9aa-ca15fb1c7875"
  Accept-Language: "en-US"
  Cache-Control: "public, max-age=86400"
  X-Powered-By: "Koa"

  # Keys with spaces get quoted
  "headers with spaces": {
    "custom header": "numquam"
    "another one": "confugo"
  }
}
